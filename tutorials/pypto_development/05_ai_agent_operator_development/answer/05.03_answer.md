# 行 Softmax 算子开发参考任务

请使用 PyPTO 算子开发工作流完成下列任务。所有必需信息已经给出，请直接开始，不要重复询问算子名称、shape、dtype 或性能目标。

## 算子规格

- 算子名称：`row_softmax`
- 输入：`x`，shape 为 `[8, 8]`，dtype 为 FP32
- 输出：`y`，shape 为 `[8, 8]`，dtype 为 FP32
- 计算轴：最后一维，每一行独立归一化
- 数学定义：对第 `i` 行先计算 `m_i = max_j x[i,j]`，再计算 `y[i,j] = exp(x[i,j] - m_i) / sum_k exp(x[i,k] - m_i)`
- 支持范围：本任务只要求上述固定 shape 和 dtype

## 参考实现与测试

- golden 必须是独立、仅使用 PyTorch、并与上述稳定 Softmax 定义一致的 FP32 参考实现。
- 测试至少包含两类输入：普通随机输入；同时包含较大正值和较大负值的输入。
- 测试必须在 `TILE_FWK_DEVICE_ID` 指定的真实 Ascend NPU 上运行，不能使用 CPU 或仿真结果代替。
- 输出结果中的每个值都必须与参考结果逐一比较；精度要求为 `atol=1e-3`、`rtol=1e-3`，并且 `all_close=true`。

## 工作流范围

- 初始化编排状态时将 `max_stage` 设置为 6。
- 性能目标：本任务不进行性能调优。端到端精度验证通过后停止，不进入性能优化阶段。
- 在 `custom/row_softmax/` 中生成规格、golden、PyPTO 实现、测试和工作流要求的过程产物。
- 必须实际运行生成的 `custom/row_softmax/test_row_softmax.py`，不能只根据 Agent 的文字总结报告完成。

## 禁止行为

- 不得在 `row_softmax_impl.py` 中使用 Torch API 完成核心数值计算。
- 不得为了匹配实现而修改 golden 的数学语义。
- 不得放宽精度容差。
- 不得用 CPU、仿真或“实现与自身比较”冒充真实 NPU 精度通过。

## 验收清单判断依据

1. 数学定义：必须包含“先减行最大值再归一化”的稳定形式，只写 `softmax(x)` 不算明确。
2. 接口：输入输出的名称、`[8,8]` shape 和 FP32 dtype 必须同时出现。
3. 设备与输入：必须写明真实 Ascend NPU（`TILE_FWK_DEVICE_ID`），且覆盖普通随机和较大正负值两类输入。
4. 容差：必须写明 `atol=1e-3`、`rtol=1e-3` 和逐输出比较，不能只写“精度正确”。
5. 运行结果：只能由学习者当前独立重跑 `test_row_softmax.py` 的实际输出确定，退出码为 0 且输出 `all_close=true` 才为满足；Agent 的文字总结不能作为依据。
