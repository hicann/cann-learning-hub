1. A
   动态 shape 代码通常写成 `view -> compute -> assemble`，是因为输入的真实 batch 可能变化。
   kernel 可以按固定 tile 取局部数据，完成计算后再写回全局输出，从而处理未知 batch 或尾块。

2. A
   只把 batch 设成动态，可以保留更多静态 shape 信息。
   这样代码更容易阅读，编译优化也更明确；如果所有维度都动态，边界管理和编译复杂度都会提高。

3. A
   普通 Python `for` 在 Host 侧执行。
   `pypto.loop` 是 PyPTO kernel 计算图的一部分，可以参与设备侧分块、条件分支和写回组织。

4. Host 侧配置开关；根据当前 tile 位置处理特殊逻辑。

5. 循环边界。
   典型场景包括首块初始化、尾块收尾、边界补偿或首尾 batch 的特殊规则。
