# 图编译

## 章节概述
本章讲解 GE 图编译的完整流程，涵盖图构建与输入（AscendIR 构图与 Parser 解析）、编译配置（融合、精度、buffer、stream）、编译产物（OM 结构、外置权重、SO in OM、模型缓存），以及自定义算子入图和自定义融合 Pass 等图编译扩展能力，帮助开发者掌握从图构建到编译输出的全流程实践。
