# 模型执行与优化

## 章节概述
本章讲解 GE 模型执行流程与优化技术，涵盖静态 Shape 执行流程（整图下沉）、动态 Shape 执行流程（Host 调度），以及对应的执行优化技术，帮助开发者理解不同 Shape 场景下的执行机制并掌握性能优化方法。
