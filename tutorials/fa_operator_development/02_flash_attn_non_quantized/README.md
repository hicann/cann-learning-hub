# 第1章 非量化Flash Attention算子开发

## 章节概述
本章聚焦**非量化**Flash Attention（闪存注意力）算子，即输入Q、K、V均为FP16或BF16的高精度浮点类型。本章首先介绍非量化Flash Attention的概念、算子规格与计算流程，帮助开发者建立对非量化注意力算子的整体认识，为后续具体实现章节打好基础。本章不重复介绍Flash Attention的基础原理，也不涉及具体代码实现。
