《FlashAttention 算子开发课程》第 3 章 3.3 节测验答案
====================================================

1. BNSD 是内存连续的。BNSD 按 D→S→N→B 排布，同一个头内的所有
   token 连续存放，因此一个 [128,128] 基本块（同头同段 token × D）
   在张量内顺序存放、地址连续；BSND 按 D→N→S→B 排布，同一头的
   token 被其他头隔开，取基本块需要按 stride 跳址。

2. TND 的 actualSeqLengths 是叠加式，做差得到三条序列长度：
   128、192-128=64、224-192=32，共 128+64+32=224 个有效 token 位置。
   若按 BSND padding 对齐，三条序列都要补齐到最长 128，
   总占用 = 3×128 = 384，浪费 384-224 = 160 个 token 位置。

3. TND 把 B、S 合成一个 T 轴，T 轴按固定基本块（如 128）切分时，
   序列边界不会恰好落在基本块边界上，最后一个块只有不足 128 的行
   （如 72、64 行），这就是尾块。尾块意味着：
   - 基本块大小不再规整，Kernel 需要按实际行数单独处理（掩码、循环次数）；
   - 矩阵乘的 M 维不满，Cube 计算效率下降；
   - Tiling 侧 workspace 与流水设计也要为尾块额外留倍数空间
     （如 s2Size 不对齐时 stage 空间从 2 倍升 3 倍）。
