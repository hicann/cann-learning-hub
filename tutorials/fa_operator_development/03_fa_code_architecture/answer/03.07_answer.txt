《FlashAttention 算子开发课程》第 3 章 3.7 节测验答案
====================================================

1. Q 是「驻留片上」的输入：GM --DataCopy--> L1A --LoadData--> L0A，
   在整个 S2 循环里反复使用、不重复搬运；
   P 是 vector1 的产物：从 UB 回流到 L1A 再 LoadData 到 L0A，
   走的是 Vector → Cube 的反向通路（分离架构下 UB↔L1 双向通路），
   每个 KV 块现算现用。

2. 右矩阵（K、V）在 L1→L0 搬运时用 LoadDataWithTranspose，
   在搬运的同时完成转置：mmad 需要的 B 操作数排布与 GM 中的
   存放排布不一致，借助搬运指令顺带完成格式变换，
   省去单独的转置计算。

3. 乒乓解决「搬运与计算互相等待」的问题。没有乒乓时，
   同一块缓冲先被填（搬运）、再被算（计算）、再填下一块——
   搬运单元和计算单元在时间上严格串行交替空转；
   乒乓用两份缓冲让任一时刻都有一份在被计算、另一份在被填充，
   搬运时间被计算时间「藏」起来。

4. 基本块 64×128 = 8192 个 FP32 数据，一条 VF 指令处理 64 个，
   至少 8192 / 64 = 128 条 VF 指令（仅按数据量估算，
   不计中间量如 m、l 的额外指令）。
