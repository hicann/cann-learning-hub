《FlashAttention 算子开发课程》第 3 章 3.2 节测验答案
====================================================

1. 两段式把「检查与准备」和「执行」解耦：
   - workspace 的大小必须由 Tiling 算出来（CV 数据交换空间 + Vector 核计算
     空间 + 预留），框架要提前统一申请，不能等 Kernel 跑起来再发现不够；
   - 第一段把输入解析、Tiling 计算的产物打包进 aclOpExecutor，
     第二段直接消费，避免重复解析，且同一 executor 可在不同 stream 上复用。

2. GQA（分组查询注意力），N1=32 个 Q 头共享 N2=8 组 KV，
   组数 G = N1/N2 = 4，即每 4 个 Q 头共用同一份 K/V。

3. nextTokens = 0 表示每个 token 只能关注它自己及之前的 token，
   即因果掩码（causal mask）场景；preTokens 给了一个很大的值，
   意味着向前的范围不构成实际限制。
