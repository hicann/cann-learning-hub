《FlashAttention 算子开发课程》第 2 章 2.7 节测验答案
====================================================

1. FA1 论文算法：外层循环 KV 块（每个 KV 块载入片上，服务所有 Q 块），
   内层循环 Q 块。
   2.5 节伪代码（V2 结构）：外层循环 Q 块，内层循环 KV 块——正好相反。

2. FA1 的更新式 O ← (α·l·O + P̃·V) / l_new，每步除以 l_new 是为了让 O_i 始终
   保持"已归一化"状态。
   收益：O 在任何时刻都是一个语义完整的中间结果（近似加权平均），短序列时所有
   状态可以整体驻留片上，概念上干净。
   代价：每个块对上都要对 O 做 3 趟逐元素乘 + 1 趟除——non-matmul 运算数量
   与块对总数 Tr×Tc 成正比，随序列长度平方增长，且这些运算只能落在
   CUDA core / Vector 单元，速度远低于 Tensor Core / Cube。

3. FA1 的并行维度 = batch × head（B × H）。因此在小 batch、少头数的场景
   （典型如 batch=1 的长文推理、decode）下任务数远小于核心数，大量算力闲置
   （B=1、H=8 时 108 个 SM 只亮 8 个，占用率约 7%）。

4. 因为加速器上矩阵乘单元（GPU 的 Tensor Core、NPU 的 Cube）与逐元素运算单元
   （CUDA core / Vector）的速度相差悬殊：逐元素运算既占不满专用矩阵单元，
   又要额外读写片上存储。FA2 论文的经验法则是每搬运 1 字节片上存储应配上
   约 100 FLOPs 的计算，否则算力抵不过搬运——non-matmul 运算正是"低算力高搬运"
   的低效部分，占比越高整体越远离峰值。

5. 错。FA1 是精确算法——输出与标准 Attention 逐位一致（本节实验对拍误差 1e-16 量级，
   纯浮点舍入）。它省显存靠的是分块计算让 n×n 的中间矩阵 S、P 从未出现在 HBM，
   而不是近似。

6. FA1 风格除法 2048 次，V2 风格 512 次，比值 4（= 块对数 16 ÷ Q 块数 4）。
   即 FA1 每个块对都除一次，V2 把 ÷l 推迟到每个 Q 块收尾只除一次；
   逐元素乘法 FA1 也比 V2 多 1/3（4096 vs 2048）。

7. K、V 外层载入，各只搬运 1 轮（总量 = 自身数据量，是"好公民"）；
   Q、O、l、m 在每个外层轮次都要从 HBM 读回片上，共 Tc 轮，
   总流量 = (Q+O+l+m) 数据量 × Tc；O 的中间结果每个块对算完还要
   写回 HBM、下轮再读回累加。
   "O 的更新与 Q 绑定"使这部分流量随 Tc（即随序列长度 n）线性增长
   ——外层每多一个 KV 块，全部 Q 块的状态和 O 就多横穿一次 HBM。
   V2 交换循环后 Q 只读 1 次、O 只写 1 次，这笔账被彻底抹掉。
