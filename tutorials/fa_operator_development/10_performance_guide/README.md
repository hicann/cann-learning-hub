# 第10章 性能优化指南

> 所属部分：第三部分 FA 算子性能优化实战 ｜ 状态：✅ 已发布

## 章节概述

本章是全书性能优化部分的收束：将前面各章的优化方法**汇总**为一份可检索、可执行的性能优化指南。拿到一个 FA 算子（或通用 Cube/Vector 算子）的性能问题后，按「性能建模定位 → 均衡性检查 → CV 流水与切块 → 核内流水 → 负载均衡」的路径逐项排查，直至逼近硬件理论性能。

本章的三份产出：**优化方法地图**（10.2，全书方法一页总览）、**排查路径与决策树**（10.3，症状 → 处方对照）、**逐项 checklist**（10.4，五张可打印清单）。
