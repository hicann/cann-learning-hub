# 10.5 章节测验答案

**Q1** 四层次：核间 → 引擎间 → 引擎内 → 指令级。上层问题（核空转）下层补不回来，所以从上往下。

**Q2** 输出 bound 判断（带宽受限 I < I* / 计算受限 I > I*）。带宽线优先查 K 切分整块率、DN、bank 冲突；计算线优先查 VF 优化、块大小、RegBase。

**Q3** 有效块计量 + 贪心分核（9.2/9.3）：分核不均的根因是 mask/section 没计入有效块统计。

**Q4** Cube busy 高、Vector idle 多 → Vector 活太少。处方：块大小重权衡（7.5）、AIV 配比调整；若 Vector 长阶段没被掩盖导致 Cube 断流，则 preload 流水（第5章）。

**Q5** BGBK_CFLT = UB bank 冲突实锤。三板斧：① VEC 单条指令限宽（不超 256B）；② 读写 pingpong（输入输出分放 ping/pong）；③ 块分布到多个 bank group。

**Q6** 四步：① 列容量约束求 kBase 上限（L0A/L0B 方程）；② 对齐到分形 16 与搬运粒度；③ 建模每个候选的耗时（搬运笔数 + fixup 段数 + 复用率）；④ 取耗时最小者，尾块单独兜底（掩码/降档/合并）。

**Q7** 四条纪律：先测量再动手、一次改一项、量化验收、回到上一层。瓶颈迁移指修好一处后瓶颈移到另一层（如核间 → 引擎间），所以优化必须迭代：每轮重新测量、重新建模、再走决策树。

**Q8** DN 条件：输入类型受限（float/fp8/hifloat8 等）、无可选输入（无 pse/mask/drop）、布局对齐（d 维对齐 128 等）、S2 较长。带 mask 时必须在 Vector 上把掩码叠加到 mm1 的输入，Vector 中转不可避免，DN 省中转的收益消失、只剩对齐约束的负担，所以不划算。
