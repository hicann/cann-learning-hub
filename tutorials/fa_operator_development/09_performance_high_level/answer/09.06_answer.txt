# 9.6 章节测验答案

**Q1** 三层：① shape 锯齿（B/N 不整除核数的离散锯齿）；② mask 无效块（因果 mask 下靠前的 S1 行有效块少）；③ section 变长（各 batch 有效 KV 不同、含 shared prefix 分段）。名义 shape 均分在这三层都会把「空气」当任务分出去，负载严重倾斜。

**Q2** section 是 KV 轴上的有效分段。输入从标量 shape 变成 per-batch 的有效区间数组，分核从算术题变成带变长权重的一维装箱题。

**Q3** 计量单位 = 每个 (b,n,s1) 行的有效 S2 基本块数。CoreWeight = Σ所有行权重 / 核数 = 每核期望负载。

**Q4** 并行度 = B×N×S1，decode 下 Q=1、B 小，行数远小于核数（如 8 任务 vs 40 核），唯一并行度来源是 S2，必须切 KV。

**Q5** `if (sInnerBlockNums - dif > dif)`，dif = target×(curCore+1) − curWeight。直觉：下一行比缺口的两倍还大时，塞进当前核会跨过理想值太多，让它去下一个核两边更均衡。

**Q6** 本质区别：封核边界——不合轴只能落在整行边界（粒度=行权重），合轴可落在任意 gs1 位置（粒度=基本块）。合轴买到均衡上限（逼近理论极限），付出 gs1 解码与跨 BN 核特殊路径的实现成本。

**Q7** 合轴：行数 < 核数或行权重方差大（decode、变长严重）——粒度是主要矛盾。不合轴：prefill/训练，行数远超核数——锯齿被摊薄，简单结构更划算。

**Q8** 三个坑：① gs1 解码的除法/取模 → 预计算查找表上提 TilingData；② 跨 BN 边界核 base 地址切换 → 「单 BN 核 / 跨 BN 核」两条内部路径；③ 行被劈开的 softmax 统计跨核拼接 → 走 merge 通路（与切 S2 同源）。

**Q9** M = max(m_i)；L = Σ l_i·exp(m_i−M)；ACC = Σ acc_i·exp(m_i−M)；attn = ACC/L。缩放因子把各段从局部基准 m_i 对齐到全局基准 M，没有它不同基准的指数不可相加，结果错误。

**Q10** 不是。并行度上限 = 核数，之后收益封顶，merge 成本（buffer 读写 + 归并计算 + 核间同步）线性上涨。在线 softmax 在任何作用域只维护 (m, l, acc) 局部统计量，归并规则可交换、与顺序无关——所以能沿任意轴切分、任意顺序合并，这是 FA 一切并行化的数学根基。
