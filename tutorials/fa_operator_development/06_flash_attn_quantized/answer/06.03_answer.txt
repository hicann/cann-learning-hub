06.03 量化原理 —— 小测验答案

1. 公式与浮点选对称的原因：
   - 非对称：q = round((r - Z) / S)，反量化 r̂ = S·q + Z，定点区间 [-128, 127] 或 [0, 255]；
   - 对称：q = round(r / S)，反量化 r̂ = S·q，是对称量化取 Z = 0 的特例。
   - 浮点格式（FP8/HiF8）自带符号位、正负区间天然对称，零点 Z 没有用武之地；且对称量化省掉零点的存储与计算，反量化退化为一次乘法。整数格式面向无符号硬件或偏移明显的数据时才需要 Z。

2. amax 法下离群值的危害：
   - S = amax / QMAX 由最大绝对值决定。一个离群通道的 amax 是其他通道的 100 倍时，全局 scale 被拉大 100 倍，其他通道的有效分辨率（QMAX/S）下降 100 倍，大量数值舍入到 0（见 6.4 节代码实验：pertensor 误差 3.7% vs pergroup 0.95%）。
   - 大模型（LLM）的激活恰恰有著名的离群通道问题，所以粗粒度量化精度差，必须靠更细的粒度（pergroup/perblock）把离群值「关进自己的组」。

3. AntiQuant 与 Dequant 的区别：
   - AntiQuant：处理**输入**——把低 bit 存储的数据（INT8/INT4/FP8）转回高精度（BF16/FP16）供计算，发生在算子计算之前；伪量化场景下作为独立算子插在存储与计算之间。
   - Dequant：处理**输出**——把低 bit 计算结果（INT32）转回高 bit（BF16/FP16），一般发生在 matmul 后的 FixPipe 单元，随路完成。
   - ReQuant 则是把 INT32 结果转回低 bit（INT8/INT4），供下一层继续低 bit 计算，同样在 FixPipe。

4. 静态/动态的适配对象与代价：
   - weight 在推理期间不变，离线校准一次即可拿到稳定 scale——静态量化的「scale 作为固定参数传入」性能最好（kernel 里不需要在线统计）。
   - 激活随每次输入变化，离线统计的 scale 容易失配——动态量化在线对 feature 统计 amax 并同步计算 scale，精度更高，但付出在线统计的计算开销（Vector 上的 amax 归约），量化算子性能略差。
   - 训练为了保精度一般也用动态量化；推理对 weight 静态、对激活按精度要求在静态（快）与动态（准）之间取舍。
