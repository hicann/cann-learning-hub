07.06 优化步骤③核内流水 —— 小测验答案

1. RegBase 相比 MemBase 的差异：
   - MemBase：GM → UB → GM，每条 Vector 计算指令都从 UB 读操作数、写回 UB。
   - RegBase：GM → UB → RegisterFile → UB → GM——数据装进向量寄存器后，多条计算在寄存器间连续流转，不必每条回 UB。
   - 收益：省掉中间的 UB 读写（每次都可能是 bank 冲突点）；寄存器访问零延迟，计算密度拉满——核内最后一级流水。

2. 四类寄存器与处理单元：
   - 向量寄存器（RegTensor）：存放计算指令的目标数据；地址寄存器（AddrReg）：跟随 for-loop 迭代累加，更新 UB 搬运起始地址；对齐寄存器（UnalignReg）：访问 UB 上非 32B 对齐地址；掩码寄存器（MaskReg）：按 bit 标识有效数据（0 为无效），控制指令只作用于有效位。
   - LD 指令由寄存器读单元处理（UB → 向量寄存器）；ST 指令由寄存器写单元处理（向量寄存器 → UB）；计算指令由寄存器计算单元处理（源与目的都是 RegTensor）；标量计算由 VF-Scalar 单元处理。

3. vLoop 与尾块：
   - 循环次数 repeatTimes = ceil(size / floatRepSize)，floatRepSize = 64（一个寄存器 256B = 64 个 FP32）。
   - 尾块（size 不是 64 整数倍的最后一段）靠 MaskReg 兜底：掩码按 bit 标识该段内哪些数据有效，Mul 等 API 带 MaskMergeMode::ZEROING 让无效位写 0——不用为尾块单独写一套循环。

4. VF 定位三步法：
   - ① 先排除外围：UB 上的值都能用调测指令打印，先确认错误发生在 VF 代码内还是外（搬运、同步等外围问题先排掉）；
   - ② 手推公式：保证搬运正确后，从 vLoop 开始逐条指令手推计算，验证哪一步与预期不符；
   - ③ 搬出验证：把寄存器中的中间数据 ST 回 UB 再打印，与手推值对比——VF 内部不可观测，就用「搬出来」制造观测点。
