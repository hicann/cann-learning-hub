《FlashAttention 算子开发课程》第 1 章 1.2 节测验答案
====================================================

1. Q、K、V 的形状都是 n × d（n 为序列长度，d 为单头维度）。
   三者都来自同一份输入 X（n × d_model）：
   Q = X·W_Q，K = X·W_K，V = X·W_V，其中 W_Q/W_K/W_V 是三组可学习的权重矩阵。

2. S[i, j] = 第 i 个 token 的查询与第 j 个 token 的键的点积（除以 √d），
   衡量"第 i 个 token 对第 j 个 token 的关注程度"。
   S 是 n 行（n 个查询）× n 列（n 个键被查询）的两两比对结果，
   比对的对象是"查询×键"，与向量维度 d 无关，所以是 n × n。

3. 按行做。因为每一行是"同一个查询对所有键的分数"，
   归一化的语义是"这个 token 把注意力按比例分给各个位置"，和必须为 1；
   按列做没有这种概率含义（一列属于不同的查询，混在一起没有意义）。

4. 不除 √d 时，点积的方差随维度 d 线性增长（实验中 d=4096 时随机点积
   可达 ±100 量级）。分数差距过大时 Softmax 饱和成近似独热分布
   （一个位置接近 1、其余接近 0），注意力和梯度失去区分度，训练困难。
   除以 √d 把分数方差拉回约 1 的量级。

5. GQA 节省的是 KV Cache 的显存与访存。推理阶段逐字生成时，
   每一步都要把全部历史 K/V 读一遍参与计算，缓存大小直接决定
   长上下文能力和每步访存量；训练时 KV 不需要持久缓存，压力小得多。

6. KV Cache 里存的是 K 和 V。Q 不需要缓存，因为每步只有新 token 的
   1 行 Q 需要计算，用完即弃；而历史 token 的 K、V 在后续每一步
   都要被新 Q 重新"查询"，才算一次存起来反复复用是划算的。
