《FlashAttention 算子开发课程》第 1 章 1.4 节测验答案
====================================================

1. 因为 e^x 单调递增且增长极快，减去行最大值 m 后所有指数变为
   e^(x-m) ≤ e^0 = 1（且 > 0），指数部分永远落在 (0, 1] 区间，
   不可能超过浮点上限，故一定不溢出；分母也由有限项 (0,1] 的数
   相加而成，同样安全。正确性由平移不变性保证：分子分母同乘 e^(-m)。

2. Softmax(x_i) = e^(x_i) / Σ e^(x_j)。把每个 e^(x_j) 都写成
   e^(m_old)·e^(x_j - m_old)，分子分母中的 e^(m_old) 约掉，
   所以基准 m 取多少都不影响结果（数值前提：exp(x-m) 不上溢，
   即基准不能太小——1.4 节 m=-1000 的反例正是违反了这一点）。
   换基准 m_old → m_new 时，
   α = e^(m_old - m_new)。因为 m_new = max(m_old, 新块最大) ≥ m_old，
   所以 m_old - m_new ≤ 0，α ≤ 1（α ≤ 1 保证旧状态只会被缩小，
   数值天然稳定）。

3. l_new = α·l_old + rowsum(P̃)，其中 P̃ = e^(S_new - m_new)；
   Õ_new = α·Õ_old + P̃·V_new。
   最终输出 O = Õ / l（所有块处理完后）。

4. 外层切 Q（每块 M 行），内层切 KV（每块 B 行）。
   分工原因：Q 块的三状态 (m, l, Oacc) 必须驻留片上跨内层循环
   存活，Q 是"驻留方"，块数少、状态连续；K/V 是"流过方"，
   逐小块搬入、用完即弃，且每个 KV 块会被所有 Q 块复用，
   读取次数从 n 摊薄到约 n/M 次。

5. 第 i 个 Q 块只需遍历到它自己所在的块号（j ≤ block(i)）为止。
   j < block(i) 的整块（严格下三角区）完全不需要元素级掩码——
   块内所有位置都是"过去"；只有对角块（j == block(i)）内部
   既有过去又有未来，才需要逐元素掩码。

6. 错。FlashAttention 是精确算法：Online Softmax 与整体 Softmax
   数学上严格相等（平移不变性 + 递推的归纳证明），分块只改变
   计算顺序与访存路径，不引入任何近似（1.5 节实验误差仅在
   浮点舍入量级 1e-10）。它快是因为 IO-aware 的数据流重构，
   而不是牺牲精度。注意与"稀疏注意力 / 线性注意力"等真正的
   近似方案区分。
