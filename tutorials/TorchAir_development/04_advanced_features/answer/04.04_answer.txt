======================================================================
4.4 AI Core 和 Vector Core 限核功能 章节练习答案
======================================================================

1. （单选题）`limit_core_num` 配置的核心语义是什么？
   答案：B
   解析：limit_core_num 配置的是 Stream 级最大核数，而不是每个算子固定使用的实际核数。

2. （单选题）AI Core 算子的实际用核数在 Profiler 的 `kernel_details.csv` 中主要查看哪一列？
   答案：A
   解析：AI Core/AI Vector 算子的实际核数查看 Block Num，Mix Core 还需查看 Mix Block Num。

3. （单选题）`stream=None` 作为 `limit_core_num` 的 stream 参数时，表示什么？
   答案：B
   解析：stream=None 表示进入 with 语句块时的当前 Stream。

4. （单选题）对通信类算子，当前限核功能支持哪种类型的控核？
   答案：B
   解析：通信类算子只支持 AI Vector 控核。

5. （单选题）在 CANN <= 8.5.0 时，同时开启静态 Kernel 与控核功能，通常优先保证什么生效？
   答案：B
   解析：在 CANN 8.5.0 及以下版本中，控核优先生效，相关静态 Kernel 会失效。

6. （单选题）不推荐多线程并发设置同一条 Stream 控核数的主要原因是？
   答案：A
   解析：多线程并发设置同一 Stream 时，最终控核值无法得到确定性保证。

7. （多选题）关于限核功能的描述，正确的有哪些？
   答案：ABC
   解析：应选择 A（配置值是最大值，不保证算子一定用满指定核数）、B（配置值不能超过目标 AI 处理器允许的最大核数）、C（可通过 SoC 配置文件查看 AI Core 与 Vector Core 数量）。这些做法符合本功能的使用约束与验证原则；未选项不能作为正确结论。

8. （多选题）限核功能更适合哪些使用方式或场景？
   答案：ABC
   解析：应选择 A（micro batch 多流并行场景）、B（为不同 Stream 预留资源，避免单流独占全部计算核）、C（与 Profiler 结合验证实际的核使用情况）。这些做法符合本功能的使用约束与验证原则；未选项不能作为正确结论。

9. （多选题）使用 `limit_core_num` 时，正确的做法有哪些？
   答案：ABC
   解析：应选择 A（分别设置 `op_aicore_num` 与 `op_vectorcore_num` 的合法值）、B（在目标 Stream 的上下文中配置需要受限的算子）、C（对 Mix Core 算子同时关注 `Block Num` 和 `Mix Block Num`）。这些做法符合本功能的使用约束与验证原则；未选项不能作为正确结论。

10. （多选题）下列哪些限制或注意事项是正确的？
   答案：ABC
   解析：应选择 A（非 Ascend C 算子暂不支持控核）、B（通信类算子仅支持 AI Vector 控核）、C（静态 Kernel 和控核的优先级会受 CANN 版本影响）。这些做法符合本功能的使用约束与验证原则；未选项不能作为正确结论。
