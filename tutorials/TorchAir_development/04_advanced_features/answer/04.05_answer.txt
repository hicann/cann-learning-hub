======================================================================
4.5 静态 Kernel 编译功能 章节练习答案
======================================================================

1. （单选题）静态 Kernel 编译最适合哪类模型或输入场景？
   答案：B
   解析：静态 Kernel 编译适用于固定 Shape 或可枚举的少量 Shape 场景。

2. （单选题）开启静态 Kernel 编译的 options 参数是？
   答案：A
   解析：通过 torch.compile 的 options.static_kernel_compile=True 开启静态 Kernel 编译。

3. （单选题）在 `static_kernel_compile=True` 时，设置 `disable_static_kernel_compile_cache=False` 的含义是？
   答案：B
   解析：static_kernel_compile=True 时，disable_static_kernel_compile_cache=False 表示允许命中并复用缓存。

4. （单选题）多卡场景使用静态 Kernel 编译前，必须配置哪个环境变量？
   答案：B
   解析：多卡场景必须设置 LOCAL_WORLD_SIZE，并确保同一节点各进程取值一致。

5. （单选题）以下哪项会导致静态 Kernel 缓存不命中？
   答案：A
   解析：CANN、硬件、算子属性或相关编译选项变化都会造成缓存不命中。

6. （单选题）当 Profiler 的 `record_op_args=True` 且 `skip_first=0` 时，对静态 Kernel 编译的影响是？
   答案：B
   解析：指定的 Profiler 算子信息统计组合不支持与静态 Kernel 编译同时使用。
