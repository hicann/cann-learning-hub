======================================================================
3.2 基础功能介绍 章节练习答案
======================================================================

1. （单选题）`force_eager=True` 的主要作用是什么？
   答案：B
   解析：force_eager 保留 npugraph_ex 的上层图增强处理，但不执行 NPUGraph Capture-Replay，可用于区分上层图处理与 Runtime 问题。

2. （单选题）设置 `force_recapture=True` 后，最符合其行为的是？
   答案：A
   解析：force_recapture 会在每次执行前重新 Capture，可用于区分图捕获执行与输入输出内存处理问题。

3. （单选题）业务需要在多次 Replay 后仍长期持有某次输出时，应优先开启哪个选项？
   答案：B
   解析：clone_output 用于避免长期持有的输出被后续 Replay 覆盖。

4. （单选题）`fullgraph=True` 的含义是？
   答案：B
   解析：fullgraph=True 要求目标逻辑形成单一图，出现图中断时会直接暴露问题。

5. （单选题）下列哪个基础选项的默认值为 `False`？
   答案：B
   解析：clone_output 默认值为 False；clone_input、inplace_pass 和 pattern_fusion_pass 默认值均为 True。

6. （单选题）`pattern_fusion_pass=True` 的主要目的是什么？
   答案：B
   解析：pattern_fusion_pass 会用融合算子替换匹配的 FX 子图。

   答案：ABC
   解析：应选择 A（先以 Eager 结果确认模型数值正确性）、B（使用 `force_eager=True` 区分上层图处理与 NPUGraph Runtime 问题）、C（使用 `force_recapture=True` 判断问题是否与回放或地址复用有关）。这些做法符合本功能的使用约束与验证原则；未选项不能作为正确结论。
