==================== 第 1 题（单选） ====================
答案：B
解析：昇腾NPU的并行体系是「外层多核SPMD + 内层单核SIMD」的双层嵌套结构——多核集群通过block_idx分配数据分片（SPMD），单核内部再用一条指令批量并行处理一批同构数据（SIMD）。A、C、D均混淆了二者的嵌套关系与各自职责。
==================== 第 2 题（单选） ====================
答案：C
解析：「各数据元素可按不同分支独立执行」是SIMT（单指令多线程）的特征，而非SIMD。SIMD要求所有数据在同一指令周期内同步执行完全相同的操作，具备单指令驱动、数据同构、同步执行三个特征。
==================== 第 3 题（单选） ====================
答案：B
解析：Vector算子的核心计算逻辑由AI Core的向量处理单元（Vector）承载，遵循SIMD并行、在UB上完成计算。标量处理单元负责控制流与地址计算，Cube面向矩阵计算，本地存储用于缓存数据。
==================== 第 4 题（单选） ====================
答案：C
解析：`asc.muls`为乘标量（输入 + 标量）z = x * scalar，属于标量类接口；`asc.add`/`asc.max`为双目，`asc.relu`为单目。
