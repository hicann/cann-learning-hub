==================== 第 1 题（多选） ====================
答案：A、B、C
解析：Atlas A2/A3 使用 AIC/AIV 分离模式。AIC 是负责矩阵计算的 Cube Core，AIV 是负责矢量计算的 Vector Core，两者分别具有独立的 Scalar 调度单元。Vector 的源数据和目的数据位于 UB，而不是 L0C。

==================== 第 2 题（多选） ====================
答案：A、B、C
解析：CV 融合需要 Cube 与 Vector 之间存在直接数据依赖，中间结果能够分片传递，并且当前分片可以放入可用的片上缓冲区。融合前后必须保持数学语义等价，因此 D 错误。

==================== 第 3 题（判断） ====================
答案：错误
解析：CV 融合提供减少算子调度和组织分片流水的条件，实际收益仍受目标硬件、Shape、Tiling、片上空间以及 Cube/Vector 阶段耗时影响，需要在目标规格上测量。
