## 功能和接口

对输入 X 的每一行执行 softmax：m[i]=max_j X[i,j]，Y[i,j]=exp(X[i,j]-m[i])/sum_k exp(X[i,k]-m[i])。
输入为 Ascend NPU 上连续的二维 float32，全部元素有限且绝对值不超过 80。M 在 4 到 256 之间且是 4 的倍数；N 在 128 到 2048 之间且是 64 的倍数。
输出为新分配的连续二维 float32，shape、dtype、device 与输入相同；不得修改输入。仅前向，不要求梯度、原地输出或随机计算。
公开调用入口显式拒绝域外输入，dtype 不符采用 TypeError，其他输入约束采用 ValueError 并提供可识别原因。编译期 build(rows,cols) 与公开 run(x) 可分离；pytest 必须实际调用本地 NPU 实现。

## 参考与精度

使用 CPU 上 torch.softmax(X.double(),dim=1).float() 独立计算参考；每个输出元素 rtol=1e-4、atol=1e-6；行和与 1 的绝对误差不超过 1e-5；输入在调用前后精确不变。参考不调用被测 kernel，不放宽标准。
