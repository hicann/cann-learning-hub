# B0 源码语义成本模型（首次性能假设前）

每个 Y[i,j] 依赖完整第i行的最大值和指数和，不依赖其他行；列chunk不是可独立完成输出的task。M,N编译期固定。每元素1次减、1次exp、1次除法；每行max和sum各需N-1次二元合并（逻辑模型）。Cube=0；没有XOR、cast、逐元素整数除法/取模或数据相关分支。块级行偏移bx*N为每行固定计算，列向量偏移是64*k。

当前lowering对每个64元素块分别水平归约，再用vmax/vadd顺序合并块标量：每行2*(N/64)条水平归约；四段VF，m/s各一次标量UB写入与广播加载。max阶段初始化一次，sum阶段初始化一次。逐元素exp与normalize各遍历N/64个向量。

每行GM读4N、写4N，共8N字节。块级DMA一读一写。UB完整payload访问依次：GM写x、max读x、exp读x/写e、sum读e、normalize读e/写y、DMA读y，合计32N字节（不含m/s少量标量访问）；显式驻留x/e/y各4N，加m/s按32B对齐，共12N+64B。最多24640B，自动调度每行一次，无task内跨行迭代，buffer单版本。AIV72，逻辑block=M；M=4/64/68/256分别4/64/68/256任务，波次容量比0.0556/0.8889/0.9444/3.5556。

工作量可消除上界（非实测收益）：每行不变分母可从N次除法改为1次倒数+N次乘法；归约可由每chunk水平归约改为跨chunk向量累加后单次水平归约，减少2*(N/64-1)次水平归约；若寄存器生命周期允许，合并VF和中间e可减少完整UB payload读写，但须按具体lowering/寄存器压力验证。批量R行不减少元素数学工作，可将GM DMA/块级固定段次数从M组降为ceil(M/R)组，同时改变并行任务数和UB占用。上述是逻辑工作量而非加速比，须结合真实profiling才能排候选。
