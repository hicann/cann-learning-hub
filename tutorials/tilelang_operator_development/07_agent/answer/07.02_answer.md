# 7.2 练习解析

## 1. 从常数输入的预期形成测试

同一行有 N 个相等的值，减去该行最大值后都为 0；指数都为 1，分母为 N，所以每个输出为 1/N。这里依据的是数学定义。

测试可以构造一行 N 个相同的输入值，运行实际 kernel，再把每个输出元素与 1/N 按规定容差进行比较。也可以使用独立的 PyTorch reference 生成完整预期结果。

不可以只检查 shape。shape 只能说明输出维度和元素个数正确，无法证明元素值正确。即使 kernel 输出全为 0、结果算错或漏算尾部元素，shape 仍可能正确。

## 2. 最终门禁

最终门禁可以发现 ledger 中存在已经创建、却没有记录 `RESULT` 的候选。此时调优记录尚未闭环，门禁会阻止 Agent 直接宣布调优完成。
