## 2. 平台差异分析

| 维度 | CANNLab | 华为云沙箱 |
| --- | --- | --- |
| 环境准备 | 预置开发环境，适合快速开始 | 需要确认镜像、驱动和工具链配置 |
| 设备访问 | 由平台分配实验资源 | 可直接核对云主机中的 NPU 设备状态 |
| 主要用途 | 教学、开发和快速验证 | 真实设备验证与性能观察 |
| 复现要求 | 记录镜像模板与 Python 内核版本 | 记录实例规格、镜像和软件版本 |

## 3. 算子工程目录职责

```mermaid
flowchart LR
    A[输入与算子调用] --> H[op_host]
    H -->|参数校验与Tiling数据| K[kernel]
    K -->|计算结果| T[test]
    T -->|功能与精度检查| R[验证报告]
```

- `op_host`：完成算子注册、Shape 推导、dtype/format 约束和 Tiling 等 Host 侧逻辑。
- `op_kernel`：实现数据搬运和 Ascend C 核心计算逻辑。
- `test`：构造输入与基准结果，检查功能、精度和必要的性能指标。
- `CMakeLists.txt` 等构建文件：组织编译、打包和部署流程。

目录名称可能随 CANN 版本和生成参数变化，应以本次 `msopgen` 的实际输出为准。

## 4. 参考结论

CANNLab 的价值是降低环境准备成本并提高教学复现性；华为云沙箱的价值是让学习者核对真实 NPU、驱动和运行状态。两者应使用同一组版本记录、最小样例和检查项，形成可复验的环境报告。
