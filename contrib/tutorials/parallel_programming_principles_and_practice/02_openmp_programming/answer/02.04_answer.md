# 参考答案

CMake 通过 find_package(OpenMP) 检测并链接 OpenMP。若未找到，宏关闭 pragma 路径，程序仍可构建但 OpenMP backend 不会产生真实多线程加速。


## 参考实验操作

实验必须基于 `src/openmp_spmv/`。用 `bash scripts/build.sh` 构建；固定矩阵和 repeat，以 `OMP_NUM_THREADS`、`OMP_SCHEDULE` 做单变量组合；串行结果作为正确性和 speedup 基线。
