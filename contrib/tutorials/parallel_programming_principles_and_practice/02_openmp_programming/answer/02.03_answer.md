# 参考答案

原工程固定 16 线程和 static；课程副本在未设置环境变量时保持该默认值，并允许用 `OMP_NUM_THREADS`、`OMP_SCHEDULE` 做实验。Uniform 行长度接近时 static 低开销且均衡；long-tail 行长度差异大时 dynamic 可能改善均衡，但调度开销可能抵消收益。


## 参考实验操作

实验必须基于 `src/openmp_spmv/`。用 `bash scripts/build.sh` 构建；固定矩阵和 repeat，以 `OMP_NUM_THREADS`、`OMP_SCHEDULE` 做单变量组合；串行结果作为正确性和 speedup 基线。
