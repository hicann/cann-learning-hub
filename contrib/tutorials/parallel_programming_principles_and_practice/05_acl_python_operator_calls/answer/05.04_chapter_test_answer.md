# 5.4 参考答案

## 一、客观题

1. B。`acl.op.set_model_dir` 注册 ATC 生成的单算子 OM 目录，不加载整图模型。
2. H2D 是 Host→Device，D2H 是 Device→Host。算子异步提交，必须同步 Stream 后再读回结果。
3. AI CPU/tf_kernel，且 `aicore_accelerated=false`。
4. 错。导入成功和文件存在都不是当前真实设备执行证据。

## 二、简单题

- 调用入口：`acl.blas.gemm_ex`；
- A/B/output shape：`[32,128]`、`[128,64]`、`[32,64]`；
- 用 Event 统计重复算子平均时间；
- D2H 后执行：

```python
np.testing.assert_allclose(gemm_out, gemm_golden, atol=0.02, rtol=0)
```

## 三、中等题

- 调用入口：`acl.op.execute_v2("SparseTensorDenseMatMul", ...)`；
- indices/values/x/output shape：`[100,2]`、`[100]`、`[128,1]`、`[64,1]`；
- 坐标必须唯一且满足 `0 <= row < 64`、`0 <= col < 128`；
- D2H 后执行：

```python
np.testing.assert_allclose(spmv_out[:, 0], spmv_golden, atol=1e-3, rtol=0)
```

## 四、困难题

`run_gemm()` 与 `run_spmv()` 各自只保留一层 `try/finally`，完成“设备内存 → H2D →
算子提交 → Event/Stream 同步 → D2H → 校验 → 逆序释放”。统一 runner 先取得两份真实结果，
再调用 Notebook 中的 `write_validated_report()`；不要在 runner 开头预设 PASS。

最终 JSON 至少包含：

```json
{
  "schema_version": 1,
  "gemm": {"status": "PASS", "fallback": 0},
  "spmv": {
    "status": "PASS",
    "actual_backend": "AICPU/tf_kernel capability path on 910B3/CANN 9.0",
    "aicore_accelerated": false,
    "fallback": 0
  },
  "validation": "PASS"
}
```
