# 5.2 参考答案

将 `M, N, K` 设为 `32, 64, 128`，同步修改单算子描述中的 A、B、C/output shape。
`gemm_ex` 的 `M、N、K` 分别对应输出行数、输出列数和归约维，设备输出应为 `[32, 64]`。

Event 必须在同一 Stream 上包住重复的 `gemm_ex`，同步后用
`acl.rt.event_elapsed_time(start, end) / repeat` 得到平均设备时间。该时间不包含 ATC、H2D、D2H；
NumPy reference 另行计时。正确性至少检查：

```python
max_abs_error = float(np.max(np.abs(out.astype(np.float32) - golden.astype(np.float32))))
np.testing.assert_allclose(out, golden, atol=0.02, rtol=0)
```

报告中的实际入口写 `pyACL/acl.blas.gemm_ex device path`，不要仅凭 API 名称推断具体 Kernel 类别。
