# 参考答案

本章 Host C++ 与实验 3.2 OpenMP 使用鲲鹏毕昇 Host 编译器 `clang++`，MPI 使用 mpicxx wrapper，ACL 应用使用主机编译器并链接 CANN 库，Ascend C Kernel 使用 bisheng 或工程提供的 Ascend C CMake。


## 参考实验操作

实验必须基于 `src/`。先记录 `command -v`、版本和环境变量，再编译运行 `hello_host.cpp`；对 `hello_world.asc` 只在具备毕昇环境时编译，否则记录缺失条件。

分析时先判断退出码、正确性和可比性，再解释性能变化。若环境缺少 CANN、MPI 或多设备，应提交明确的诊断证据，不得把历史 CSV 冒充本机运行结果；参考答案不规定固定耗时。
