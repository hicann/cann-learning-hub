# 参考答案

官方使用 `clang -v` 验证鲲鹏毕昇 Host 编译器，是因为该独立安装包提供的命令名就是 `clang`/`clang++`；CANN `bisheng` 是另一条异构编译入口。

架构参数必须从目标环境的 `bisheng --help`、产品文档或官方样例取得。命令应包含源文件、实际架构和输出路径，不应复制其他硬件的架构值。


## 参考实验操作

实验必须基于 `src/`。先记录 `command -v`、版本和环境变量，再编译运行 `hello_host.cpp`；对 `hello_world.asc` 只在具备毕昇环境时编译，否则记录缺失条件。
