# 8.2 参考答案

- memcheck：DataCopy 长度超过 LocalTensor，核心诊断为 illegal write；
- racecheck：MTE2→Vector 缺少同步，核心诊断为 Potential RAW hazard；
- initcheck：未初始化数据被读取，核心诊断为 uninitialized read；
- synccheck：SetFlag 无对应 WaitFlag，核心诊断为 Unpaired set_flag；
- msDebug：断点命中 `AscendC::Add` 后，backtrace/frame/source 应共同指向当前 Kernel 源码位置。

独立 ASC 目标可直接使用 `target_compile_options`；标准算子工程必须通过 CANN 提供的 `add_ops_compile_options` 或 `npu_op_kernel_options` 给 Kernel 目标加选项。

故障程序的工具退出码必须原样记录，但不能只凭退出码判断成功。日志匹配 MODE 对应诊断时，实验状态为
`EXPECTED_DIAGNOSTIC`；修复后的未插桩 baseline 正常返回时才写 `PASS`。msDebug 缺少工具、开关或
`/dev/drv_debug` 读写权限时写 `BLOCKED`，不执行任何提权操作。
