# 参考答案

共性是 runtime、device memory、copy、stream、sync、reference、cleanup。GEMM 使用 aclTensor/workspace/executor；SpMV 使用 sparse handle/CSR/DnVec descriptors。


## 参考实验操作

实验必须基于 `src/acl_operator_calls/`。分别进入 `GEMM-acl`、`SpMV-acl` 执行 build/run；先确认输出是 real 还是 stub，再沿 `main.cpp` 标出创建、执行、同步、验证和释放位置。
