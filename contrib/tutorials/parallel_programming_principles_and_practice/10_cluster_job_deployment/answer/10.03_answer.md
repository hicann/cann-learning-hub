# 参考答案

环境变量适合显式外部依赖，相邻目录依赖工作区布局，网络 clone 依赖账号和网络；vendored dependency 固定版本、离线可用，最适合课程复现。


## 参考实验操作

实验必须基于 `src/ascend_xyce/`。确认 vendored backend 后离线 build；用环境变量和 `--matrix` 改一个配置；检查三种 solver 的 converged、residual、solution error，并保存 CSV/log。

建议记录表：

| Matrix | Solver | Linear/Simulation | Iterations | Residual | Converged | Error |
|---|---|---|---|---|---|---|
|  |

分析时先判断退出码、正确性和可比性，再解释性能变化。若环境缺少 CANN、MPI 或多设备，应提交明确的诊断证据，不得把历史 CSV 冒充本机运行结果；参考答案不规定固定耗时。
