# 2.3 参考答案

## 一、客观题

1. 每个 head 的 64 个通道拆成 32 个 even/odd pair，12 个 head 共 384 个 pair；输出再按相反顺序重排回 `[12,64]`。
2. Vector Core（AIV）。
3. SIMD 用向量指令批量处理 LocalTensor；SIMT 由一个线程处理一个 pair。
4. position=0 时旋转角为 0，所以 cos=1、sin=0，输出等于输入。
5. 错。模板文件不是编译、执行或正确性证据。

## 二、简单题

reference 直接使用：

```python
out_even = x_even * cos - x_odd * sin
out_odd = x_even * sin + x_odd * cos
```

position=0 时用 `assert_array_equal` 验证两份输出与输入完全一致。

## 三、中等题

SIMD 通过条件至少包含 `status=PASS`、`cases=4/4`、`max_error <= tolerance`、
`fallback=0`、`path=ASCENDC_SIMD_RTC` 和 `device_id=0`。其中程序只有在全部 case 满足
tolerance 时才返回 0；Notebook 再检查机器字段并输出 `REPORT_STATUS=PASS`。

## 四、困难题

只改变一个 tile/vector 参数，保持输入、4 个 position case、warmup、repeat、Device 和计时口径一致。
先比较正确性，再比较 `device_mean_us`。该字段是 Host 计得的 launch+sync 时间；若需要纯 Kernel
时间，应后续使用 profiler。没有同口径真机数据时只写 `DEFERRED`，不填固定性能数字。

SIMT 文件仍只是 Ascend 950 模板；必须在 950 上真实编译、执行并与相同 reference 比较。
