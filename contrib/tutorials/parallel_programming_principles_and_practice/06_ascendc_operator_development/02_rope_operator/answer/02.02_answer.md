# 2.2 参考答案

SIMD 由 Vector Core 对 LocalTensor 批量执行 `Mul/Sub/Add`；SIMT 由大量线程分别处理一个 pair。
两者的并行组织不同，但都必须按相同的 even/odd pair、cos/sin 和输出顺序实现同一 RoPE
数学语义，否则不能使用同一 reference 比较结果。

- `AIV_ONLY` 证明 SIMD Kernel 的任务类型是 Vector Core；
- `fallback=0` 证明本程序没有走预设 fallback；
- `device_id=0` 记录本次目标 Device，但不能单独证明结果正确；
- 910B3 的 `ROPE_RESULT status=PASS` 只覆盖 SIMD/AIV + RTC，不覆盖 Ascend 950 SIMT。
