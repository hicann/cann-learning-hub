# 参考答案

CSV 能支持历史耗时、误差、compression 和 partition 趋势；当前源码能证明 backend 接口、BF16 转换、主机分区循环和 persistent 生命周期。当前 FP32 正式路径有真实 Device API（`AscendCSpmvBackend` RTC 链，CSV `actual_backend=ascend_c`）；历史 CSV 的 persistent 计时来自旧 Host 实现，不能仅凭类名/字段名证明其来自 AI Core。


## 参考实验操作

实验必须基于 `src/ascend_spmv/`。构建运行 benchmark，沿 `ISpmvBackend` 追踪各实现；比较精度、partition、cold/warm 和误差；FP32 正式路径已有 Device API（`AscendCSpmvBackend`），FP16/BF16/persistent 无 Device 调用时只报告主机原型证据。
