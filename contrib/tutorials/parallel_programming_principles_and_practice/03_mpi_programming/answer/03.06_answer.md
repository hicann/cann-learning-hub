# 参考答案

有效报告需说明 slot、绑定策略、进程数、PASS、一次性 distribution 与 steady-state 的区别。无固定最佳进程数。


## 参考实验操作

实验必须基于 `src/mpi_spmv/`。先运行 `bash scripts/run.sh`，再用 `MPI_PROCESSES=1/2/4 bash scripts/run_mpi.sh`；从输出区分 compute、communication、total，并核对误差。

建议记录表：

| Ranks | Compute | Communication | Total | Balance | Error |
|---|---|---|---|---|---|
|  |

分析时先判断退出码、正确性和可比性，再解释性能变化。若环境缺少 CANN、MPI 或多设备，应提交明确的诊断证据，不得把历史 CSV 冒充本机运行结果；参考答案不规定固定耗时。

## 四类考核参考答案

### 1. 客观题

答案：（1）C。rank 2 负责 `[offset[2], offset[3])`，即 `[500, 750)`。（2）对。分到 0 行的 rank 不参与本地 SpMV 数值计算，但仍必须参与 collective 与最终校验，否则会导致通信卡死。

### 2. 简单题

处理方法：`cd src/mpi_spmv` → `bash scripts/build.sh`，然后分别 `MPI_PROCESSES=1/2/4 bash scripts/run_mpi.sh --matrix U1 --repeat 3 --csv results/U1_Np.csv` 并汇总表格。字段归属：Compute、Balance 来自 rank 本地计算计时与局部 nnz；Communication、Total 含 collective/同步计时；Error 为相对误差（PASS 门槛）。判定条件：命令可复现、Ranks/Total/Compute/Communication/Balance/Error 字段齐全、correctness=PASS、字段归属说明正确。

### 3. 中等题

处理方法：从 CSV/rank 日志读取每个 rank 的局部 nnz 与 compute 时间，计算不均衡度量（如 max/avg 或 (max-min)/avg）。行数均分只保证行数相同，不保证 nnz 相同；长尾矩阵中少数 rank 承担大部分非零元，其 compute 时间成为慢 rank，整体扩展性受最慢 rank 限制。证据字段：各 rank 的 local rows、local nnz、compute 时间。判定条件：给出计算过程与实测字段，结论把行数均分与 nnz 不均区分开。

### 4. 困难题

处理方法：把每次运行的 total 分解为一次性 distribution（首次数据划分/广播）、每轮 compute、每轮 communication 与同步；计算 communication 占比 = communication/total 随 rank 的变化。rank 增多时局部计算下降但通信次数/量通常上升，最优 rank 数出现在“继续分片收益 < 通信与同步代价”的交叉点。下一步单变量实验：固定矩阵与 repeat，只改变进程数（或只改变分区方式）重测并比较。判定条件：分解有字段依据、能指出最优 rank 数的限制因素，并给出只改一个变量的验证设计。
