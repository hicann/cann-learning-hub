## 第二部分 简单题（答案要点）

- 四步骤作用：基线记录未修改版本的运行时间与正确性；受控/公平比较保证比较口径公平——Dis-GMRES 用单变量实验（一次只改一个变量），MuduoXinyu 是固定模型、输入、解码参数、环境和统计口径下的复合实现包 A/B（同时改变算子组织与 dtype），结论只能归因于整体实现包；正确性门禁确保性能数据以正确实现为前提；性能判定用同等条件下的多次测量给出收益结论。
- MuduoXinyu 功能门禁至少包含：token exact 一致性检查、fallback 路径检查、算子调用计数检查（≥2 项即可）。

## 第三部分 中等题（答案要点）

- Dis-GMRES profiling 关键指标：AI Core 热点（SpMV/Dot/AXPY 执行时间与占比）、Host 控制开销、通信耗时。单变量实验示例：仅切换 SpMV 后端而保持输入、迭代数与通信方式不变；正确性门禁为 NPU 结果与参考一致；性能判定以多次统计为准（如 1 次预热 + 3 次统计）。
- MuduoXinyu 公平 A/B 步骤：相同环境与输入（固定模型、输入、解码参数与统计口径）、Path A 与 Path B 各自 1 次预热 + 3 次统计、用同一指标（如每 token 耗时）比较。A/B 同时改变算子组织与 dtype，结论只能归因于整体实现包。若新实测 B vs A 为负值，如实报告性能回退与 `performance_beneficial=false`，不得包装为优化成功。

## 第四部分 困难题（答案要点与通过标准）

- 方案一：报告需给出 profiling 证据（热点排名与占比）、单变量实验前后数据与正确性门禁结果；结论限定在 world1 边界内，不得声称 HCCL 2/4/8 卡结论。
- 方案二：报告需给出功能门禁结果与 A/B 统计表；如实记录本轮 Atlas A3 实测值（Path B 相对 Path A 为 `+2.24176969162644%`、`performance_valid=true`、`performance_beneficial=true`；若新环境实测为负值则记录负值与 `performance_beneficial=false`）；结论如实描述，不把负性能包装为优化成功。
- 通过标准：证据链完整；负性能如实报告；结论与实验条件一致，没有声称未验证项已通过。
