# 参考答案

当前 Device 路径把局部向量放入全局 Device buffer，经 HCCL AllReduce 形成全局 v；local SpMV 计算 w，Dot/Norm 的局部结果再经 AllReduce 成为全局量，AXPY 更新正交向量。AllGather 计数在当前 Device 路径为 0；kernel launch 反映 Ascend C RTC kernel 的 Host 提交开销。
