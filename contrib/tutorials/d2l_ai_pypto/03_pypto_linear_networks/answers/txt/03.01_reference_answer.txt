练习3.1.1

假设我们有一些数据 x_1, ..., x_n in R。我们的目标是找到一个常数b，使得最小化 sum_i (x_i - b)^2。

1. 找到最优值b的解析解。
2. 这个问题及其解与正态分布有什么关系？

  解答

    第1问：
    
    首先，最优值的b满足 (d sum_i (x_i - b)^2)/(d b) = 0，求b的导数：
    接着，可以将左边的式子进行化简：
    
    (d sum_i (x_i - b)^2)/(d b) = 2 sum_i (x_i - b)
    = 2 (sum_i x_i - n b)
    = 2 n (mean(x) - b)
    
    mean(x) 是 x_1, ..., x_n 的平均值。因此当且仅当 b = mean(x) 时，sum_i (x_i - b)^2 最小。

    第2问：
    
    假设 x_1, ..., x_n 是从正态分布中采样得到的，那么 b = mean(x) 是最大似然估计下的均值。也就是说，如果假设数据来自正态分布，并且想要找到一个最好的均值来描述这些数据，那么可以选择样本均值作为估计量。
    
    所以，该问题及其解与 x_1, ..., x_n 符合正态分布相关。


练习3.1.2

推导出使用平方误差的线性回归优化问题的解析解。为了简化问题，可以忽略偏置b（我们可以通过向 X 添加所有值为1的一列来做到这一点）。

1. 用矩阵和向量表示法写出优化问题（将所有数据视为单个矩阵，将所有目标值视为单个向量）。
2. 计算损失对w的梯度。
3. 通过将梯度设为0、求解矩阵方程来找到解析解。
4. 什么时候可能比使用随机梯度下降更好？这种方法何时会失效？

  解答

    第1问：
    
    对于线性回归问题，损失函数是平方误差。假设我们有一个数据集 {(x_1, y_1), ..., (x_n, y_n)}，其中 x_i in R^d 是输入特征，y_i in R 是标签。我们的目标是找到一组权重向量 w in R^d，使得预测值 y^_i = w^T x_i（忽略偏置b）与真实标签 y_i 之间的平方误差最小化。因此，损失函数可以写成以下形式：
    
    L(w) = (1)/(2n) sum_i=1^n (y^_i - y_i)^2 = (1)/(2n) || X w - y ||_2^2
    
    其中 X = [x_1^T, ..., x_n^T]^T 是输入特征的矩阵，y = [y_1, ..., y_n]^T 是标签向量。
    
    则线性回归优化问题可以写成：
    min_w (1)/(2n) || X w - y ||_2^2
    
    第2问：
    
    损失函数对权重向量 w 的梯度为：
    
    grad_w L(w) = (1)/(n) sum_i=1^n (y^_i - y_i) grad_w y^_i = (1)/(n) sum_i=1^n (y^_i - y_i) x_i
    
    其中 y^ = [y^_1, ..., y^_n]^T 是预测值向量。
    
    第3问：
    
    根据题意，将梯度设为0，可得：
    
    grad_w L(w) = (1)/(n) X^T (y^ - y) = 0
    其中，y^ 是预测值，y 是真实值，X 是输入数据。将上式变形为：
    
    X^T (y^ - y) = 0
    进一步变形得到：
    
    X^T y^ = X^T y
    因为 y^ = X w，所以：
    
    X^T (y^ - y) = 0
    => X^T (X w - y) = 0
    => w = (X^T X)^(-1) X^T y
    
    第4问：
    
    当数据集较小时，解析解可能比随机梯度下降更好。然而，在大型数据集上，计算解析解可能会非常耗时。此外，当矩阵 X^T X 不可逆时，解析解不存在。在这种情况下，需要使用正则化或数值优化方法。
