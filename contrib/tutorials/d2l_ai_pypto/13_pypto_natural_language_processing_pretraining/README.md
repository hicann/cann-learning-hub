# 第13章 pypto 自然语言处理：预训练

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 13 章，介绍使用 pypto 在昇腾 NPU 上实现自然语言处理的预训练方法，涵盖 word2vec、近似训练、预训练词嵌入的数据集、GloVe、子词嵌入、词的相似性和类比任务及 BERT 预训练。
