# 第9章 pypto 现代循环神经网络

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 9 章，介绍使用 pypto 在昇腾 NPU 上实现现代循环神经网络，涵盖门控循环单元（GRU）、长短期记忆网络（LSTM）、深度循环神经网络、双向循环神经网络、机器翻译与数据集、编码器-解码器架构、序列到序列学习（seq2seq）及束搜索。
