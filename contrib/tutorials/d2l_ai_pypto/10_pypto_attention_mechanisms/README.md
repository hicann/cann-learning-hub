# 第10章 pypto 注意力机制

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 10 章，介绍使用 pypto 在昇腾 NPU 上实现注意力机制，涵盖注意力提示、注意力汇聚（Nadaraya-Watson 核回归）、注意力评分函数、Bahdanau 注意力、多头注意力、自注意力与位置编码及 Transformer。
