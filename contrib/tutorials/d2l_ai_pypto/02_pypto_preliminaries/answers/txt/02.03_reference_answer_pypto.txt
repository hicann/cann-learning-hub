练习 1
证明一个矩阵 A 的转置的转置是 A，即 (A^T)^T = A。

  解答
    PyPTO 编程验证：
    @pypto.frontend.jit(runtime_options={"run_mode": pypto.RunMode.NPU})
    def practice01_kernel(out: pypto.Tensor([], pypto.DT_BOOL)):
        pypto.set_vec_tile_shapes(5, 8)
        A = pypto.arange(20.0).reshape([5, 4])
        out.move(pypto.eq(A, A.transpose(0, 1).transpose(0, 1)))

    out = torch.zeros((5, 4), dtype=torch.bool, device="npu:0")
    practice01_kernel(out)
    print("PyPTO 验证结果:\n", out.cpu().numpy())


练习 2
给出两个矩阵 A 和 B，证明 A^T + B^T = (A + B)^T。

  解答
    PyPTO 编程验证：
    @pypto.frontend.jit(runtime_options={"run_mode": pypto.RunMode.NPU})
    def practice02_kernel(a: pypto.Tensor([], pypto.DT_FP32),
                          b: pypto.Tensor([], pypto.DT_FP32),
                          out: pypto.Tensor([], pypto.DT_BOOL)):
        pypto.set_vec_tile_shapes(5, 8)
        out.move(pypto.eq(a.transpose(0, 1) + b.transpose(0, 1), (a + b).transpose(0, 1)))

    A = torch.rand(4, 4, dtype=torch.float32, device="npu:0")
    B = torch.rand(4, 4, dtype=torch.float32, device="npu:0")
    out = torch.zeros((4, 4), dtype=torch.bool, device="npu:0")
    practice02_kernel(A, B, out)
    print("PyPTO 验证结果:\n", out.cpu().numpy())


练习 3
给定任意方阵 A，A + A^T 总是对称的吗？为什么？

  解答
    解析证明：(A + A^T)^T = A^T + (A^T)^T = A^T + A = A + A^T。
    因此给定任意方阵 A，A + A^T 恒为对称矩阵。

练习 6
运行 A / A.sum(axis=1)，看看会发生什么。请分析一下原因？

  解答
    PyPTO 中带 keepdim=True 的广播除法验证：
    @pypto.frontend.jit(runtime_options={"run_mode": pypto.RunMode.NPU})
    def practice06_kernel(a: pypto.Tensor([], pypto.DT_FP32),
                          out: pypto.Tensor([], pypto.DT_FP32)):
        pypto.set_vec_tile_shapes(5, 8)
        out.move(pypto.div(a, a.sum(dim=1, keepdim=True)))

    A = torch.arange(20.0, dtype=torch.float32, device="npu:0").reshape(5, 4)
    out = torch.zeros((5, 4), dtype=torch.float32, device="npu:0")
    practice06_kernel(A, out)
    print("PyPTO 验证结果:\n", out.cpu().numpy())


练习 7
考虑一个具有形状 (2, 3, 4) 的张量，在轴 0、1、2 上的求和输出是什么形状？

  解答
    PyPTO 验证多轴求和：
    @pypto.frontend.jit(runtime_options={"run_mode": pypto.RunMode.NPU})
    def practice07_kernel(a: pypto.Tensor([], pypto.DT_FP32),
                          out0: pypto.Tensor([], pypto.DT_FP32),
                          out1: pypto.Tensor([], pypto.DT_FP32),
                          out2: pypto.Tensor([], pypto.DT_FP32)):
        pypto.set_vec_tile_shapes(2, 3, 8)
        out0.move(pypto.sum(a, dim=0))
        out1.move(pypto.sum(a, dim=1))
        out2.move(pypto.sum(a, dim=2))

    A = torch.arange(24, dtype=torch.float32, device="npu:0").reshape(2, 3, 4)
    out0 = torch.zeros((3, 4), dtype=torch.float32, device="npu:0")
    out1 = torch.zeros((2, 4), dtype=torch.float32, device="npu:0")
    out2 = torch.zeros((2, 3), dtype=torch.float32, device="npu:0")
    practice07_kernel(A, out0, out1, out2)
    print("out0.shape:", out0.shape)
    print("out1.shape:", out1.shape)
    print("out2.shape:", out2.shape)


练习 8
为 linalg.norm 函数提供 3 个或更多轴的张量，并观察其输出。对于任意形状的张量这个函数计算得到什么？

  解答
    PyPTO 实现沿指定轴计算 L2 范数 sqrt(sum(x^2, dim))：
    @pypto.frontend.jit(runtime_options={"run_mode": pypto.RunMode.NPU})
    def practice08_kernel(x: pypto.Tensor([2, 3, 4], pypto.DT_FP32),
                          out0: pypto.Tensor([3, 4], pypto.DT_FP32),
                          out1: pypto.Tensor([2, 4], pypto.DT_FP32),
                          out2: pypto.Tensor([2, 3], pypto.DT_FP32)):
        pypto.set_vec_tile_shapes(2, 3, 8)
        x_sq = pypto.mul(x, x)
        out0.move(pypto.sqrt(pypto.sum(x_sq, dim=0)))
        out1.move(pypto.sqrt(pypto.sum(x_sq, dim=1)))
        out2.move(pypto.sqrt(pypto.sum(x_sq, dim=2)))
