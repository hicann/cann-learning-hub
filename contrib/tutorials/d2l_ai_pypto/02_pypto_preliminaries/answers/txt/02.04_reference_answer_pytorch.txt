微积分

练习2.4.1

绘制函数 y = f(x) = x^3 - 1/x 和其在 x = 1 处切线的图像。

  解答

    解析计算：
    f(1) = 1^3 - 1/1 = 0
    f'(x) = 3 x^2 + 1/x^2
    f'(1) = 3(1)^2 + 1/(1)^2 = 4
    切线方程：y = 4(x - 1) + 0 = 4x - 4

    NumPy / Matplotlib 绘图：
    import numpy as np
    import matplotlib.pyplot as plt

    x_np = np.arange(0.1, 2.0, 0.01)
    y_np = x_np ** 3 - 1.0 / x_np
    y_tangent = 4.0 * (x_np - 1.0)

    plt.plot(x_np, y_np, label='f(x)')
    plt.plot(x_np, y_tangent, '--', label='Tangent line at x=1')
    plt.legend()
    plt.xlabel('x')
    plt.ylabel('y')
    plt.show()


练习2.4.2

求函数 f(x) = 3 x_1^2 + 5 e^{x_2} 的梯度。

  解答

    根据梯度的定义：
    partial f / partial x_1 = 6 x_1
    partial f / partial x_2 = 5 e^{x_2}
    梯度 grad f(x) = (6 x_1, 5 e^{x_2})

    PyTorch autograd 验证：
    import torch
    x_torch = torch.arange(2.0, requires_grad=True)
    y_torch = 3 * x_torch[0] ** 2 + 5 * torch.exp(x_torch[1])
    y_torch.backward()
    print("梯度 grad f(x):", x_torch.grad)


练习2.4.3

函数 f(x) = ||x||_2 的梯度是什么？

  解答

    根据 2-范数定义：f(x) = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
    偏导数：partial f / partial x_i = x_i / sqrt(sum_j x_j^2) = x_i / ||x||_2
    梯度 grad f(x) = x / ||x||_2

    PyTorch autograd 验证：
    import torch
    x_torch = torch.arange(4.0, requires_grad=True)
    y_torch = torch.dot(x_torch, x_torch).sqrt()
    y_torch.backward()
    print("梯度 grad f(x):", x_torch.grad)


练习2.4.4

尝试写出函数 u = f(x, y, z)，其中 x = x(a, b)，y = y(a, b)，z = z(a, b) 的链式法则。

  解答

    根据多元微积分链式求导法则：
    partial u / partial a = (partial u / partial x)(partial x / partial a) + (partial u / partial y)(partial y / partial a) + (partial u / partial z)(partial z / partial a)
    partial u / partial b = (partial u / partial x)(partial x / partial b) + (partial u / partial y)(partial y / partial b) + (partial u / partial z)(partial z / partial b)
