# 第4章 多层感知机
## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 4 章，使用 pypto 框架在昇腾 NPU 上实现。涵盖多层感知机、过拟合与欠拟合、正则化技术（权重衰减、暂退法）、数值稳定性与参数初始化等关键主题。
