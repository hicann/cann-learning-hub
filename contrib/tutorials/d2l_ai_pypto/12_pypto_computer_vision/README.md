# 第12章 计算机视觉

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 12 章，使用 PyPTO 框架在昇腾 NPU 上实现计算机视觉中的核心任务，涵盖图像增广与微调、目标检测（边界框、锚框、多尺度检测、SSD 与 R-CNN 系列）、语义分割与转置卷积、全卷积网络（FCN）以及神经风格迁移。
