### 练习11.2.1
假设我们想要通过绘制集合内点之间的所有直线并检查这些直线是否包含来验证集合的凸性。

i. 证明只检查边界上的点是充分的。

ii. 证明只检查集合的顶点是充分的。

**解答：**

i. 设闭集 C 中任意两边界点的连线都含于 C。任取 a,b∈ C，过它们的直线交边界于 p,q，则 [a,b]⊆[p,q]⊆ C，故 C 凸。

ii. 多面体是其顶点的凸包 P=conv(v₁,…,vₖ)。对任意 x,y∈ P，写 x=Σᵢαᵢvᵢ、y=Σᵢβᵢvᵢ（αᵢ,βᵢ≥0，各自和为 1），则

tx+(1-t)y=Σᵢ(tαᵢ+(1-t)βᵢ)vᵢ∈ P,

故 P 凸，其凸性由顶点完全决定。

### 练习11.2.2
用p-范数表示半径为r的球，证明

Bₚ[r]:=x| x∈ Rᵈ and ‖x‖ₚ ≤ r

对所有 p≥ 1 是凸集。

**解答：**

在这个问题中，我们需要证明，对于所有的p范数，半径为r的球的凸集性。p‑范数形式的说明如下：

‖x‖ₚ = (Σᵢ₌₁ⁿ |xᵢ|ᵖ)^((1)/(p))

其中 x ∈ Rⁿ 是一个n维向量，p ≥ 1。

要证明一个集合是凸（convex）的，我们需要满足以下条件：对于该集合中的任意两点，将这两点连接起来形成的线段也在该集合中。

对于定义的集合 Bₚ[r]，如果 x,y ∈ Bₚ[r]，我们需要证明在 0 ≤ t ≤ 1 的任意情况下，tx + (1-t)y ∈ Bₚ[r]。这里，tx + (1-t)y 表示x和y之间的一条线段。

由于x和y满足p-范数小于或等于r，我们有 ‖x‖ₚ ≤ r 和 ‖y‖ₚ ≤ r。

根据t，我们可以得到：

aligned ‖tx + (1 - t)y‖ₚ &≤ t‖x‖ₚ + (1 - t)‖y‖ₚ &≤ tr + (1 - t)r = r aligned

最后一步我们用到的是三角不等式，这里‖·‖ₚ是一个范数，所以满足三角不等式。

因此，我们证明了对于所有的 p ≥ 1，集合 Bₚ[r] 是凸的。

### 练习11.2.3
已知凸函数f和g表明max(f, g)也是凸函数。证明min(f, g)是非凸的。

**解答：**

在这个问题中中，我们需要分析最大函数（max）和最小函数（min）的凸性质。

首先，我们来分析最大函数的凸性。假设 f 和 g 是凸函数，我们需要证明 max(f,g) 也是凸函数。

对于任意的 x₁,x₂∈R 和 0≤ t≤ 1，我们有：

max(tf(x₁)+(1-t)f(x₂), tg(x₁)+(1-t)g(x₂))

我们可以将其拆分为两个部分：
1. max(tf(x₁), tg(x₁))
2. max((1-t)f(x₂), (1-t)g(x₂))

对于第一部分，由于 f 和 g 是凸函数，我们有：

tf(x₁)+(1-t)f(x₂) ≤ f(tx₁+(1-t)x₂), tg(x₁)+(1-t)g(x₂) ≤ g(tx₁+(1-t)x₂)

因此，

max(tf(x₁),tg(x₁)) ≤ max(f(tx₁+(1-t)x₂),g(tx₁+(1-t)x₂))

对于第二部分，我们可以进行类似的推导。

综上所述，我们有：

max(tf(x₁)+(1-t)f(x₂), tg(x₁)+(1-t)g(x₂)) ≤ max(f(tx₁+(1-t)x₂),g(tx₁+(1-t)x₂))

因此，我们证明了最大函数 max(f,g) 是凸函数。

接下来，我们来证明最小函数 min(f,g) 是非凸的。

假设 f(x)=x 和 g(x)=-x，我们可以看到 f 和 g 都是凸函数，因为它们的二阶导数恒为零。

然而，min(f,g)=min(x,-x)=-|x|，这是一个非凸函数。

因此，我们证明了最小函数 min(f,g) 是非凸的。

### 练习11.2.4
证明Softmax函数的规范化是凸的，即f(x) = log Σᵢ exp(xᵢ)的凸性。

**解答：**

记 sᵢ=softmax(xᵢ)=(e^(xᵢ))/(Σⱼ e^(xⱼ))，则 Σᵢ sᵢ=1。

一阶导：(∂ f)/(∂ xᵢ)=sᵢ。

Hessian：(∂² f)/(∂ xᵢ∂ xⱼ)=sᵢ(δᵢⱼ-sⱼ)，即 H=diag(s)-ssᵀ。对任意 z，

zᵀ Hz=Σᵢ sᵢ zᵢ²-(Σᵢ sᵢ zᵢ)²≥ 0,

因由 Cauchy–Schwarz（取 aᵢ=√(sᵢ)、bᵢ=√(sᵢ)zᵢ）有 (Σᵢ sᵢ zᵢ)²≤(Σᵢ sᵢ)(Σᵢ sᵢ zᵢ²)=Σᵢ sᵢ zᵢ²。故 H≽ 0，f 凸。

### 练习11.2.5
证明线性子空间X = x | W x = b是凸集。

**解答：**

假设X非空，即存在至少一个解x满足Wx = b。这可以通过选择x = W⁻¹b来实现，其中W⁻¹表示W的逆矩阵，我们选择任意两个解x₁和x₂，满足Wx₁ = b和Wx₂ = b。

我们选择介于x₁和x₂之间的向量y，可以表示为y = λ x₁ + (1-λ)x₂，其中0 ≤ λ ≤ 1。

证明Wy = b过程如下：

Wy = W(λ x₁ + (1-λ)x₂)

由于Wx₁ = b和Wx₂ = b，可以得到：

Wy = λ Wx₁ + (1-λ)Wx₂ = λ b + (1-λ)b = b

因此，对于任意介于x₁和x₂之间的向量y，都有Wy = b。

根据凸集的定义，我们证明了对于任意两个解x₁和x₂，以及介于x₁和x₂之间的向量y，都有Wy = b。因此，线性子空间X=x| Wx=b是凸集。

### 练习11.2.6
证明在线性子空间b = 0的情况下，对于矩阵M的投影Proj X可以写成M X。

**解答：**

设 X=Mz|z∈ℝᵏ 为 M 的列空间（b=0 时为过原点的子空间）。v 到 X 的投影是其中与 v 最近的点：

min_z‖v-Mz‖².

对 z 求导令其为零：Mᵀ(v-Mz)=0，M 列满秩时

z*=(Mᵀ M)⁻¹Mᵀv, Proj_X(v)=Mz*=M(Mᵀ M)⁻¹Mᵀv.

记系数 X=z*，则投影可写作 MX。

### 练习11.2.7
证明对于凸二次可微函数f，对于ξ ∈ [0, ε]，我们可以写成f(x + ε) = f(x) + ε f'(x) + (1)/(2) ε² f''(x + ξ)。

**解答：**

这是带 Lagrange 余项的 Taylor 公式，对任意二次可微函数成立，不依赖凸性。

由带积分余项的展开

f(x+ε)=f(x)+ε f'(x)+∫ₓ^(x+ε)(x+ε-t)f''(t)dt.

f'' 连续，由积分中值定理存在 ξ∈[0,ε] 使

∫ₓ^(x+ε)(x+ε-t)f''(t)dt=f''(x+ξ)∫ₓ^(x+ε)(x+ε-t)dt=(1)/(2)ε² f''(x+ξ),

其中 ∫ₓ^(x+ε)(x+ε-t)dt=(1)/(2)ε²。代入即得。

### 练习11.2.8
给定一个凸集X和两个向量x和y证明了投影不会增加距离，即‖x - y‖ ≥ ‖Proj_X(x) - Proj_X(y)‖。

**解答：**

记 p=Proj_X(x)、q=Proj_X(y)。投影的变分刻画为：p∈ X 且对任意 z∈ X

⟨x-p,z-p⟩≤0.

分别取 z=q、z=p 得

⟨x-p,q-p⟩≤0, ⟨y-q,p-q⟩≤0.

于是

‖p-q‖²=⟨x-y,p-q⟩+⟨p-x,p-q⟩_≤0+⟨y-q,p-q⟩_≤0≤⟨x-y,p-q⟩≤‖x-y‖‖p-q‖,

两边除以 ‖p-q‖ 得 ‖p-q‖≤‖x-y‖。
