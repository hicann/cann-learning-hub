# 第7章 现代卷积神经网络

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 7 章，使用 PyPTO 框架在昇腾 NPU 上实现现代卷积神经网络，按历史时间顺序介绍 AlexNet、VGG、NiN、GoogLeNet、批量规范化、残差网络（ResNet）和稠密连接网络（DenseNet）等经典架构。
