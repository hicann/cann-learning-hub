8.7 通过时间反向传播 练习参考答案

练习8.7.1

对称矩阵的幂迭代性质。

假设我们拥有一个对称矩阵 M ∈ R^{n×n}，其特征值为 λ_i，对应的特征向量是 v_i（i = 1, ..., n）。假设特征值的序列顺序为 |λ_i| ≥ |λ_{i+1}|。

解答：

1a. 证明 M^k 拥有特征值 λ_i^k

设 λ_i 是 M 的特征值，v_i 是对应特征向量，即 M v_i = λ_i v_i。使用数学归纳法证明：

- 当 k=1 时：M^1 v_i = λ_i v_i = λ_i^1 v_i，成立。

- 归纳假设：假设 M^{k-1} v_i = λ_i^{k-1} v_i 成立。

- 归纳步骤：
  M^k v_i = M · M^{k-1} v_i
          = M · (λ_i^{k-1} v_i)        (由归纳假设)
          = λ_i^{k-1} (M v_i)          (常数提出)
          = λ_i^{k-1} · λ_i v_i        (由特征值定义 M v_i = λ_i v_i)
          = λ_i^k v_i

因此 M^k 拥有特征值 λ_i^k，且对应的特征向量仍为 v_i。得证。

1b. 证明对于一个随机向量 x ∈ R^n，M^k x 有较高概率与 M 的特征向量 v_1 在一条直线上（共线）。

由于 M 是对称矩阵，其特征向量 {v_1, v_2, ..., v_n} 构成 R^n 的一组正交基。因此任意向量 x ∈ R^n 可以唯一表示为特征向量的线性组合：

  x = c_1 v_1 + c_2 v_2 + ... + c_n v_n

对于随机向量 x，通常所有系数 c_i ≠ 0（概率为 1）。

将 M^k 作用于 x：

  M^k x = M^k (c_1 v_1 + c_2 v_2 + ... + c_n v_n)
        = c_1 M^k v_1 + c_2 M^k v_2 + ... + c_n M^k v_n
        = c_1 λ_1^k v_1 + c_2 λ_2^k v_2 + ... + c_n λ_n^k v_n

提取 λ_1^k：

  M^k x = λ_1^k [c_1 v_1 + c_2 (λ_2/λ_1)^k v_2 + ... + c_n (λ_n/λ_1)^k v_n]

由于特征值按模排序 |λ_1| ≥ |λ_2| ≥ ... ≥ |λ_n|，且通常 |λ_1| > |λ_2|（非退化情况），对于 i ≥ 2：

  lim_{k→∞} (λ_i/λ_1)^k = 0

因此当 k 足够大时：

  M^k x ≈ λ_1^k c_1 v_1 ∝ v_1

即 M^k x 收敛到主特征向量 v_1 的方向。这就是幂迭代法（Power Iteration）的数学原理。

1c. 上述结果对于循环神经网络中的梯度意味着什么？

在 RNN 的 BPTT（Back-Propagation Through Time）中，从时间步 T 到时间步 t 的梯度传递需要经过 Jacobian 矩阵的连乘：

  ∂L/∂h_t = ∂L/∂h_T · ∏_{k=t}^{T-1} J_k

其中 J_k = ∂h_{k+1}/∂h_k 为第 k 步隐状态对第 k+1 步隐状态的 Jacobian。

在平稳假设下（即假设权重矩阵不随时间步变化），J_k 近似为同一矩阵 W 的某种变换形式，梯度在反向传播中近似于：

  ∂L/∂h_t ≈ ∂L/∂h_T · W^{T-t}

根据 1a 和 1b 的结论：

(1) 梯度爆炸与梯度消失：
    - 若 W 的最大特征值模 |λ_1| > 1 → W^{T-t} 中特征值以指数级增长 → 梯度指数级爆炸
    - 若 |λ_1| < 1 → W^{T-t} 中特征值以指数级衰减 → 梯度指数级消失

(2) 梯度方向退化：
    - 由 1b 可知，当 T-t 较大时，W^{T-t} 在任意输入向量的作用下，其输出方向会收敛到 W 的最大特征值对应的特征向量 v_1 的方向
    - 这意味着：不同的输入序列经过长程 BPTT 后，产生的梯度方向会高度相似（都趋向 v_1 方向）
    - 后果：不同时间步的参数更新方向高度相关 → 所有参数被同向更新 → 学习效率低下 → 难以捕获多样化的长距离依赖模式

练习8.7.2

除了梯度裁剪，应对循环神经网络中梯度爆炸的其他方法。

解答：

1. 权重正则化：
   - L2 正则化：限制权重矩阵的 Frobenius 范数，防止权重过大
   - 谱正则化：直接限制权重矩阵的最大奇异值（谱范数 ≤ 1），从源头控制特征值的模，有效防止梯度爆炸

2. 激活函数选择：
   - ReLU：正半轴导数为 1，不会放大梯度，但负半轴导数 = 0 可能导致梯度消失
   - tanh：饱和区导数趋近于 0，可能加剧梯度消失
   - LeakyReLU / ELU：在负半轴也有小梯度，可缓解梯度消失

3. 更好的架构设计：
   - LSTM (Long Short-Term Memory)：通过输入门、遗忘门、输出门控制信息流，Cell State 提供梯度传播的"高速公路"
   - GRU (Gated Recurrent Unit)：LSTM 的简化版，仅含更新门和重置门
   - 残差连接 (Residual Connection)：提供梯度直接传播的路径，避免连续矩阵乘法
   - Layer Normalization：对每层输出做归一化，稳定训练过程，已经在 Transformer 中证明其有效性

4. 更好的参数初始化：
   - Xavier (Glorot) 初始化：使得前向传播和反向传播的各层方差保持一致
   - 正交初始化 (Orthogonal Initialization)：使权重矩阵特征值模 ≈ 1，避免梯度指数级变化，是 RNN 非常推荐的初始化策略

5. 训练技巧：
   - 截断 BPTT (Truncated BPTT)：只回传固定步数（如 35 步）的梯度，将长序列切分为多个子序列分别训练
   - 自适应优化器 (Adam, RMSProp)：动态调整每个参数的学习率，可缓解梯度尺度不一致的问题
   - 学习率衰减：随训练进程逐步降低学习率，稳定收敛

6. 混合精度训练：
   - 使用 fp16 计算 + fp32 权重累积，配合 loss scaling 技术处理 fp16 动态范围的限制

- NPU 场景：PyPTO 通过 pypto.RunMode 支持 NPU 原生精度控制，fp16+fp32 混合训练配合 loss scaling 处理动态范围限制。
