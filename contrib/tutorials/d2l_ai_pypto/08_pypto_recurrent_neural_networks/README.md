# 第8章 pypto 循环神经网络

## 章节概述
本章内容改编自 [Dive into Deep Learning](https://zh.d2l.ai/) 第 8 章，介绍使用 pypto 在昇腾 NPU 上实现循环神经网络（RNN），涵盖序列模型、文本预处理、语言模型、从零实现与简洁实现、以及通过时间反向传播（BPTT）。
