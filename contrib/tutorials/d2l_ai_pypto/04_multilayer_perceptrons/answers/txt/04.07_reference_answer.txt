练习4.7.2

向本节中描述的模型的隐藏层添加偏置项（不需要在正则化项中包含偏置项）。

1. 画出相应的计算图。
2. 推导正向和反向传播方程。

解答：

1.（计算图可参考本章正文。）
2. 正向传播按计算图的顺序逐项计算：

ẑ = W^(1) x          （第一层线性变换）
z = b^(1) + ẑ         （加上偏置）
h = φ(z)              （激活函数）
ô = W^(2) h           （第二层线性变换）
o = b^(2) + ô         （加上偏置）
L = l(o, y)           （计算损失）
s = λ/2 (‖W^(1)‖_F^2 + ‖W^(2)‖_F^2)  （正则化项）
J = L + s             （目标函数）

反向传播方程：

反向传播的目的是计算梯度 ∂J/∂W^(1)、∂J/∂W^(2)、∂J/∂b^(1)、∂J/∂b^(2)。

前两个式子和本章正文中给出的相同。

∂J/∂W^(1)
= (∂J/∂z) · (∂z/∂W^(1)) + (∂J/∂s) · (∂s/∂W^(1))
= ∂J/∂z · x^T + λ W^(1)。

∂J/∂W^(2)
= (∂J/∂o) · (∂o/∂W^(2)) + (∂J/∂s) · (∂s/∂W^(2))
= ∂J/∂o · h^T + λ W^(2)。

详细的求导过程可参考本章正文。

第一步是计算目标函数J=L+s相对于损失项L和正则项s的梯度。
∂J/∂L = 1，∂J/∂s = 1。
接下来，我们根据链式法则计算目标函数关于输出层变量o的梯度：
∂J/∂o
= (∂J/∂L) · (∂L/∂o)
= ∂L/∂o
∈ ℝ^q。

接下来，计算正则化项相对于两个参数的梯度：
∂s/∂W^(1) = λ W^(1)，∂s/∂W^(2) = λ W^(2)。

现在可以计算最接近输出层的模型参数的梯度
∂J/∂W^(2) ∈ ℝ^{q×h}。
使用链式法则得出：
∂J/∂W^(2) = (∂J/∂o) · (∂o/∂W^(2)) + (∂J/∂s) · (∂s/∂W^(2)) = ∂J/∂o · h^T + λ W^(2)。
为了获得关于W^(1)的梯度，我们需要继续沿着输出层到隐藏层反向传播。
关于隐藏层输出的梯度 ∂J/∂h ∈ ℝ^h 由下式给出：
∂J/∂h
= (∂J/∂o) · (∂o/∂h)
= W^(2)^T ∂J/∂o。

由于激活函数 φ 是按元素计算的，
计算中间变量 z 的梯度 ∂J/∂z ∈ ℝ^h
需要使用按元素乘法运算符，用 ⊙ 表示：
∂J/∂z
= (∂J/∂h) · (∂h/∂z)
= ∂J/∂h ⊙ φ'(z)。

最后，可以得到最接近输入层的模型参数的梯度
∂J/∂W^(1) ∈ ℝ^{h×d}。
根据链式法则，得到：
∂J/∂W^(1)
= (∂J/∂z) · (∂z/∂W^(1)) + (∂J/∂s) · (∂s/∂W^(1))
= ∂J/∂z · x^T + λ W^(1)。

根据链式法则，偏置项的梯度为：

∂J/∂b^(1)
= (∂J/∂z) · (∂z/∂b^(1))
= ∂J/∂z。

∂J/∂b^(2)
= (∂J/∂o) · (∂o/∂b^(2))
= ∂J/∂o。

练习4.7.3

计算本节所描述的模型，用于训练和预测的内存空间。

解答：

训练需要存储的参数：x, z, h, o, y, W^(1), W^(2), ∂J/∂W^(1), ∂J/∂W^(2)。

参数维度分析：
- 输入 x：n 维
- W^(1) 和 ∂J/∂W^(1)：n × m 维
- z 和 h：m 维
- W^(2) 和 ∂J/∂W^(2)：m × k 维
- o 和 y：k 维

网络参数均为 float 单精度浮点数，占4字节。训练所需存储的参数个数为：(n + n×m×2 + m×2 + m×k×2 + k×2)，总内存约为该个数 × 4 字节。

预测所需存储的参数个数为：(n + n×m + m×2 + m×k + k×2)，总内存约为该个数 × 4 字节。

假设需要计算二阶导数，计算图会发生什么变化？预计需要多长时间？

解答：

需要构造一个以一阶导数为前向传播的计算图，再对其进行反向传播来求二阶导。计算时间大约是一阶导数的两倍。

练习4.7.5

假设计算图对当前拥有的GPU来说太大了。

1. 请试着把它划分到多个GPU上。
2. 与小批量训练相比，有哪些优点和缺点？

解答：

1. 可以按以下三种方式把网络划分到多个GPU上：网络并行、分层并行和数据并行。网络并行：把每层网络的计算划分到不同的GPU。分层并行：把每层内的计算划分到不同的GPU，比如把全连接层输出单元拆分到不同GPU上计算。数据并行：把数据拆分到不同GPU上计算同样的网络，然后汇总各个GPU上的结果来更新参数。
2. 优点是可以用多个GPU训练更大的模型（前两种划分方法），以及更快地训练模型（第三种划分方法）；缺点是节点间的通信可能成为瓶颈，导致加速效果有限。
