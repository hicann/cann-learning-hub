练习4.6.3

当使用或不使用暂退法时，每个隐藏层中激活值的方差是多少？绘制一个曲线图，以显示这两个模型的每个隐藏层中激活值的方差是如何随时间变化的。

解答：

在使用暂退法时，每个中间激活值h以暂退概率p被随机变量h'替代，具体定义为：

h' = 0       （概率为p）
h' = h/(1-p) （概率为1-p，即其他情况）

在该定义下，h'的期望值保持不变，即 E[h'] = h。其方差推导如下：

D(h') = E[(h' - E(h'))^2] = E(h'^2) - E^2(h')
      = 0^2 × p + [h/(1-p)]^2 × (1-p) - h^2
      = h^2/(1-p) - h^2
      = h^2 × p/(1-p)

可见方差随暂退概率p增大而增大，这表明暂退法在训练过程中向激活值注入了额外的随机性（方差变大），从而起到了正则化作用。

练习4.6.4

为什么在测试时通常不使用暂退法？

解答：

训练时使用暂退法是为了防止模型过拟合，提高网络泛化能力。测试时我们不再需要防止过拟合，且希望模型的输出是确定的、可重复的，因此不使用暂退法。

练习4.6.7

如果我们将暂退法应用到权重矩阵的各个权重，而不是激活值，会发生什么？

解答：

考虑一个简单的单层无偏置神经网络 ŷ = φ(W x)，其中ŷ是输出，φ是激活函数，W是权重，x是输入。

定义dropout函数为：以概率p输出0，以概率1-p输出 h/(1-p)。该函数在概率p下导数为0，在概率1-p下导数为 1/(1-p)。

记L为损失函数，z = W x。

情形一：dropout放在激活层之后（标准做法）。

前向传播：输出 ŷ 以概率p变为0，以概率1-p变为 φ(W x)/(1-p)。这意味着被丢弃的神经元对输出完全不产生贡献。

反向传播时，权重梯度 ∂L/∂W 以概率p为0（神经元被丢弃，梯度不传播），以概率1-p为 (∂L/∂ŷ) · φ'(z) · x / (1-p)（对存活神经元缩放补偿）。被丢弃的神经元既不参与前向计算，也不参与反向梯度更新。

情形二：dropout放在激活层之前。

前向传播：线性输出 z = W x 先经过dropout得到 ẑ，再通过激活函数得到 ŷ = φ(ẑ)。当神经元以概率p被丢弃时，ẑ = 0，此时 ŷ = φ(0)；当神经元存活时，ẑ = W x/(1-p)，ŷ = φ(W x/(1-p))。

反向传播时，权重梯度 ∂L/∂W 以概率p为0（线性层输出被置零），以概率1-p为 (∂L/∂ŷ) · φ'(ẑ) · x / (1-p)。

关键区别在于：当dropout放在激活层之前时，被丢弃的神经元在前向传播中仍然输出 φ(0)，而不是0。对于ReLU来说 φ(0)=0，影响不大；但对于sigmoid或tanh等激活函数，φ(0) ≠ 0，这意味着被"丢弃"的神经元实际上仍然对网络输出产生贡献，削弱了dropout的正则化效果。因此标准做法是将dropout放在激活层之后，确保被丢弃的神经元完全不参与前向计算。

以下展示dropout前置的实验结果（具体图像和训练过程详见answers/04.06_reference_answer.ipynb）。

练习4.6.8

开发另一种用于在每一层注入随机噪声的技术，该技术不同于标准的暂退法技术。尝试开发一种在Fashion-MNIST数据集（对于固定架构）上性能优于暂退法的方法。

解答：

对每个ReLU层的输出添加高斯噪声，可以作为一种替代标准暂退法的正则化方法。

# 导入见4.6.1
def noise_layer(X,rate=0.1):
return X+rate*torch.rand(X.shape)
class Net4_6_8(nn.Module):
def __init__(self, num_inputs, num_outputs, num_hiddens1, num_hiddens2,
is_training=True):
super(Net4_6_8, self).__init__()
self.num_inputs=num_inputs
self.training = is_training
self.lin1 = nn.Linear(num_inputs, num_hiddens1)
self.lin2 = nn.Linear(num_hiddens1, num_hiddens2)
self.lin3 = nn.Linear(num_hiddens2, num_outputs)
self.relu = nn.ReLU()

def forward(self, X):
H1 = self.relu(self.lin1(X.reshape((-1, self.num_inputs))))
# 只有在训练模型时才使用dropout
if self.training == True:

H1 = noise_layer(H1)
H2 = self.relu(self.lin2(H1))
if self.training == True:

H2 = noise_layer(H2)
out = self.lin3(H2)
return out

num_inputs, num_outputs, num_hiddens1, num_hiddens2=784, 10, 256, 256

net = Net4_6_8(num_inputs, num_outputs, num_hiddens1, num_hiddens2)
num_epochs, lr, batch_size=10, 0.5, 256
loss = nn.CrossEntropyLoss(reduction='none')
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
trainer = torch.optim.SGD(net.parameters(), lr=lr)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
