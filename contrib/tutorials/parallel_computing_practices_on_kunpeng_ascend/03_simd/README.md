# ARM NEON SIMD 编程（第三章）

## 课程简介

本章进入**数据级并行**：在单个 CPU 核心内部，用一条指令同时处理多个数据元素。理论部分讲授 NEON 的寄存器体系与向量数据类型、六类核心指令（访存、算术、比较、类型转换与舍入、位运算、逻辑运算），以及可迁移的优化方法论。

配套实验共 7 个，沿"标量 → 向量 → 结构化访存 → 综合优化"的路径递进：从最简单的 AXPY 开始建立向量化思维，经 GEMV 引入规约与多累加变量展开，再通过 RGB↔BGR、白平衡、RGB2Gray、YUV2RGB 四个图像处理案例掌握交织存取、类型提升与定点化等工程细节，最后以 GEMM 综合实训收尾——在单核范围内做五级递进优化（标量基准 → NEON 向量化 → 4×4 寄存器分块 → Cache 三方向分块 → B 块内存打包），把第二章测得的存储层次参数真正用起来。

每个实验都采用**递增式版本组织**：后一版本在前一版本基础上只新增一个实现方法，输出表格相应增加一行，便于对照阅读、理解优化的引入过程。所有版本均带正确性校验，且因浮点加法不满足结合律，校验采用随累加长度缩放的相对容差。

## 适合人群与前置要求

面向具备 C 语言基础、了解数组与指针的学习者。建议先完成第二章，本章的 Cache 分块与内存打包直接使用第二章测得的缓存行大小与各级缓存容量。

本章不涉及多线程与 NPU；第五章的综合实训会在本章 GEMM 实现之上叠加 OpenMP 线程级并行。

## 学习目标

- 掌握 NEON 寄存器体系与向量数据类型的对应关系，能够根据元素类型选择正确的 intrinsic；
- 掌握访存、算术、比较、类型转换、位运算、逻辑运算六类指令的语义与使用场景；
- 能够独立完成典型算法的 NEON 向量化改写，并正确处理尾块、对齐与交织存取；
- 理解多累加器打破依赖链、Cache 分块提高算术强度、内存打包改善访存连续性的作用机理；
- 能够对向量化前后的结果做正确性校验，并对性能做定量对比与归因；
- 建立"测量 → 归因 → 优化 → 验证"的优化闭环意识。

## 实验环境说明

- 本章实验依赖 AArch64 + NEON，在 x86 平台上无法编译；请确认 `uname -m` 输出为 `aarch64`。
- 所有源码通过 `%%writefile` 内嵌在 Notebook 中，请自上而下依次执行各单元格（Shift+Enter）。
- 每个实验的多个版本在同一次运行中完成计时与校验，面对完全相同的数据与运行环境，版本之间具有可比性。
- 浮点结果校验采用随累加长度缩放的**相对容差**：向量化改变了累加顺序，与标量顺序求和存在微小差异属正常现象。
- 参考加速比会随处理器型号、编译器版本与系统负载变化，学习时应关注版本之间的相对变化及其成因。
- 遇到 🔧 **动手练习** 与 🤔 **思考题** 时，建议先独立完成，再阅读后续内容。
- 在线体验链接由仓库维护人员配置，当前记为 `-`。
