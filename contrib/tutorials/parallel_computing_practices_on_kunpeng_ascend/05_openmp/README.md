# OpenMP 共享内存编程（第五章）

## 课程简介

本章仍然是线程级并行，但换一种抽象层次：用编译制导语句表达并行意图，把线程的创建、划分与回收交给运行时。理论部分讲授 Fork-Join 执行模型与 `parallel` 构造、数据环境规则与四大数据子句、`reduction` 归约机制、循环携带依赖的识别与消除、四类循环调度策略与负载均衡、并行区域的复用与 `nowait`、伪共享的判定与消除、`collapse` 与 `simd` 协同，以及 `task` 任务并行。

配套实验共 9 个，每个实验对应一个知识单元，且都采用**递进式版本组织**：以串行实现为基准，每个版本仅引入一种新的 OpenMP 构造或一处相应的代码改写，并在同一次运行中完成全部版本的计时与正确性校验，因而各版本面对完全相同的数据与运行环境，具有可比性。

最后的综合实训把第三章的 NEON 单线程实现与本章的线程级并行叠加起来，共五个版本：两条基准 → 朴素 OpenMP → OpenMP 与 Cache 分块 NEON 融合 → 同一条指令用于打包版本（**产生数据竞争**）→ 线程私有缓冲区修复。实训刻意安排了两个对照案例：一个加速比可观但绝对性能低于单线程的版本，以及一处不崩溃、不告警、小规模无法复现的数据竞争。第二条主线是保持代码不变、仅改变线程数的强扩展性研究。

## 适合人群与前置要求

面向已完成第四章 Pthreads 学习的学习者——理解了显式同步的代价，才能体会 OpenMP 抽象的价值与边界。综合实训还要求先完成第三章的 NEON GEMM 实验。

本章不涉及 NPU。

## 学习目标

- 理解 OpenMP 与 Pthreads 的抽象层次差异，掌握 Fork-Join 执行模型与 `parallel` 构造语义；
- 能够正确使用 `private` / `firstprivate` / `lastprivate` / `shared` 控制变量作用域，用 `default(none)` 强制显式声明；
- 能够用 `reduction` 替代显式临界区，理解私有副本初值与合并时机；
- 能够判定循环是否可安全并行，识别并消除可消除的循环携带依赖；
- 能够针对不规则负载选择合适的调度策略，用不均衡因子定量刻画负载分布；
- 能够通过复用并行区域降低 Fork-Join 开销，正确判断何时可安全去除隐式栅栏；
- 能够用线程局部化与数组段归约消除竞争与伪共享；
- 能够用 `collapse` 与 `simd` 实现 TLP 与 DLP 的协同，并用 `task` 并行化递归与不规则问题；
- 能够设计强扩展性实验，并解释"加速比高但绝对性能低"这类反直觉结果。

## 实验环境说明

- 运行前请确认编译器支持 OpenMP（`echo | gcc -fopenmp -dM -E - | grep _OPENMP` 应有输出），并用 `nproc` 确认可用核心数。
- 部分实验会读取 `OMP_NUM_THREADS` 与 `OMP_SCHEDULE` 环境变量；调度策略实验中 `schedule(runtime)` 的实际行为由 `OMP_SCHEDULE` 决定。
- 所有源码通过 `%%writefile` 内嵌在 Notebook 中，请自上而下依次执行各单元格（Shift+Enter）。
- 综合实训中的"打包版本"**故意保留了一处数据竞争**：它不崩溃、不告警，且在小规模下无法复现。请按 Notebook 指引先观察、再修复，不要跳过该版本。
- 强扩展性实验要求保持代码不变、仅改变线程数；核心数不足时请相应调整线程数扫描范围。
- 参考耗时会随核心数、编译器版本与系统负载变化，学习时应关注版本之间的相对变化及其成因。
- 在线体验链接由仓库维护人员配置，当前记为 `-`。
