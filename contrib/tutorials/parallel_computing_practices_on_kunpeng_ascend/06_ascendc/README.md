# Ascend C 算子开发（第六章）

## 课程简介

本章理论部分讲授昇腾 AI 处理器体系结构与 CANN 软件栈分层、Ascend C 的 Host-Device 异构编程模型（核函数限定符、内核调用符、异步下发语义、SPMD 执行模型）、三段流水编程范式（CopyIn-Compute-CopyOut）与两级切分策略、矢量计算与规约 API、算子融合，以及矩阵计算与 Cube 单元。

配套实验共 7 个，按"打通链路 → 建立范式 → 掌握 API → 综合运用"的路径递进：HelloWorld 不做任何计算，只为建立并验证这条异构执行链路；向量加法引入三段流水与两级切分；ReduceSum 建立核内 + 核间的两级规约结构；Sigmoid 对照手写实现与高阶 API，讨论精度取舍；融合算子用 `y = σ(a·x + b) ⊙ v` 这条三算子链，沿融合程度实现四个递进版本，先核算融合前后的访存量、再用实测检验上界能兑现多少；MatMul 比较 AIV 矢量单元路径与 Cube 单元 Matmul 高阶 API 的算力差距；最后 Softmax 综合实训把规约、数值稳定性与算子融合三条线索合到一起，实现五个版本，每个版本只引入一处改动，版本间的差值因此都能归因到具体原因。

## 适合人群与前置要求

面向具备 C/C++ 基础、已完成第二至五章 CPU 并行学习的学习者。理解存储层次（第二章）与数据切分（第三、五章）是本章"片上占用核算"与"两级切分"的直接前提。

本章不要求预先掌握昇腾开发经验，但要求能够读懂 C++ 模板与类的基本写法。

## 学习目标

- 掌握昇腾 AI 处理器的体系结构（Scalar / Vector / Cube 单元）与片上存储层次，了解 CANN 软件栈分层；
- 能够编写、编译并运行 Ascend C 核函数，理解核函数限定符、内核调用符三个参数与异步下发语义；
- 理解 SPMD 执行模型，能够用 `GetBlockIdx()` 完成核间数据分片；
- 掌握 CopyIn-Compute-CopyOut 三段流水的标准写法，区分 TQue 与 TBuf 的适用场景；
- 能够完成核间与核内两级切分，正确处理尾核、尾块与对齐约束，并用双缓冲重叠搬运与计算；
- 能够实现两级规约结构的规约类算子，识别并规避中间量溢出与输出量化失效；
- 能够核算算子融合前后的访存量、预测收益上界，并说明融合的代价与收益边界；
- 能够使用 Matmul 高阶 API 调用 Cube 单元，并与矢量单元实现做 GFLOPS 对照。

## 实验环境说明

- 运行前请确认：`npu-smi info` 能查到设备，`$ASCEND_TOOLKIT_HOME` 已设置，`bisheng` 在 `PATH` 中。
- **若环境检查未通过**：先重新运行 Notebook 中的"环境准备"单元格；仍不通过则在终端执行 `source $ASCEND_TOOLKIT_HOME/set_env.sh` 并重启内核。
- 源代码通过 `%%writefile` **分段写入同一个 `.asc` 文件**——讲一段、写一段，最后实现 `main` 函数。请务必自上而下依次执行各单元格（Shift+Enter），跳过中间单元格会导致 `.asc` 文件不完整而编译失败。
- 实验一先用 `bisheng` 直接编译单个 `.asc` 文件，随后演示 CMake 工程方式，并对照二者的适用场景。
- HelloWorld 的多核输出顺序不确定，这是 SPMD 执行模型的正常表现，不是实验失败。
- 片上缓冲区容量、可用核数等规格由 Notebook 中的环境查询单元格实测给出，后续所有"片上占用核算"以实测规格为准，不要沿用讲义中的示例数值。
- 参考耗时与 GFLOPS 会随芯片型号、CANN 版本与系统负载变化，学习时应关注版本之间的相对变化及其成因。
- 遇到 🔧 **动手练习** 与 🤔 **思考题** 时，建议先独立完成，再阅读后续内容。
- 在线体验链接由仓库维护人员配置，当前记为 `-`。
