# Lecture1 智能系统概述

> **面向昇腾芯片的智能系统开发教程** —— 从概念理解到技术实践的全面指南

本 Lecture 系统性地介绍智能系统的核心概念与技术体系，涵盖智能系统的定义、组成、开发流程与技术展望四大主题，并在介绍昇腾 910 平台时提供可在 Notebook 中直接运行的代码。

## 章节结构

- 1.1 什么是智能系统
- 1.2 智能系统的四大重要意义
- 1.3 智能系统的层级体系
- 1.4 智能系统的应用领域概览
- 2.1 四大核心组成部分
- 2.2 智能芯片——计算与控制的核心
- 2.3 智能软件——支撑算法落地的关键
- 2.4 智能计算——AI 算法的核心动力
- 2.5 智能互联——构建万物互联的基础
- 2.6 智能系统的整体闭环架构
- 3.1~3.5 走近昇腾 910：NPU 可用性检查、npu-smi 状态查询、Host 与 Device 协作、CPU vs NPU 性能对比、微型神经网络执行
- 4.1~4.7 智能系统开发流程：芯片选型、BootLoader、操作系统移植、编译构建、软件框架、应用程序开发
- 5.1~5.7 技术展望：硬件/软件/算法/互联演进、挑战与应对、边缘 AI 与端云协同
