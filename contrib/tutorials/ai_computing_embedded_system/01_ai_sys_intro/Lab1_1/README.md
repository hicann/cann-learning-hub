# 实验1.1 CANNLab 开发环境搭建和测试

> **实验平台**：GitCode CANNLab 云沙箱（昇腾 Atlas NPU · Ascend 910B3）
> **CANN 版本**：9.0 ｜ **Python**：3.11.4 ｜ **内核**：ARM
