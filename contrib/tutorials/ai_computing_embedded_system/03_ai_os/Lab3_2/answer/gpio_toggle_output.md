# GPIO 驱动测试程序预期输出

程序文件：`code/gpio_toggle.c`

## 情形一：10µs 高速翻转（默认参数）

运行命令：`sudo ./gpio_toggle`

终端输出：

```
GPIO 驱动测试程序
  物理引脚: 40 (wPi 25)
  半周期:   10 us
  理论频率: 50.00 kHz
  按 Ctrl+C 停止
```

示波器观测（探头接物理引脚 40，GND 接开发板 GND）：

| 观测项 | 预期结果 |
|---|---|
| 波形形状 | 规则方波，边沿陡峭清晰 |
| 电平幅度 | 0 ~ 3.3V 完整摆幅 |
| 时钟周期 | 约 20µs（半周期 10µs） |
| 实测频率 | 约 45~48kHz（受 digitalWrite 本身耗时影响，略低于理论 50kHz） |
| 周期稳定性 | 周期均匀一致，无明显抖动（已提升 SCHED_FIFO 实时优先级） |

> 结论：GPIO 翻转与信号质量良好，以 10µs 为周期的 SPI 通讯可以轻松胜任。

## 情形二：降速为 LED 闪烁

运行命令：`sudo ./gpio_toggle 500000`（半周期 500000µs = 0.5s）

终端输出：

```
GPIO 驱动测试程序
  物理引脚: 40 (wPi 25)
  半周期:   500000 us
  理论频率: 0.00 kHz
  按 Ctrl+C 停止
```

硬件效果：在引脚 40 与 GND 之间串接 LED + 330Ω 电阻，可观察到 LED 以 0.5s 亮、0.5s 灭的频率闪烁（1Hz）。

> 结论：同一套 GPIO 电平翻转机制，改变速率即可从高速 SPI 时钟降速为 LED 闪烁，体现“一套底层机制、多种上层应用”的设计思想。
