# 实验3.3 昇腾 CANN 基础操作实验

> **实验平台**：云沙箱 + 香橙派开发板
> **CANN 版本**：9.0.0 ｜ **Python**：3.11 ｜ **Ascend 910B3**

本实验从"自下而上、层层依赖"的协同架构视角，系统讲解昇腾 CANN、操作系统与驱动程序三者之间的关系，并深入剖析 CANN 软件栈的核心模块与功能层次。在云沙箱环境中完成 NPU 硬件识别、CANN 环境验证、ACL 编程体验等基础操作；最后在昇腾香橙派开发板上查询 NPU 与 CANN 版本信息，建立"固件→驱动→CANN"严格匹配的工程意识。
