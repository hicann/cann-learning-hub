# Lecture2 智能硬件系统

本章节系统介绍智能硬件系统的核心架构与关键技术，涵盖 SoC 片上系统、CPU、协处理加速单元（NPU/GPU/DSP/FPGA）、存储器单元、常用接口，并重点解析华为昇腾 AI 处理器的硬件系统、达芬奇架构与开发应用平台。

## 章节结构

- 1. 智能硬件片上系统芯片（SoC）
- 2. 中央处理单元（CPU）
- 3. 协处理加速单元
- 4. 存储器单元
- 5. 常用接口
- 6. 昇腾硬件系统
- 7. 昇腾 AI 处理器架构
- 8. 达芬奇 AI 处理器架构
- 9. 昇腾开发应用平台
