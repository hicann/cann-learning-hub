# 参考答案目录

本目录包含实验1.1「动手开发环节」各题目的参考答案。

| 文件 | 题目 | 难度 |
|---|---|---|
| `answer1_cpu_info.py` | 获取并打印 CPU 型号和核心数 | ⭐ |
| `answer2_npu_info.py` | 获取并打印 NPU 型号和健康状态 | ⭐ |
| `answer3_memory_info.py` | 获取内存总量与使用率 | ⭐⭐ |

## 运行方式

```bash
python answer1_cpu_info.py
python answer2_npu_info.py
python answer3_memory_info.py
```

> 建议先独立完成题目，再对照参考答案学习。
