# 06.01 课后练习答案

1. 连续数组的相邻元素地址连续，Host（主机侧程序）可以提前推导搬运起点、长度和尾块范围，NPU Kernel（NPU 核函数）更容易使用 `DataCopy`（Ascend C 数据搬运接口）把一段数据从 GM（Global Memory，全局内存）分块搬入 UB（Unified Buffer，统一缓冲区）。
2. 链地址法需要先读取当前节点，才能知道下一个节点位置；不同 query（查询请求）的链长也可能不同，因此容易形成随机小块访存和不一致的循环次数。
3. 4 槽桶化 Cuckoo Hash（布谷鸟哈希，一种为每个键设置少量候选位置的哈希表方法）体现连续数组式访存布局：每个桶是固定 32B 的连续区域，每个 query 只检查固定数量的候选槽。
4. 固定读取两个桶会在部分命中场景下多读一个桶，但它让基础控制流程和访存上界稳定，便于多核均分、UB 预算和结果验证。
