# 10.02 课后实践参考答案

使用 `scheduler.pipeline_schedule` 对同一组任务分别设置 `queue_depth=1、2、3`，记录 `end_to_end`。默认 31 个节点、双 Compute lane 的数据中，队列深度增大后等待减少；继续增加深度时，收益会受到最慢阶段和 Compute lane 数量限制，不能无限提升。

参考实现的关键输入是：

```python
timing = pipeline_schedule(
    priority_order,
    cost,
    queue_depth=depth,
    copy_in=payload['copy_in'],
    copy_out=payload['copy_out'],
    compute_lanes=payload['compute_lanes'],
)
print(depth, timing['end_to_end'])
```

还需要确认每个任务都有三个阶段事件，并满足 `CopyIn` 结束不晚于 `Compute` 开始、`Compute` 结束不晚于 `CopyOut` 开始。
