# 课程简介
《并行计算：通智融合》是一门紧跟“通算与智算融合”产业发展趋势的新工科核心课程。本课程打破传统计算课程局限，以鲲鹏（Kunpeng）通用算力与华为昇腾（Ascend）智算算力为核心底座，内容垂直穿透底层硬件架构、多核并行编程、昇腾算子开发及深度学习模型昇腾异构部署，旨在培养具备软硬件协同设计与底层性能调优能力的系统级复合型人才。

# 核心技能
- 基础硬件架构与单核极致优化能力；
- 多核并发编程与共享内存调度能力；
- 基于 Ascend C 的异构 AI 算子开发能力；
- 产业级 AI 模型端侧部署与全链路调优能力；

# 适用对象
- 计算机相关专业大二以上学生
- 对并行计算/异构计算感兴趣的开发人员
