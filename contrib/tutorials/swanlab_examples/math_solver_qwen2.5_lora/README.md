# 基于昇腾 NPU 的数学解题大模型微调实战

本项目演示如何在华为昇腾 NPU 上，使用 **LoRA 微调**技术对 **Qwen2.5-0.5B-Instruct** 大语言模型进行微调，使其成为解答小学数学题的"数学解题专家"。

## 环境准备

### 安装依赖

如果你使用的是魔搭（ModelScope）在线环境，以下库通常已预装。否则请执行：

```bash
pip install transformers modelscope==1.35.4 peft swanlab torch_npu
```

## 课程学习

打开 `math_solver.ipynb`，按照 notebook 中的章节顺序逐步学习：

1. 项目背景与整体流程概览
2. 环境准备与依赖安装
3. 数据集探索与分析
4. 模型下载与加载
5. 数据预处理
6. LoRA 微调配置与原理
7. 在昇腾 NPU 上启动训练
8. 模型推理
9. 交互式体验

## 教师使用指导：基于 SwanLab 的课后作业与性能/精度排行

本教程支持作为课后作业发布，学生提交训练结果后，教师可通过 SwanLab 平台查看**精度排行榜**和**性能排行榜**。

### 第一步：创建组织（教师操作）

1. 登录 [SwanLab 官网](https://swanlab.cn)，点击左上方「**创建空间**」
2. 填写组织名（如 `npu-math-class`）和组织昵称，完成创建
3. 记下**组织名**（username），后续发给学生

### 第二步：邀请学生加入

1. 进入组织空间 →「管理」→「成员管理」
2. 点击「**邀请成员**」，复制邀请链接
3. 将链接和组织名发给学生

### 第三步：配置 SwanLab API Key（学生操作）

学生首次使用需在终端登录 SwanLab：

```bash
pip install swanlab
swanlab login
```

按提示粘贴 API Key（在 SwanLab 网页端「用户设置 → API Key」获取）。

### 第四步：学生提交作业

学生在 notebook 的 SwanLab 配置 cell 中，将 `workspace` 设为教师创建的组织名：

```python
swanlab_callback = SwanLabCallback(
    workspace="npu-math-class",              # 教师创建的组织名
    project="math-solver-homework",          # 统一项目名（所有学生相同）
    experiment_name="张三-2024001",          # 学生姓名-学号（每人不同）
    config={
        "model": "Qwen2.5-0.5B-Instruct",
        "lora_r": 8,
        "learning_rate": 1e-4,
        "batch_size": 64,
        "epochs": 5,
    }
)
```

运行训练后，结果自动上传到组织空间下的统一项目中。

### 第五步：查看排行榜（教师操作）

打开 SwanLab 组织空间 → 项目 `math-solver-homework` → **表格视图**，可以看到所有学生的实验汇总：

**精度排行榜**（按模型效果排）：

|------|------|----------|----------|------------|-----|
| 1 | 张三-2024001 | 0.32 | 92.1% | 64 | 1e-4 |
| 2 | 李四-2024002 | 0.35 | 90.8% | 32 | 1e-4 |
| 3 | 王五-2024003 | 0.41 | 88.5% | 16 | 1e-4 |

**性能排行榜**（按训练效率排）：

| 排名 | 实验 | 总时间(s) | 吞吐量(样本/s) | NPU显存(MB) |
|------|------|-----------|----------------|-------------|
| 1 | 张三-2024001 | 935 | 64.2 | 24500 |

操作方式：在表格视图中点击列头即可排序。按 `val_loss` 升序排为精度榜，按 `perf/throughput_samples_per_s` 降序排为性能榜。

### 作业评分建议

| 维度 | 指标 | 权重 | 说明 |
|------|------|------|------|
| 模型精度 | `val_loss` 越低越好 | 50% | 核心能力 |
| 训练效率 | `perf/throughput_samples_per_s` 越高越好 | 30% | NPU 优化能力 |
| 资源利用 | `perf/npu_memory_MB` 越低越好 | 10% | 工程素养 |
| 代码规范 | notebook 注释完整性 | 10% | 教师主观评分 |

在 SwanLab 实验页面可以为不同批次打标签（如 `batch-2026-spring`），便于按学期筛选排行。

## 防作弊分析（教师手册）

以下是学生可能作弊的手段及对应防范措施，教师需了解并提前布防。

### 高风险作弊手段

| 手段 | 说明 | 危害 | 防范 |
|------|------|------|------|
| **直接伪造指标** | 在代码中 `swanlab.log({"val_loss": 0.01})` 写死好成绩，不实际训练 | 极高 | 见下方「指标防伪」 |
| **替换更大模型** | 把 Qwen2.5-0.5B 换成 7B/14B，精度碾压同学 | 高 | 在 config 中校验 `model` 字段，SwanLab 表格可见 |
| **验证集过拟合** | 反复在验证集上调参，val_loss 很高但泛化差 | 高 | 教师保留独立测试集，最终用测试集排名 |
| **直接 log 假性能** | `swanlab.log({"perf/throughput": 9999})` 虚报速度 | 中 | 见下方「性能防伪」 |

### 中低风险作弊手段

| 手段 | 说明 | 危害 | 防范 |
|------|------|------|------|
| **抄袭同学代码** | 复制他人的 notebook，改个 experiment_name 提交 | 中 | 要求提交 git 仓库链接，查 commit 历史 |
| **用预训练权重** | 加载已有数学模型权重，跳过训练直接推理 | 中 | 要求训练曲线完整（SwanLab 有记录） |
| **篡改数据集** | 把难题删掉，只留简单题 | 低 | 教师提供统一数据集路径，禁止修改 |
| **虚报 batch_size** | 实际用 bs=4 但 config 里写 64 | 低 | SwanLab 自动记录硬件日志，可交叉验证 |

### 防范措施

#### 1. 指标防伪：验证训练过程真实性

SwanLab 会自动记录**训练曲线**（每步的 loss 变化）。真训练的曲线是平滑下降的，伪造的指标没有曲线或曲线不自然。

**检查方法**：在 SwanLab 实验页面查看 loss 曲线，如果：
- 曲线为空但 val_loss 很低 → 直接伪造，判作弊
- 曲线只有一两个点 → 可能只跑了几步就 log 假结果
- 曲线正常平滑下降 → 大概率真实训练

#### 2. 性能防伪：交叉验证性能数据

训练吞吐量（样本/秒）和 batch_size、模型大小、硬件型号之间有物理约束：

```
合理吞吐量 ≈ batch_size × NPU算力 / 模型计算量
```

**检查方法**：
- 0.5B 模型 + bs=64 + 910B3 的合理吞吐量在 40-80 样本/秒
- 如果有人报 500 样本/秒 → 物理上不可能，判作弊
- 对比 `perf/total_time_s` 和 SwanLab 自动记录的训练时间戳是否一致

#### 3. 代码审查：要求提交完整代码

要求学生提交：
- 完整 notebook 文件（含所有 cell 的执行输出）
- Git 仓库链接（有 commit 历史，不是一次性 push）

**检查方法**：
- notebook 中 `model` 加载代码是否为 Qwen2.5-0.5B
- `TrainingArguments` 中的参数与 SwanLab config 是否一致
- 是否有 `swanlab.log()` 直接写死指标的代码

#### 4. 统一测试集：教师保留最终评测

训练完成后，教师用**自己保留的独立测试集**重新评测所有学生的模型权重：

```python
# 教师评测脚本（不公开测试集）
for student_checkpoint in all_checkpoints:
    model = load_model(student_checkpoint)
    score = evaluate(model, teacher_test_set)  # 教师的独立测试集
    ranking.append((student, score))
```

这样即使学生在验证集上过拟合，最终排名也以教师测试集为准。

#### 5. SwanLab 配置校验

在 SwanLab 表格视图中，检查以下字段一致性：

| 检查项 | 正常值 | 异常信号 |
|--------|--------|----------|
| `config.model` | Qwen2.5-0.5B-Instruct | 出现 7B/14B 等更大模型 |
| `config.batch_size` | 与 perf/batch_size 一致 | 不一致说明虚报 |
| 训练曲线点数 | 与总步数接近 | 远少于总步数说明中途伪造 |
| Git commit 数 | ≥ 3（多次提交） | 仅 1 个 commit 说明一次性抄袭 |
