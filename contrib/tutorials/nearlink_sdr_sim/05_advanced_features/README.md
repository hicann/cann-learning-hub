# 第五章 跳频抗干扰、接入与功率控制

## 章节概述

本章聚焦于星闪 SLE 标准中的三项高级信道适应技术——跳频扩频（对抗多径衰落）、六阶段接入建链流程（G/T 角色协商与调度器配置）和发射功率自适应控制（闭环失败检测与功率步进）。通过对比跳频与固定信道的 FER、扫描接入成功率、观察功率阶梯轨迹，帮助学生理解系统级抗干扰与链路管理的实现原理。
