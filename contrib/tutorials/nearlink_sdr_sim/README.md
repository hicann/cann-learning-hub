# Nearlink SDR Simulation Course

基于 TXS-10002-2025 SparkLink SLE 标准的星闪通信链路仿真教学课程。

## 课程概述

本课程通过六个章节的实验，从物理层 GFSK 调制解调入手，逐步深入到 Polar 信道编码、MAC 帧结构、HARQ/AMC/QoS 链路保障机制，最终完成 SleNode 双节点端到端安全通信仿真，构建完整的星闪 SLE 协议栈认知体系。本课程支持的硬件型号为 CPU、NPU 910B3和NPU 950，且本课程已经在 gitcode notebook 在线体验环境中验证跑通无报错。
