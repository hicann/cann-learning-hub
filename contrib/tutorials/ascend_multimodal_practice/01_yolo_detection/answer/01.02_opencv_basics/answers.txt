练习 1 答案：C
解析：NumPy 数组形状是 (高度, 宽度, 通道数)。题目说图片是 640×480，但"640×480"
在不同语境含义不同。按"宽640 × 高480"理解，数组形状应为 (480, 640, 3)：
  - 第 1 维是高度=480（行）
  - 第 2 维是宽度=640（列）
  - 第 3 维是通道=3（RGB）
注意 OpenCV/NumPy 中高度在前宽度在后，这是初学者最容易搞反的地方。
（若题目"640×480"指 高×宽，则答案是 D (640, 480, 3)，关键看约定。

练习 2 答案：
- 0 表示 纯黑（完全没有光）
- 255 表示 纯白（光的强度最大）
（8 位无符号整数 uint8 的取值范围正好是 0-255）

练习 3 答案（代码）：

    import numpy as np
    import matplotlib.pyplot as plt

    img = np.zeros((50, 50), dtype=np.uint8)   # 先全黑
    img[25:, :] = 255                            # 下半部分（第25行起）全白

    plt.imshow(img, cmap='gray')
    plt.title("上黑下白")
    plt.axis('off')
    plt.show()

解析：img[25:, :] 表示"第 25 行到最后一行，所有列"，赋值为 255 即变白。
记住 NumPy 索引是 [行, 列] = [y, x]。
