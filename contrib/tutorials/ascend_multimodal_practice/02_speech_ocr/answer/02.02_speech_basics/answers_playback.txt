练习 1 答案：B
解析：华为云 SIS 要求音频格式为 16kHz 采样率、16bit 位深、单声道（简称 16k16bit）。
这是语音识别的标准电话级音质，平衡了识别准确率和文件大小。A 是 CD 音质（过高），
C 太低音质差影响识别，D 是专业音频（浪费带宽）。

练习 2 答案：
- AK/SK 应该存放在 .env 文件中
- 用 python-dotenv 库（load_dotenv + os.getenv）加载
- 不要硬编码在代码里，也不要提交到 git（会泄露凭证被他人盗用）

练习 3 答案：
云环境（如 CANN 社区 JupyterLab）是远程服务器，没有本地音频输出设备（扬声器），
playsound 调用系统音频 API 时找不到设备所以失败。
替代方案：用 IPython.display.Audio，它会在 Notebook 输出区域生成内嵌播放器，
不依赖系统音频设备，云环境也能显示和播放。
