- speed 参数范围：-500 到 500

练习 3 答案（代码）：

    from IPython.display import Audio, display
    output = tts_synthesize(
        text='从前有座山，山里有座庙',
        output_path='./story.wav',
        voice='chinese_xiaoyan_common',   # 小妍女声
        speed=-200                          # 慢速
    )
    display(Audio(output))

解析：讲故事用慢速 + 柔和女声（小妍）效果最佳，娓娓道来的感觉。
