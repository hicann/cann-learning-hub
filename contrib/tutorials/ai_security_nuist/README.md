## 课程简介

本课程围绕 **人工智能安全** 主题设计，面向初学者构建从环境配置、智能威胁检测、AI 模型后门攻防到人脸伪造对抗的模块化实验体系。课程采用“基础项目—提高项目—挑战项目”的递进式结构，通过 9 个实验帮助学习者逐步理解人工智能安全中的典型场景、核心模型方法与攻防实践流程。

课程以华为昇腾 AI 计算生态为实验基础，结合 **CANN、MindSpore、Jupyter 在线编程环境、AI 算力资源** 等能力，引导学习者完成模型训练、推理优化、攻击验证、防御评估与生成式伪造检测等实验任务。

课程总学时为 **16 学时**。

## 适合人群

本课程适用于 **0 基础的新手学习者**，学习前不要求具备深度学习开发经验。建议学习者具备基本的 Python 语法阅读能力；若没有 Python 基础，也可以在实验过程中同步学习。

- 对人工智能安全感兴趣，但尚未系统学习过 AI、深度学习或网络安全的学生；
- 希望了解昇腾 NPU、CANN 和 MindSpore 基础使用方式的初学者；
- 希望通过实验方式入门智能威胁检测、模型后门攻防和人脸伪造对抗的学习者；
- 华为 ICT 学院相关课程、实训、创新实践或竞赛预备阶段的学员。

## 学习目标

- 理解人工智能安全的基本概念、典型应用场景与实验流程；
- 掌握基于 CANN 与 MindSpore 的基础实验环境配置方法；
- 使用 Jupyter 在线编程环境完成 AI 模型训练、推理和结果分析；
- 了解 CNN、ResNet、GAN、ProGAN、StyleGAN 等常见模型在安全场景中的应用；
- 能够完成勒索软件检测、加密恶意流量检测等基础智能威胁检测任务；
- 理解 AI 模型后门攻击的基本原理，并能够完成 BadNets 后门攻击实验；
- 掌握 Neural Cleanse 后门检测与 BNP 剪枝防御的基本实验思路；
- 了解人脸伪造生成与检测的基本方法，认识生成式 AI 带来的安全风险；
- 初步形成 AI 安全实验分析、问题定位和结果评估能力。
