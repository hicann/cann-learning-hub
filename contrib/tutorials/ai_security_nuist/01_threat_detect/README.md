# 《人工智能安全》模块化实验教程

## 一、教程简介

本教程围绕人工智能安全中的 **智能威胁检测、AI 模型后门攻防、人脸伪造对抗** 三个方向展开，基于华为 **CANN、MindSpore、ModelArts、Jupyter 在线编程环境与 AI 算力** 完成实验。

课程从基础实验环境配置和安全检测模型构建开始，逐步过渡到后门攻击、后门检测、防御策略，最后进入深度伪造生成与检测对抗实验。整体设计遵循“由易到难、由检测到攻防、由传统安全任务到生成式 AI 安全任务”的递进式路线。

每个章节建议包含以下三类资源：

| 类型 | 内容说明 |

## 六、总体总结

本教程适合作为一门 **16 课时的人工智能安全实验课**，也可以扩展为“Notebook 在线实验 + 源码仓库 + 授课 PPT + 实验报告模板”的完整实践型课程。

课程的核心价值在于将人工智能安全中的三个典型问题串联起来：

1. **智能威胁检测**：让学生掌握 AI 模型在安全检测任务中的基础应用。
2. **AI 模型后门攻防**：让学生理解模型自身可能存在的安全风险，以及攻击、检测、防御的完整流程。
3. **人脸伪造对抗**：让学生了解生成式 AI 带来的内容安全问题，并掌握基础检测方法。

整体上，该教程能够帮助学生建立从 AI 安全基础实践到模型安全攻防，再到生成式 AI 安全对抗的系统化实验能力。
