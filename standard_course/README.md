# CANN 课程体系总体规划

> CANN 全栈课程体系设计目录，以**原子课程为基础积木**，支撑**启航营**、**常规课**（传统学科课程、CANN 新增课程）、**CANN教材**三大课程形态，覆盖从短期集训到高校学分课、从入门到专家的完整学习路径。五大分区自包含，与 cann-learning-hub 标准课程包内容保持一致。

---

## 一、课程体系总览

### 1.1 核心理念：原子课程是基础

**原子课程**是整个 CANN 课程体系的基础积木，按**技术栈四层 × 难度三级**组织，共 135 门。每门原子课可单独支撑一节课（45–90 分钟），具备独立的学习目标、核心内容、实践项目与考核标准。

四大课程形态均由原子课程拼装、节选或教学化而来：

| 课程形态 | 与原子课程的关系 | 拼装方式 |
|---------|----------------|---------|
| **启航营** | 原子课程节选 | 从 L1/L4 层选取入门级原子课，按两天/两周集训节奏重组，配套高强度实践 |
| **传统学科课程** | 原子课程教学化 | 将 L4 架构/算子类原子课融入大学传统课程（体系结构/计组/并行计算等），以单元包/对照案例/实验替换形式外挂融入 |
| **CANN 新增课程** | 原子课程拼装 | 每门课程由 10–30 门原子课按章节拼装，关注前后章节连续性，配套大作业 |
| **CANN 新增教材** | 原子课程系统化 | 将原子课程内容按教材体例系统化组织，形成完整的知识体系与教学脉络 |

## 二、五分区详细介绍

### 2.1 00 原子课程（体系基础）

**定位**：课程体系的基础积木，按技术栈四层（应用层/AI 框架层/加速库/编程编译 NPU 架构）× 难度三级（初级/中级/高级）组织，每门原子课可单独支撑一节课（45–90 分钟）。是启航营、传统学科课程、CANN 新增课程、新增教材的共同内容来源。

**规模**：135 门
- **L1 应用层**：44 门（深度学习/计算机视觉/生成式 AI/大语言模型/科学计算/推荐系统）
- **L2 AI 框架层**：29 门（框架基础/训练技术/推理技术/图框架/进阶主题；含 CANN 训练推理初/中/高阶 L2-20~25、图框架 L2-26~28、昇腾 AI 产业生态 L2-29）
- **L3 加速库**：13 门（Aclnn/GE/通信库/C++并行算法/Python加速库）
- **L4 编程·编译·NPU 架构**：49 门（Ascend C/PyPTO/TileLang/PyAsc/CANNBot/NPU架构）

**对其他分区的支撑**：
- 启航营：节选 L1-25/26、L1-31、L4-01/07、L4-14、L4-45 等入门级原子课
- 传统学科课程：将 L4-47/48/49（NPU 架构）教学化为体系结构三幕剧
- 新增课程：每门课程由 10–30 门原子课拼装（如课程三拼装 L4-01~30、L3-01~09）
- 教材：将原子课程内容按教材体例系统化组织
- 推荐系统：L1-42~44（CTR/DIN/DSSM → 自动融合优化 → 多卡调优+自定义算子）
- CANN 训练/推理/图框架：L2-20~28（CANN 训练推理初/中/高阶 + 图框架初/中/高阶）、L2-29（昇腾 AI 产业生态）

**详细大纲**：[原子课程总纲](./00_atomic_courses/README.md)

---

### 2.2 01 启航营（原子课程节选）

**定位**：短期集训营，面向零基础新入行者、竞赛新手、跨领域转型开发者，通过高强度理论+实践快速建立 CANN 开发能力。两营递进，结业算子同源。

**与原子课程关系**：从 L1（应用层）和 L4（编程架构）层选取入门级原子课，按集训节奏重组，配套高强度实践。

**规模**：
- **两天营**：≈14 小时（理论 7 + 实践 7），结业算子 add_rms_norm（矢量单算子）
- **两周营**：≈60 小时（理论 20 + 实践 40），结业算子 add_rms_norm + quant-matmul（双算子 + PyTorch 集成）

**课程结构**：
- 两天营：7 讲（AI 基础→大模型部署→推理优化→Ascend C 矢量算子→PyTorch 接入+CANNBot→结业作业）
- 两周营：13 讲（在两天营基础上扩展矩阵算子、融合算子、调试调优、多卡通信等）

**详细大纲**：[启航营课程总览](./01_bootcamp/README.md)

---

### 2.3 02 传统学科课程（原子课程教学化）

**定位**：CANN/昇腾知识融入大学传统学分课程，采用"换芯不换课"策略——传统课程大纲主体不动，CANN 以单元包/对照案例/实验替换外挂式融入，教师零改造或低改造即可采用。

**与原子课程关系**：将 L4 架构/算子类原子课教学化，融入大学传统课程（体系结构/计组/并行计算等），以单元包/对照案例/实验替换形式外挂融入。

**规模**：
- **计算机组成原理**（本科大二必修）：M2/M5 轻量融入，外挂式 6–8 学时
- **计算机体系结构**（本科高年级/研究生）：M2/M5 主讲融入，"AI 时代的体系结构挑战"三幕剧三次主讲课（各 135 分钟）= 原子课 L4-47~49 教学化
- **其他 12 个学科 15 门课**：并行计算/DL 系统/图像处理/编译/OS/嵌入式/数值/计算科学/数据科学/HPC 等，方向性规划

**融入模式**：
- M2 单元植入：传统课内插入 1–3 个 NPU/CANN 单元
- M3 实验替换：课程主题不变，实验用 Ascend C 重做
- M4 工具透明：课程不教 CANN，但训练/实验默认跑 NPU
- M5 教材渗透：争取进入国内主流教材/讲义的 NPU 章节

**详细大纲**：[传统学科课程目录](./02_traditional_courses/README.md)

## 三、课程质量标准

### 3.1 课件规范

- **结构标准**：每节课包含**钩子**（真实问题/数据开场）、**核心内容**（60%）、**互动检查点**（15%）、**小结与行动出口**（10%）
- **标题标准**：结论式标题，明确传达本课核心观点
- **视觉标准**：图文结合，核心原理配示意图/架构图/流程图

### 3.2 课程大纲标准

- **独立大纲**：每门课程单独大纲，包含课程基本信息、课程目标（OBE）、教学安排、考核方式、学习参考
- **两列实践**：每章节实践配备 cann-learning-hub（教程练习）+ CANNJudge（判题练习）双平台
- **三难度题库**：每章节实践**含易**（跟练跑通）/**中**（变体改造）/**难**（独立实现+性能要求）三题
