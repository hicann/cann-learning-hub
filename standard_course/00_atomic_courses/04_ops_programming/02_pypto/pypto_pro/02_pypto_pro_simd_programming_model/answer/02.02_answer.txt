02.02 课后练习答案

1. pl.DYNAMIC（动态维度）。DYNAMIC 维度值不参与编译特化，值变化复用同一编译变体；STATIC 则会生成新变体。
2. B。stream 与 block_dim 只影响本次启动，不参与编译签名。
3. 参考答案：1 次。首维改为 DYNAMIC 后，[16, 256] 与 [32, 256] 共享同一编译实例（第二维 256 固定不变）；若首维用 STATIC 声明，则两个尺寸会生成两个编译实例；若写成固定整数，则另一尺寸不匹配，会被拒绝，而不是自动生成新实例。仅改 DYNAMIC 标注不能自动处理全部行，必须同时修改循环与搬运坐标。推导依据：JIT 文档"编译签名与复用"。
