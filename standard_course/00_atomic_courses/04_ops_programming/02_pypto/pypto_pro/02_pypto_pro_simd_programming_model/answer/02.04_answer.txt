02.04 课后练习答案

1. 32×64×2 = 4096 = 0x1000 字节；连续排布时第三块起始地址 = 0x0000 + 2×0x1000 = 0x2000。
2. C。L0A/L0B Buffer 要求 512 字节对齐（UB/L1 为 32 字节，L0C 为 64 字节）。
3. 参考答案：FP16 每元素 2 字节，单 Tile = 8×512×2 = 8192 = 0x2000 字节。三个 Tile Group 地址可取 0x0000 / 0x2000 / 0x4000（均为 32 的倍数，满足对齐）。这里元素数翻倍而元素字节数减半，单 Tile 大小恰好仍为 0x2000；该结论来自重新计算，不能推广到其他 shape/dtype。
