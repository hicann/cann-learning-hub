10.06 编程实践参考答案（完整串行参考已提供，待 950 验证）

【实践一】独立 Host 分块参考函数（不代表 Device 功能验证）：
    def plan_rows(seq, block=256):
        assert isinstance(seq, int) and isinstance(block, int)
        assert seq > 0 and block > 0
        return [(start, min(block, seq - start)) for start in range(0, seq, block)]

    assert plan_rows(2048)[-1] == (1792, 256)
    assert plan_rows(3000)[-1] == (2816, 184)
    for seq in (2048, 3000):
        plan = plan_rows(seq)
        assert sum(length for _, length in plan) == seq
        assert plan[0][0] == 0
        assert all(0 < length <= 256 and start + length <= seq for start, length in plan)
        assert all(start + length == next_start
                   for (start, length), (next_start, _) in zip(plan, plan[1:]))

H=128 的逻辑字节数见 10.03 答案；还需重算 AIV 分行、临时区、槽数和地址。
S=3000，块宽256时 ceil(3000/256)=12；最后 Q/KV 块编号11，起点2816，有效长度184。
Q/K/V 尾块的有效范围须传到全部参与搬运/计算的 Tile，causal 三角 mask 另处理。原题3072=12×256，不存在尾块。
