### 3.1 双平台实践

| 平台 | 定位 | 练习类型 | 能力目标 |
|------|------|---------|---------|

### 3.2 三难度分级

每章节实践含**易 / 中 / 难**三题：

| 难度 | 定位 | 题目特征 | 能力要求 |
|------|------|---------|---------|
| 🟢 **易** | 跟练跑通 | 提供完整代码与步骤，学生跟随操作即可完成 | 理解基本概念，能复现示例 |
| 🟡 **中** | 变体改造 | 基于示例进行修改/扩展，需要理解原理并调整参数/代码 | 能理解原理，进行简单改造 |
| 🔴 **难** | 独立实现 + 性能要求 | 独立设计并实现解决方案，需满足正确性与性能指标 | 能独立解决问题，追求极致性能 |

### 4.3 与原子课程的衔接

六门新增课程均由原子课程拼接而成：
- 每门课程的章节对应 1–3 门原子课
- 原子课提供单课深度内容，新增课程提供系统化学习路径
- 原子课编号（L1-xx / L2-xx / L3-xx / L4-xx）在各课程大纲中标注映射关系
- 新增原子课 L1-42~44（推荐系统）、L2-20~29（CANN 训练/推理/图框架/昇腾生态）可作为各课程的补充素材与进阶选修
