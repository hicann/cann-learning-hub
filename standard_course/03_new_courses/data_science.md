| 项目 | 内容 |
|------|------|

## 二、课程目标（OBE 成果导向）

### 2.1 知识目标

完成本课程后，学员能够：

1. **阐述** 数据科学的基本概念、工作流程与应用场景，理解数据驱动决策的核心思想
2. **掌握** 数据采集与预处理的核心方法，理解数据清洗、特征工程、数据增强的原理与实践
3. **理解** 数据伦理与偏差的核心概念，掌握数据隐私保护、算法公平性评估与合规性要求
4. **掌握** 数据可视化的原理与方法，能选择合适的图表类型呈现数据分析结果
5. **理解** 机器学习与神经网络的基本原理，掌握经典模型的训练与评估方法

### 2.2 能力目标

完成本课程后，学员能够：

6. **完成** 数据科学全流程实践：数据采集→预处理→分析→建模→可视化，输出数据分析报告
7. **使用** NPU 加速数据处理与机器学习任务，体验「改一行 import」的零成本迁移，量化加速收益
8. **实现** 经典机器学习模型（分类/回归/聚类）与简单神经网络（MLP/CNN），完成训练与评估
9. **构建** 数据可视化看板，能有效呈现数据分析结论与洞察
10. **评估** 数据与模型的伦理风险，能识别并缓解数据偏差与算法不公平问题

### 2.3 素养目标

11. 建立**数据驱动思维**，能从数据中发现问题、分析问题、解决问题
12. 培养**数据伦理意识**，关注数据隐私、算法公平与合规性，做负责任的数据科学实践者
13. 具备**跨领域应用能力**，能将数据科学方法应用于不同行业场景（金融、医疗、零售、制造等）

## 三、章节规划（6 章）

> 每章实践含**三档难度**：易 = 跟练跑通；中 = 变体改造；难 = 独立实现 + 性能要求。

### 第 1 章：数据科学导论

| 项目 | 内容 |
|------|------|
| **核心内容** | 数据科学的定义与发展脉络；数据科学工作流程（CRISP-DM：业务理解→数据理解→数据准备→建模→评估→部署）；数据科学的应用场景（金融风控、医疗诊断、零售推荐、智能制造等）；数据科学工具栈（Python 生态：NumPy/pandas/scikit-learn/Matplotlib）；数据科学中的数学基础（线性代数、统计学、概率论）；NPU 在数据科学中的角色与加速场景；张量基础与 NPU 数据布局 |
| **原子课映射** | L1-25（深度学习数学与张量基础） |
| **实践设计** | **易**：环境首跑——搭建 Python 数据科学环境，完成 NumPy/pandas 基础操作；**中**：数据集加载——加载真实数据集（如 Titanic、鸢尾花），完成数据探索与基本统计分析；**难**：NPU 数据管线 baseline——使用 AsNumpy 将数据处理迁移到 NPU，对比 CPU 与 NPU 的数据处理速度 |

### 第 2 章：数据采集与预处理

| 项目 | 内容 |
|------|------|
| **核心内容** | 数据采集方法（API 爬取、数据库查询、文件读取、传感器数据）；数据清洗（缺失值处理、异常值检测、重复值去除、数据格式统一）；特征工程（特征构造、特征选择、特征编码、特征缩放）；数据增强（数据扩充、合成数据、SMOTE 过采样）；ETL 流程设计与实现；Python 数据处理加速（AsNumpy、Math-Python、Thrust-Python）；NPU 加速数据预处理管线；数据质量评估与监控 |
| **原子课映射** | L1-25/26（深度学习数学与张量基础、框架入门，节选）+ Python 加速库（L3-10~13） |
| **实践设计** | **易**：AsNumpy 跟练——使用 AsNumpy 完成数组操作，对比 NumPy 与 AsNumpy 的用法与性能；**中**：ETL 变体——针对真实数据集实现完整的 ETL 流程（抽取→清洗→转换→加载），输出清洗后的数据集；**难**：全加速管线——将完整的数据预处理管线迁移到 NPU，量化各环节的加速比，输出性能优化报告 |

### 第 3 章：数据伦理与偏差

| 项目 | 内容 |
|------|------|
| **核心内容** | 数据伦理概述（数据隐私、数据所有权、数据使用边界）；数据偏差来源（采样偏差、测量偏差、标注偏差、历史偏差）；算法公平性（群体公平、个体公平、公平性指标：Demographic Parity、Equalized Odds）；隐私保护技术（数据脱敏、差分隐私、联邦学习概述）；数据合规性（GDPR、个人信息保护法、数据安全法）；数据偏见的真实案例分析（招聘歧视、信贷歧视、人脸识别偏差）；负责任的数据科学实践框架 |
| **原子课映射** | 案例教学（无专属原子课） |
| **实践设计** | **易**：数据审计跟练——对给定数据集进行数据审计，识别潜在的偏差与隐私风险；**中**：公平性评估——训练分类模型并评估其在不同群体上的公平性指标，分析偏差来源；**难**：数据审计报告——针对真实业务场景，完成完整的数据伦理审计报告，包含风险识别、影响评估与缓解建议 |

### 第 4 章：数据可视化

| 项目 | 内容 |
|------|------|
| **核心内容** | 数据可视化原理（视觉感知、数据-墨水比、图表设计原则）；图表类型选择（比较类：柱状图/条形图；分布类：直方图/箱线图；关系类：散点图/热力图；趋势类：折线图；构成类：饼图/堆叠图）；Python 可视化工具（Matplotlib、Seaborn、Plotly）；交互式可视化与仪表盘（Streamlit、Dash）；数据故事讲述（从数据到洞察到行动）；可视化中的常见误区（误导性图表、比例失真、颜色选择不当）；NPU 加速可视化数据预处理 |
| **原子课映射** | Python 生态 + NPU 输出 |
| **实践设计** | **易**：可视化跟练——使用 Matplotlib/Seaborn 对数据集进行基本可视化，绘制常见图表类型；**中**：交互式仪表盘——使用 Streamlit 或 Plotly 构建交互式数据可视化仪表盘，支持多维度数据探索；**难**：数据故事——针对真实数据集，完成完整的数据可视化与故事讲述，输出包含洞察与建议的分析报告 |

### 第 5 章：机器学习

| 项目 | 内容 |
|------|------|
| **核心内容** | 机器学习概述（监督学习/无监督学习/半监督学习/强化学习）；监督学习基础（线性回归、逻辑回归、决策树、随机森林、梯度提升树 XGBoost/LightGBM）；无监督学习（K-Means 聚类、层次聚类、PCA 降维）；模型评估（交叉验证、混淆矩阵、Precision/Recall/F1、AUC-ROC、RMSE/MAE）；超参数调优（网格搜索、随机搜索、贝叶斯优化）；特征重要性分析与模型可解释性（SHAP、LIME）；scikit-learn 风格 API 与 NPU 加速机器学习；NPU 加速训练对比 |
| **原子课映射** | L1-26/27（深度学习框架入门、卷积神经网络基础，机器学习部分） |
| **实践设计** | **易**：sklearn 风格训练——使用 scikit-learn 完成经典机器学习任务（分类/回归），理解训练流程与评估方法；**中**：换模型——在相同任务上对比不同模型（逻辑回归/随机森林/XGBoost）的性能，分析各自适用场景；**难**：加速训练对比——将机器学习训练迁移到 NPU 环境，对比 CPU 与 NPU 的训练速度与模型精度，输出加速方案建议 |

### 第 6 章：神经网络

| 项目 | 内容 |
|------|------|
| **核心内容** | 神经网络基础（人工神经元、激活函数、前向传播、反向传播）；多层感知机（MLP）架构与训练；卷积神经网络（CNN）基础（卷积、池化、经典架构）；神经网络训练技巧（初始化、批归一化、Dropout、学习率调度）；深度学习框架（PyTorch）基础；NPU 上的神经网络训练（torch_npu）；神经网络模型评估与调优；从机器学习到深度学习的过渡；与课程五（深度学习）的衔接 |
| **原子课映射** | L1-27/29（卷积神经网络基础、Transformer 架构与自注意力机制，神经网络基础部分） |
| **实践设计** | **易**：MLP——使用 PyTorch 在 NPU 上实现多层感知机，完成简单分类任务（如 MNIST）；**中**：CNN——实现卷积神经网络，在 CIFAR-10 等数据集上完成图像分类，对比 MLP 与 CNN 的性能；**难**：训练优化判题——针对给定任务，综合运用训练技巧（优化器选择、学习率调度、正则化、数据增强），在限定 epoch 内达到目标精度，通过 CANNJudge 判题 |

## 五、课程特色

1. **全流程覆盖**：从数据采集、预处理、伦理审计、可视化到机器学习、神经网络建模，覆盖数据科学完整工作流程
2. **NPU 加速体验**：实践环节融入昇腾 NPU 加速，体验「改一行 import」的零成本迁移（NumPy→AsNumpy、CPU 训练→NPU 训练），量化加速收益
3. **数据伦理差异化**：专设数据伦理与偏差章节，覆盖数据隐私、算法公平性、合规性等内容，培养负责任的数据科学实践者，是国内数据科学课程的差异化亮点
4. **三难度实践体系**：每章配备易/中/难三档实践题，从跟练跑通到变体改造再到独立实现与性能优化，满足不同基础学员的学习需求
5. **双平台支撑**：cann-learning-hub 提供教程型练习（练"会不会"），CANNJudge 提供判题型练习（练"对不对、快不快"）
6. **与后续课程衔接**：第 5–6 章（机器学习、神经网络）与课程五（深度学习）衔接，为深入学习 CNN/RNN/Transformer、目标检测、强化学习等奠定基础

## 八、学习建议

### 8.1 学习节奏建议

- **基础层（第 1 章）**：建立数据科学全局认知与环境，重点掌握 Python 数据科学工具栈的基本操作
- **数据层（第 2–3 章）**：深入学习数据采集、预处理与伦理审计，这是数据科学的核心基础，决定了后续建模的质量
- **呈现层（第 4 章）**：学习数据可视化与故事讲述，培养将数据洞察有效传达给他人的能力
- **建模层（第 5–6 章）**：学习机器学习与神经网络建模，这是从数据分析到预测决策的关键环节
- 建议每章理论学习后立即完成对应实践，通过动手加深理解；易/中难度必做，难难度选做；特别关注「改一行 import」的 NPU 加速体验，量化加速收益

### 8.2 结业项目建议

- 结业项目从**第 4 周起选题**，建议从以下方向选择：
  - **行业数据分析**：如金融风控分析、医疗数据分析、零售用户画像、制造质量分析
  - **数据产品开发**：如交互式数据仪表盘、数据可视化看板、数据 API 服务
  - **预测建模项目**：如销量预测、客户流失预测、异常检测、推荐系统原型
  - **数据伦理审计**：如针对特定数据集或模型的伦理审计与公平性评估
- 建议在第 8 周完成数据采集与预处理，第 10–12 周完成建模与分析，第 13–14 周完成可视化与报告，第 15–16 周准备答辩

### 8.3 常见问题

| 问题 | 建议 |
|------|------|
| 数学基础不好能学吗？ | 数据科学需要一定的统计学与线性代数基础，但课程会用直观的方式解释核心概念，实践环节注重工程实现；建议课前复习基本统计概念（均值、方差、概率分布），课程中遇到数学问题及时查阅资料 |
| 没有 NPU 硬件怎么办？ | 可使用昇腾云环境，或先完成 CPU 环境的实践，有环境时再体验 NPU 加速；「改一行 import」的迁移体验可先在代码层面完成，性能对比可在有环境时补做 |
| 数据科学与机器学习/深度学习有什么区别？ | 数据科学是更宽泛的概念，涵盖数据采集、预处理、分析、可视化、建模等全流程；机器学习/深度学习是数据科学中的建模方法之一。本课程覆盖全流程，课程五（深度学习）将深入学习建模方法 |
| 结业项目选题困难？ | 建议从自身研究方向、工作场景或兴趣出发，选择有实际价值的题目；也可参考课程提供的四个方向，或使用公开数据集（Kaggle、UCI ML Repository）完成项目，或与任课老师讨论确定 |
| 与课程五（深度学习）如何衔接？ | 本课程第 5–6 章（机器学习、神经网络）是课程五的基础；学完本课程后，可继续学习课程五深入掌握 CNN/RNN/Transformer、目标检测、强化学习、生成模型等深度学习技术 |
