## 二、课程目标与课程内容规划

### 2.1 三维目标

| 目标维度 | 达成要求 |
|---------|---------|
| **知识目标** | ① 阐述机器学习与深度学习的基本概念、发展脉络与数学基础；② 掌握卷积神经网络（CNN）的原理与经典架构，理解图像分类、目标检测等视觉任务；③ 理解循环神经网络（RNN/LSTM）与 Transformer 架构，掌握自然语言处理核心方法；④ 掌握监督学习的训练优化方法（优化器、正则化、数据增强）与强化学习基础；⑤ 理解生成模型（GAN/VAE）的原理与应用 |
| **能力目标** | ① 实现经典深度学习模型（CNN/RNN/Transformer）并在 NPU 环境中完成训练与推理；② 完成图像分类、目标检测、文本分类等典型任务的端到端实践；③ 优化模型训练过程（优化器、正则化、数据增强）；④ 应用强化学习方法解决简单控制任务，理解 RLHF 等对齐技术；⑤ 部署训练好的模型到 NPU 环境并完成推理验证与性能测试 |
| **素养目标** | 建立深度学习系统思维（数据、模型、训练、推理全流程思考）；培养实验设计与分析能力（实验验证假设、分析结果、优化模型）；具备技术选型能力（根据任务特点选择架构与训练策略） |

### 2.2 结业能力画像

完成本课程后，学员将能够：

- **讲得透**：CNN/RNN/Transformer 的原理、经典架构与适用任务
- **写得出**：经典深度学习模型的独立实现，在 NPU 上完成训练与推理
- **调得优**：选择合适的优化器、正则化与数据增强，优化训练收敛与泛化
- **测得准**：设计评估方案，正确使用准确率、mAP、FID 等指标分析模型
- **部得署**：将模型部署到 NPU 环境，完成推理验证与性能测试

## 三、前置内容

### 3.1 知识前置（硬性要求）

| 类别 | 要求 |
|------|------|
| 编程语言 | Python **较熟练**（函数、类、NumPy；PyTorch 基础更好） |
| 数学基础 | 线性代数（矩阵运算、特征值）与概率论基础（概率分布、期望） |
| 领域基础 | 基本机器学习概念（训练/验证/测试、过拟合/欠拟合） |

### 3.2 领域前置（建议完成）

- 课前完成 PyTorch 官方入门教程（张量操作、autograd、nn.Module）；
- 课程四《数据科学》第 5~6 章（机器学习、神经网络）为基础者可直接进阶本课程。

### 3.3 环境前置

- **在线环境（推荐）**：CANNLab 云端开发环境（NPU 训练与推理）；
- **本地环境（可选）**：已部署 CANN 的昇腾开发环境；大部分 PyTorch 代码可先在 CPU 上验证正确性，有环境时切换 NPU。

## 四、教学安排与理论讲义（PPT）（8 讲，建议 16 周内安排）

> 讲义题目与课程大纲中课程内容保持一致，存放在课程对应的 ppt 目录下；本课程讲义建设中，完成后替换「讲义建设中」标注。

|------|------|---------|---------|
| 第 1 讲 | 机器学习与深度学习导论 | 机器学习基本概念（监督/无监督/强化学习）；深度学习发展脉络（从感知机到深度网络）；神经网络数学基础（线性代数、微积分、概率）；深度学习框架入门（PyTorch 基础）；NPU 环境搭建与 torch_npu 快速入门；训练与推理的基本流程 | 2h+2h 起步, 讲义建设中 |

| 第 4 讲 | 卷积网络 | 卷积原理深入（感受野、参数共享、平移不变性）；网络设计原则（深度/宽度/分辨率权衡）；轻量化网络（MobileNet/ShuffleNet/EfficientNet）；注意力机制（SE/CBAM/Self-Attention）；特征金字塔（FPN）与多尺度检测；CNN 可视化与可解释性；NPU 卷积加速原理 | 2h+2h 起步, 讲义建设中 |

| 第 8 讲 | RNN/GAN | 序列建模深入（长序列挑战、梯度消失/爆炸、LSTM 门控）；生成模型概述（显式/隐式）；生成对抗网络（GAN）原理与训练难点（DCGAN/WGAN-GP/StyleGAN）；变分自编码器（VAE）；自回归生成模型；生成模型评估（FID/IS）；NPU 生成模型训练与推理；与《生成式 AI》课程的衔接 | 2h+2h 起步, 讲义建设中 |

## 七、学习建议

### 7.1 学习节奏

- **基础层（第 1 讲）**：建立深度学习基础认知与 NPU 环境，重点掌握 PyTorch 基本操作与训练流程
- **视觉层（第 2~4 讲）**：深入学习 CNN 与计算机视觉任务（分类→检测→网络设计），这是课程的核心部分之一
- **训练层（第 5~6 讲）**：掌握监督学习的训练优化方法与强化学习基础，理解如何让模型训练得更快更好
- **语言层与生成层（第 7~8 讲）**：学习 NLP 与序列建模、生成模型，为《生成式 AI》课程奠定基础
- 每讲理论学习后立即完成对应实践；全部实践基于 NPU 环境（torch_npu 一行代码切换后端）

### 7.2 成功要素

1. **从跟练到独立实现**：每讲实践按「易→中→难」递进，不要停留在跟练
2. **实验记录形成习惯**：记录每次超参调整与架构改动的实验结果，培养实验设计与分析能力
3. **结业项目尽早选题**：建议第 6 周起选题，第 10 周完成项目原型，第 12~14 周优化完善，第 15~16 周答辩
4. **CPU 验证＋NPU 训练**：代码先在 CPU 验证正确性，再切换 NPU 获取性能
5. **数学遇到问题及时查**：课程用直观方式解释核心原理，实践环节注重工程实现

### 7.3 后续学习路径

完成本课程后，可根据兴趣选择深入方向：

| 方向 | 推荐路径 | 目标 |
|------|---------|------|
| **生成式 AI** | 衔接课程六《生成式 AI》：LLM、扩散模型、RAG/Agent、分布式并行 | 大模型全栈能力 |
| **算子开发** | 衔接课程一/课程三：Ascend C 算子编程与性能优化 | 软硬协同优化能力 |
| **NPU 部署工程** | ATC/MindIE 推理部署、量化与服务化 | 推理工程师方向 |
