# 课程五：《深度学习》课程大纲

---

## 一、课程基本信息

| 项目 | 内容 |
|------|------|
| **课程名称** | 深度学习 |
| **课程性质** | 专业选修课（应用核心技术型） |
| **学时安排** | 建议 32–48 学时（理论 16–24 + 实践 16–24），16 周 |
| **授课对象** | 计算机/人工智能相关专业本科高年级、研究生；希望系统掌握深度学习理论与 NPU 实践的工程师 |

## 二、课程目标（OBE 成果导向）

### 2.1 知识目标

完成本课程后，学员能够：

1. **阐述** 机器学习与深度学习的基本概念、发展脉络与核心思想，理解深度学习的数学基础
2. **掌握** 卷积神经网络（CNN）的原理与经典架构，理解图像分类、目标检测等计算机视觉任务
3. **理解** 循环神经网络（RNN/LSTM）与 Transformer 架构，掌握自然语言处理的核心方法
4. **掌握** 监督学习的训练优化方法（优化器、正则化、数据增强）与强化学习基础
5. **理解** 生成模型（GAN/VAE）的原理与应用，了解深度学习的前沿方向

### 2.2 能力目标

完成本课程后，学员能够：

6. **实现** 经典深度学习模型（CNN/RNN/Transformer），在 NPU 环境中完成训练与推理
7. **完成** 图像分类、目标检测、文本分类等典型任务的端到端实践
8. **优化** 模型训练过程，能选择合适的优化器、正则化策略与数据增强方法
9. **应用** 强化学习方法解决简单控制任务，理解 RLHF 等大模型对齐技术
10. **部署** 训练好的模型到 NPU 环境，完成推理验证与性能测试

### 2.3 素养目标

11. 建立**深度学习系统思维**，能从数据、模型、训练、推理全流程思考问题
12. 培养**实验设计与分析能力**，能通过实验验证假设、分析结果、优化模型
13. 具备**技术选型能力**，能根据任务特点选择合适的模型架构与训练策略

## 三、章节规划（8 章）

> 每章实践含**三档难度**：易 = 跟练跑通；中 = 变体改造；难 = 独立实现 + 性能要求。

### 第 1 章：机器学习与深度学习导论

| 项目 | 内容 |
|------|------|
| **核心内容** | 机器学习基本概念（监督/无监督/强化学习）；深度学习发展脉络（从感知机到深度网络）；神经网络数学基础（线性代数、微积分、概率）；深度学习框架入门（PyTorch 基础）；NPU 环境搭建与 torch_npu 快速入门；训练与推理的基本流程 |
| **原子课映射** | L1-25（深度学习数学与张量基础）、L1-26（深度学习框架入门） |
| **实践设计** | **易**：首跑——在 NPU 上完成 PyTorch HelloWorld，训练简单 MLP；**中**：后端切换——将 CPU/GPU 训练代码切换为 NPU 环境，对比训练速度；**难**：训练收敛题——调整超参数使模型在指定数据集上达到目标精度 |

### 第 2 章：图像分类

| 项目 | 内容 |
|------|------|
| **核心内容** | 图像分类任务概述；卷积神经网络基础（卷积、池化、激活函数）；经典 CNN 架构（LeNet/AlexNet/VGG/ResNet）；迁移学习与预训练模型；数据增强方法；图像分类的评估指标（准确率、混淆矩阵）；NPU 图像分类训练与推理 |
| **原子课映射** | L1-27（卷积神经网络基础） |
| **实践设计** | **易**：MNIST 手写数字分类跟练，在 NPU 上训练 LeNet；**中**：CIFAR-10 变体——使用 ResNet 进行图像分类，对比不同网络架构的性能；**难**：自定义数据集图像分类——构建数据管线，实现数据增强，达到目标精度 |

### 第 3 章：目标检测

| 项目 | 内容 |
|------|------|
| **核心内容** | 目标检测任务概述（检测 vs 分类）；两阶段检测（R-CNN/Fast R-CNN/Faster R-CNN）；单阶段检测（YOLO/SSD）；Anchor 机制与 Anchor-Free；非极大值抑制（NMS）；检测评估指标（mAP、IoU、Precision/Recall）；NPU 目标检测推理与部署 |
| **原子课映射** | L1-02（目标检测算法） |
| **实践设计** | **易**：检测跟练——使用预训练 YOLO 模型在 NPU 上进行目标检测推理；**中**：换模型——对比不同检测模型（YOLO/SSD/Faster R-CNN）的精度与速度；**难**：部署题——将检测模型部署到 NPU 环境，优化推理延迟，完成端到端检测应用 |

### 第 4 章：卷积网络深入

| 项目 | 内容 |
|------|------|
| **核心内容** | 卷积原理深入（感受野、参数共享、平移不变性）；网络设计原则（深度/宽度/分辨率权衡）；轻量化网络（MobileNet/ShuffleNet/EfficientNet）；注意力机制（SE/CBAM/Self-Attention）；特征金字塔（FPN）；多尺度检测；CNN 可视化与可解释性；NPU 卷积加速原理 |
| **原子课映射** | L1-27（卷积神经网络基础，深入部分） |
| **实践设计** | **易**：backbone 分析跟练——加载预训练 ResNet，分析各层特征图；**中**：轻量化网络实现——实现 MobileNet 并与 ResNet 对比参数量与推理速度；**难**：自定义 backbone 设计——针对特定任务设计高效网络架构，在精度与速度间取得平衡 |

### 第 5 章：监督学习进阶

| 项目 | 内容 |
|------|------|
| **核心内容** | 损失函数设计（分类损失/回归损失/自定义损失）；优化器深入（SGD/Momentum/Adam/AdamW/Lion）；学习率调度（Step/Cosine/Warmup）；正则化方法（L1/L2/Dropout/Weight Decay）；数据增强（几何变换/色彩变换/Mixup/Cutout）；训练技巧（梯度累积、梯度裁剪、混合精度训练）；过拟合与欠拟合分析；NPU 训练优化实践 |
| **原子课映射** | L1-26（深度学习训练优化）、L1-30（深度学习训练优化，进阶） |
| **实践设计** | **易**：优化器对比跟练——在相同任务上对比 SGD/Adam/AdamW 的收敛速度与最终精度；**中**：正则化实验——对比 Dropout/Weight Decay/数据增强对过拟合的影响；**难**：训练优化挑战——在限定 epoch 内达到目标精度，综合运用多种训练技巧 |

### 第 6 章：强化学习

| 项目 | 内容 |
|------|------|
| **核心内容** | 强化学习基础（MDP、状态、动作、奖励、策略、价值函数）；值函数方法（Q-Learning、SARSA）；策略梯度方法（REINFORCE、PPO）；深度强化学习（DQN、Actor-Critic）；强化学习在游戏/机器人中的应用；大模型对齐中的强化学习（RLHF、RLAIF）；NPU 强化学习训练支持 |
| **原子课映射** | L1-20（强化学习进阶，RLHF 节选）+ 通用 RL 基础 |
| **实践设计** | **易**：CartPole 跟练——使用 DQN 或 PPO 解决 CartPole 控制任务；**中**：算法对比——对比 Q-Learning 与策略梯度方法在不同任务上的表现；**难**：LLM 对齐实践——理解 RLHF 流程，使用小模型进行简单的对齐实验 |

### 第 7 章：自然语言处理

| 项目 | 内容 |
|------|------|
| **核心内容** | NLP 基础（文本预处理、分词、词嵌入）；循环神经网络（RNN/LSTM/GRU）与序列建模；Seq2Seq 模型与注意力机制；Transformer 架构（自注意力、多头注意力、位置编码、Encoder-Decoder）；预训练语言模型（BERT/GPT）；NLP 典型任务（文本分类、命名实体识别、机器翻译、文本生成）；NPU NLP 任务训练与推理 |
| **原子课映射** | L1-14（大语言模型基础）、L1-28（序列模型与循环网络）、L1-29（Transformer 架构与自注意力机制） |
| **实践设计** | **易**：文本分类跟练——使用 LSTM 或 BERT 在 NPU 上完成文本分类任务；**中**：Transformer 实现——从零实现 Transformer Encoder，对比不同架构的性能；**难**：机器翻译/文本生成——实现 Seq2Seq 或 GPT 类模型，完成文本生成任务并优化推理速度 |

### 第 8 章：RNN 与生成模型

| 项目 | 内容 |
|------|------|
| **核心内容** | 序列建模深入（长序列挑战、梯度消失/爆炸、LSTM 门控机制）；生成模型概述（显式/隐式生成模型）；生成对抗网络（GAN）原理与训练难点（DCGAN/WGAN-GP/StyleGAN）；变分自编码器（VAE）原理；自回归生成模型；生成模型评估（FID/IS/人工评估）；NPU 生成模型训练与推理；与课程六（生成式 AI）的衔接 |
| **原子课映射** | L1-28（序列模型与循环网络）、L1-10（生成对抗网络） |
| **实践设计** | **易**：序列生成跟练——使用 RNN/LSTM 生成文本或音乐序列；**中**：GAN 实践——实现 DCGAN，在 CIFAR-10 或自定义数据集上训练生成模型；**难**：生成模型优化——改进 GAN 训练稳定性或实现 VAE/GAN 混合模型，评估生成质量 |

## 五、课程特色

1. **全栈技术覆盖**：从机器学习基础到 CNN/RNN/Transformer，从计算机视觉到自然语言处理到强化学习到生成模型，覆盖深度学习完整知识体系
2. **全 NPU 实践**：所有实践环节基于昇腾 NPU 环境，学员在真实硬件上完成模型训练与推理，积累一手经验；默认使用 torch_npu，一行代码切换后端
3. **三难度实践体系**：每章配备易/中/难三档实践题，从跟练跑通到变体改造再到独立实现与性能优化，满足不同基础学员的学习需求
4. **双平台支撑**：cann-learning-hub 提供教程型练习（练"会不会"），CANNJudge 提供判题型练习（练"对不对、快不快"）
5. **理论与实践并重**：每章既有核心理论讲解，又有对应的实践环节，通过动手加深理解，培养实验设计与分析能力
6. **与后续课程衔接**：第 7–8 章（NLP、生成模型）与课程六（生成式 AI）衔接，为深入学习大模型、扩散模型、RAG/Agent 等前沿技术奠定基础

## 八、学习建议

### 8.1 学习节奏建议

- **基础层（第 1 章）**：建立深度学习基础认知与 NPU 环境，重点掌握 PyTorch 基本操作与训练流程，为后续章节打下基础
- **视觉层（第 2–4 章）**：深入学习 CNN 与计算机视觉任务，从图像分类到目标检测再到网络设计，这是课程的核心部分之一
- **训练层（第 5–6 章）**：掌握监督学习的训练优化方法与强化学习基础，理解如何让模型训练得更快、更好
- **语言层（第 7 章）**：学习 NLP 与序列建模，从 RNN 到 Transformer，理解自然语言处理的核心方法
- **生成层（第 8 章）**：学习生成模型，为课程六（生成式 AI）的深入学习奠定基础
- 建议每章理论学习后立即完成对应实践，通过动手加深理解；易/中难度必做，难难度选做

### 8.2 结业项目建议

- 结业项目从**第 6 周起选题**，建议从以下方向选择：
  - **计算机视觉应用**：如图像分类系统、目标检测应用、图像分割项目
  - **自然语言处理应用**：如文本分类器、情感分析系统、简单聊天机器人
  - **强化学习应用**：如游戏 AI、机器人控制任务
  - **生成模型应用**：如图像生成、风格迁移、文本生成
- 建议在第 10 周完成项目原型，第 12–14 周进行优化与完善，第 15–16 周准备答辩

### 8.3 常见问题

| 问题 | 建议 |
|------|------|
| 数学基础不好能学吗？ | 课程会用直观的方式解释核心原理，实践环节注重工程实现；建议课前复习线性代数（矩阵运算）与概率论基础，课程中遇到数学问题及时查阅资料 |
| 没有 NPU 硬件怎么办？ | 可使用昇腾云环境（ModelArts/昇腾云服务器），或先完成理论学习与代码编写，有环境时补做实践；大部分 PyTorch 代码可先在 CPU 上验证正确性 |
| 深度学习框架不熟怎么办？ | 第 1 章会介绍 PyTorch 基础，建议课前完成 PyTorch 官方入门教程；实践环节从跟练开始，逐步过渡到独立实现 |
| 结业项目选题困难？ | 建议从自身研究方向或兴趣出发，选择有实际价值的题目；也可参考课程提供的四个方向，或与任课老师讨论确定 |
| 与课程六（生成式 AI）如何衔接？ | 本课程第 7–8 章（NLP、生成模型）是课程六的基础；学完本课程后，可继续学习课程六深入掌握大模型、扩散模型、RAG/Agent 等前沿技术 |
