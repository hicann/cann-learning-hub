## 二、课程目标与课程内容规划

### 2.1 三维目标

| 目标维度 | 达成要求 |
|---------|---------|
| **知识目标** | ① 掌握异构并行计算原理与昇腾 NPU 架构（DaVinci、AI Core、存储层次），理解 CANN 三条加速路径（加速库 / 自定义算子 / 模型编译与推理部署）；② 掌握基于加速库快速实现加速的方法（C++ 并行算法库、AclNN 算子库、AsNumpy、通信算子多卡与异构编程）；③ 系统掌握 Ascend C 算子编程（编程模型、SIMD、SIMT、SIMD&SIMT、最佳实践案例、通信算子、通算融合）与 PyPTO、CANNBot 智能开发；④ 掌握基于模型编译、转换与推理部署实现加速的方法（ATC、GE 图融合、AclGraph、PyTorch 图模式、大模型推理优化）；⑤ 建立性能优化方法论与「库 / 自研 / 部署优化」取舍原则 |
| **能力目标** | ① 基于加速库**快速实现**典型场景加速（科学计算、矩阵运算、多卡通信）；② 基于 Ascend C **独立开发** SIMD/SIMT/SIMD&SIMT 算子、通信算子并逼近极致性能；③ 基于 PyPTO 与 CANNBot 提升算子开发效率；④ 基于 ATC/GE/AclGraph/PyTorch 图模式完成模型编译与推理部署优化；⑤ 针对给定场景在三条加速路径中做出合理选型与工程决策 |
| **素养目标** | 建立「架构-编程-调优」系统观，能从硬件架构出发设计高效算法与算子；培养性能工程素养（测量、瓶颈分析、数据驱动决策）与工程决策能力（开发效率、性能、可维护性权衡） |

### 2.2 结业能力画像

完成本课程后，学员将能够：

- **讲得透**：昇腾 NPU 异构架构、三条加速路径（用库 / 自研 / 部署优化）的原理与适用场景
- **用得快**：基于 C++ 并行算法库、AclNN、AsNumpy 与通信算子快速实现典型场景加速
- **写得出**：Ascend C SIMD/SIMT/SIMD&SIMT 算子独立开发并通过 CANNJudge 判题
- **调到优**：借鉴最佳实践案例定位瓶颈，逐步逼近极致性能并产出优化报告
- **部得优**：基于 ATC/GE/AclGraph/PyTorch 图模式完成模型编译、转换与推理部署优化
- **选得对**：针对典型场景完成「库调用 vs 自研算子 vs 部署优化」的性能对比与工程决策

### 2.3 课程内容规划

## 三、前置内容

### 3.1 知识前置（硬性要求）

| 类别 | 要求 |
|------|------|
| 编程语言 | C/C++ **较熟练**（指针与内存管理、结构体、模板基础；建议课前复习 STL）；Python 基础（AsNumpy/PyPTO 实践需要） |
| 系统操作 | Linux 命令行基础（目录/文件/权限/进程/环境变量） |
| 体系基础 | 计算机组成原理基础（存储层次、流水线） |

### 3.2 领域前置（建议完成）

- 并行计算基本概念（任务并行/数据并行、并行分解）；
- 矩阵乘法维度规则与分块乘法思想（第 4~6 讲直接涉及）；
- PyTorch 基础（张量操作、模型定义与 forward，第 8~10 讲直接涉及）。

### 3.3 环境前置

- **在线环境（推荐）**：CANNLab 云端开发环境；
- **本地环境（可选）**：已部署 CANN 的昇腾开发环境（Atlas A2/A3 或 Ascend 950 系列）；无硬件时可先用仿真运行验证代码正确性，性能数据需在真实硬件上获取；
- **多卡环境（第 3、7 讲需要）**：多卡昇腾环境或云上多卡实例。

## 七、学习建议

### 7.1 学习节奏

- **第 1 讲（异构并行计算概述）**：建立异构计算与三条加速路径的全局认知，理解「先用库、再自研、后部署优化」的课程主线
- **第 2~3 讲（第一部分·加速库快速实现）**：掌握「用库」的快速加速路径——C++ 并行算法库、AclNN、AsNumpy 与通信算子，先能快速解决实际问题
- **第 4~8 讲（第二部分·自定义算子）**：课程核心，深入 Ascend C SIMD/SIMT/SIMD&SIMT 算子开发、最佳实践案例、通信算子与通算融合，并掌握 PyPTO 与 CANNBot 提升开发效率；建议投入最多时间，完成从跟练到独立实现的过渡
- **第 9~10 讲（第三部分·编译部署加速）**：掌握 ATC/GE/AclGraph/PyTorch 图模式与推理优化，打通从算子到部署的全链路加速能力

### 7.2 成功要素

1. **「先用库、再自研、后部署优化」认知路径是主线**：先掌握三条加速路径各自的适用场景与快速上手方法，再深入自研算子逼近极致性能，最终以部署优化打通端到端，形成完整的工程决策能力
2. **每讲理论学习后立即实践**：易/中难度必做，难难度选做；通过 CANNJudge 判题检验学习效果
3. **结业项目尽早启动**：建议第 8 周起选题（算子极限优化/并行算法/多卡优化/库与手写对比/推理部署优化），第 10 周完成基线实现，第 12~14 周性能优化，第 15~16 周答辩与竞赛展示
4. **双路线按需选择**：初次学习建议 A2/A3 路线（资料完善）；有基础或希望学习最新架构特性建议 950 路线（SIMD/SIMT 双模式）
5. **性能数据要在真实硬件上获取**：仿真模式可验证代码正确性，性能优化需真实硬件

### 7.3 后续学习路径

完成本课程后，可根据兴趣选择深入方向：

| 方向 | 推荐路径 | 目标 |
|------|---------|------|
| **算子极致性能** | A2/A3 极致性能三课（L4-20~22）→ 950 极致性能（L4-23~25） | 独立开发达到理论峰值 90%+ 的高性能算子 |
| **算子工程化** | 算子入图（L4-28）→ Aclnn 工程化开发（L4-29）→ 通信算子自定义开发（L4-30） | 算子库级工程化能力 |
| **多语言算子范式** | PyPTO（L4-31~35）→ TileLang（L4-36~40）→ PyAsc（L4-41~44） | 掌握多种算子编程范式 |
| **大模型训推优化** | 衔接课程一《AI 计算与神经网络计算架构实践》第一部分（训推全链路） | 大模型系统优化专家 |
