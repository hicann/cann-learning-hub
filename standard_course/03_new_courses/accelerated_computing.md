## 二、课程目标（OBE 成果导向）

### 2.1 知识目标

完成本课程后，学员能够：

1. **系统掌握** Ascend C 多层级编程模型，理解 SIMD/SIMT 执行模型、核函数结构、多级内存管理、同步机制与算子分类
2. **掌握** 典型并行计算模式（规约、扫描、矩阵乘、模板计算）的原理与实现方法，理解并行算法设计的核心思想
3. **理解** 多卡并行编程与集合通信原理，掌握 HCCL 通信库的使用与通信-计算重叠优化
4. **掌握** 常见加速库（Aclnn、GE、领域加速库）的使用方法，理解库调用与手写算子的取舍原则
5. **建立** 性能优化方法论，掌握 Roofline 分析、profiling 工具使用与瓶颈定位方法

### 2.2 能力目标

完成本课程后，学员能够：

6. **独立开发** 基于 Ascend C 的矢量、矩阵、融合算子，完成调试调优与性能优化
7. **实现** 典型并行算法（规约、扫描、矩阵乘），理解并行分解与负载均衡策略
8. **完成** 多卡并行编程，使用 HCCL 实现集合通信，优化通信-计算重叠
9. **评估** 库调用与手写算子的性能差异，能根据场景做出合理的工程决策
10. **通过** CANNJudge 泛化算子判题，完成算子极限优化竞赛，追求极致性能

### 2.3 素养目标

11. 建立**「架构-编程-调优」系统观**，能从硬件架构出发设计高效算法与算子
12. 培养**性能工程素养**，注重性能测量、瓶颈分析与数据驱动的优化决策
13. 具备**工程决策能力**，能在开发效率、性能、可维护性之间做出合理权衡

## 三、章节规划（4 章）

> 每章实践含**三档难度**：易 = 跟练跑通；中 = 变体改造；难 = 独立实现 + 性能要求。

### 第 1 章：Ascend C 编程模型

| 项目 | 内容 |
|------|------|
| **核心内容** | 异构计算原理与昇腾 NPU 架构概述（DaVinci 架构、AI Core 三核分工、存储层次、DMA 搬运）；Ascend C 编程语言定位与核心特性；编程模型核心要素（核函数定义、多级内存管理 GM/L1/UB/L0/RegFile、同步机制、算子分类）；多层级编程 API（C API/Tensor API/基础 API/高阶 API/PyAsc）；SIMD 矢量编程（Memory 矢量与 Reg 矢量、数据搬运、掩码与尾块处理）；SIMD 矩阵编程（Cube 单元、矩阵分块 Tiling、数据布局 ND/NZ Format、GEMM 完整流程）；融合算子编程（算子融合原理、GEMM+Bias+Activation 融合、AIC/AIV 分离式编程）；算子调试调优方法论（profiling 工具、性能分析、常见瓶颈与优化）；A2/A3 与 Ascend 950 双路线对比 |
| **原子课映射** | L4-01~10（A2A3/950 双路线编程模型 + 矢量/矩阵算子） |
| **实践设计** | **易**：`ascendc_operator_development(_light)` 全流程跟练——完成 Add 矢量算子开发、编译、运行与验证；**中**：变体改造——实现 Matmul 矩阵算子，调整 Tiling 分块参数对比性能，实现简单融合算子（Add+ReLU）；**难**：泛化判题——完成 Add→Matmul→融合算子的三题组泛化判题（任意 shape/数据类型），追求性能达标 |

### 第 2 章：典型并行模式

| 项目 | 内容 |
|------|------|
| **核心内容** | 并行计算基础（任务并行/数据并行、并行分解、负载均衡、依赖分析）；规约（Reduce）模式（求和/求最大值/求最小值，并行规约算法、树状规约、分块规约）；扫描（Scan）模式（前缀和、并行扫描算法、Blelloch Scan、分块扫描）；模板（Stencil）计算（热传导、卷积、邻域操作、边界处理）；矩阵乘（GEMM）并行模式（分块算法、Cache 分块、寄存器分块、数据打包、流水优化）；直方图与排序并行模式；并行模式的性能分析（算术强度、访存模式、同步开销）；NPU 上的并行模式映射与优化 |
| **原子课映射** | L1-35（并行模式）、L4-15~18（典型算子实践） |
| **实践设计** | **易**：归约/scan 教程跟练——实现并行求和规约与前缀和扫描，理解并行算法流程；**中**：变体改造——实现分块规约或分块扫描，对比不同分块大小的性能，实现 Stencil 模板计算（如热传导）；**难**：判题挑战——完成规约算子/scan 算子的三难度判题（正确性 + 性能要求），实现高性能 GEMM 分块优化 |

### 第 3 章：多卡编程

| 项目 | 内容 |
|------|------|
| **核心内容** | 多卡并行计算动机（算力/显存扩展、大规模模型训练）；多卡系统架构（HCCS 片间互联、RoCE 跨机互联、超节点 SuperPod）；集合通信原理（AllReduce、AllGather、ReduceScatter、Broadcast、AllToAll）；通信算法（Ring 算法、Tree 算法、Halving-Doubling 算法）；HCCL 通信库使用（通信组管理、集合通信 API、通信-计算重叠）；数据并行编程（DDP 原理、梯度同步、多卡训练流程）；张量并行（TP）原理与实现（纵切/横切、AllReduce 通信）；自定义通信算子开发（ASC 架构、通信算法实现、拓扑感知通信）；多卡性能优化（通信开销分析、通信隐藏、拓扑感知调度） |
| **原子课映射** | L1-32（分布式基础）、L3-06/07（HCCL/自定义通信）、L2-01（分布式训练框架） |
| **实践设计** | **易**：`hccl_development` 跟练——使用 HCCL 实现多卡 AllReduce/Broadcast，理解集合通信流程；**中**：变体改造——实现多卡数据并行训练，对比单卡与多卡的训练速度与加速比，实现通信-计算重叠；**难**：多卡通信组合题——实现张量并行或自定义通信算子（如 AllToAll），分析通信瓶颈并优化，完成多卡通信性能基准测试 |

### 第 4 章：常见加速库

| 项目 | 内容 |
|------|------|
| **核心内容** | 加速库概述（CANN 加速库体系、库与手写算子的定位与关系）；Aclnn 算子库（算子分类、调用流程、Workspace 管理、流式执行、常用算子 API、自定义扩展）；GE 图引擎（图编译原理、算子融合、内存复用、图执行下沉、自定义图 PASS）；领域加速库（FFT 快速傅里叶变换、BLAS 基础线性代数、稀疏线性代数）；通信库（HCCL 集合通信、HIXL 单边通信）；Ascend C 生态库（asc-stl 容器与算法、asc-mathdx 数学函数、高阶 API）；库调用 vs 手写算子的取舍分析（开发效率、性能上限、可维护性、适用场景）；库调用性能优化（参数调优、批量处理、内存复用）；库与手写算子的混合编程 |
| **原子课映射** | L3-01~05（Aclnn/GE）、L4-19（生态库） |
| **实践设计** | **易**：`first_operator_api_call` 跟练——使用 Aclnn 实现 GEMM+Add+ReLU 推理流程，理解库调用流程；**中**：变体改造——使用 GE 图引擎实现计算图优化，对比库调用与手写算子的性能差异，使用领域加速库（FFT/BLAS）完成科学计算任务；**难**：库调用 vs 手写对比报告——针对典型场景（如 GEMM、卷积、规约），完成库调用与手写算子的性能对比分析，输出工程决策建议报告，实现库与手写混合编程优化 |

## 四、结业设计

### 4.1 算子极限优化竞赛

任选一个已判题算子（如 GEMM、规约、融合算子）做极限优化：

- **正确性门禁**：算子必须通过正确性验证（任意 shape/数据类型）
- **性能排行**：按性能（算力利用率、延迟、吞吐量）进行班级排行
- **优化报告**：提交优化过程报告，包含性能分析、瓶颈定位、优化策略、前后对比数据
- **答辩展示**：优秀作品进行课堂展示与经验分享

### 4.2 结业项目选题方向

| 方向 | 内容 | 难度 |
|------|------|------|
| 算子开发 | 独立开发一个复杂算子（如 Attention、LayerNorm、Conv2D），完成调试调优 | ★★★ |
| 并行算法 | 实现一个高性能并行算法（如排序、稀疏矩阵乘、图算法），优化到接近理论峰值 | ★★★★ |
| 多卡优化 | 实现多卡并行训练或推理，优化通信-计算重叠，分析可扩展性 | ★★★★ |
| 库与手写对比 | 针对特定场景，完成库调用与手写算子的深度对比，输出工程决策框架 | ★★★ |

## 六、课程特色

1. **「先手写后用库」认知路径**：第 1–2 章手写算子建立底层理解（知其所以然），第 4 章使用加速库并论证取舍（工程决策能力），培养从底层到系统的完整认知
2. **双路线架构支持**：同时支持 A2/A3 与 Ascend 950 双路线，学员可根据硬件环境选择，理解架构演进与编程模型差异
3. **三难度实践体系**：每章配备易/中/难三档实践题，从跟练跑通到变体改造再到独立实现与性能优化，满足不同基础学员的学习需求
4. **双平台支撑**：cann-learning-hub 提供教程型练习（练"会不会"），CANNJudge 提供判题型练习（练"对不对、快不快"）
5. **算子极限优化竞赛**：结业设计采用优化竞赛形式，以正确性门禁 + 性能排行激发学员追求极致性能的热情，培养性能工程素养
6. **与启航营衔接**：两周启航营的双 API 对照（C API vs Tensor API）即本课程第 1 章的预演，启航营结业算子可作为本课程的进阶起点

## 九、学习建议

### 9.1 学习节奏建议

- **第 1 章（编程模型）**：这是课程的核心基础，建议投入最多时间，重点掌握 Ascend C 编程模型与矢量/矩阵算子开发，完成从跟练到独立实现的过渡
- **第 2 章（典型并行模式）**：在掌握算子开发基础后，学习并行算法设计，理解规约、扫描、矩阵乘等典型模式的并行化思路，培养并行思维
- **第 3 章（多卡编程）**：从单卡扩展到多卡，理解集合通信原理与多卡并行编程，注意多卡环境的搭建与调试
- **第 4 章（加速库）**：在手写算子建立底层理解后，学习加速库的使用，重点培养「库 vs 手写」的工程决策能力
- 建议每章理论学习后立即完成对应实践，通过动手加深理解；易/中难度必做，难难度选做；特别关注 CANNJudge 判题，通过判题检验学习效果

### 9.2 结业项目建议

- 结业项目（算子极限优化竞赛）从**第 6 周起选题**，建议从以下方向选择：
  - **GEMM 极限优化**：针对矩阵乘算子，从分块策略、数据打包、流水优化等方面进行极致优化
  - **融合算子优化**：针对典型融合算子（如 GEMM+Bias+GELU、Attention），优化访存与计算重叠
  - **规约/scan 高性能实现**：针对规约或扫描算子，优化分块策略与访存模式
  - **多卡通信优化**：针对集合通信或多卡并行训练，优化通信-计算重叠与可扩展性
- 建议在第 8 周完成算子基线实现，第 10–12 周进行性能优化，第 13–14 周完成优化报告，第 15–16 周准备答辩与竞赛展示

### 9.3 常见问题

| 问题 | 建议 |
|------|------|
| C/C++ 基础薄弱能学吗？ | Ascend C 基于 C/C++，需要一定的 C/C++ 基础；建议课前复习 C++ 基本语法（指针、引用、模板、STL），课程中从简单算子开始跟练，逐步过渡到复杂算子 |
| 没有 NPU 硬件怎么办？ | 可使用昇腾云环境，或先完成代码编写与仿真运行（Ascend C 支持仿真模式），有环境时再进行真实硬件测试与性能优化；仿真模式可验证代码正确性，但性能数据需在真实硬件上获取 |
| A2/A3 与 950 双路线如何选择？ | 初次学习建议 A2/A3 路线（资料完善，入门门槛较低）；有基础或希望学习最新架构特性建议 950 路线（支持 SIMD/SIMT 双模式）；学有余力者可对比两条路线的差异，加深对架构演进的理解 |
| 算子开发难度大，调试困难怎么办？ | 建议先跟练 cann-learning-hub 教程，理解每一步原理；从简单算子（Add/ReLU）开始，逐步过渡到复杂算子（Matmul/融合）；善用调试工具（仿真运行、profiling、日志），遇到问题及时查阅文档与社区论坛 |
| 与启航营如何衔接？ | 两周启航营的算子开发内容是本课程的入门预演；如果已完成启航营，可直接从第 1 章中难度实践开始，重点放在性能优化与复杂算子开发上；启航营结业算子（add_rms_norm/quant-matmul）可作为本课程结业项目的基础 |
