## 三、新增专题：从 CPU 到 NPU——AI 算力底座与 Ascend C 实践（2~3 学时 · 一次课，● 主讲，两版通用）

> **主题主线**（三问递进）：**算力之问**（AI 负载有何不同，CPU 为何"算不动"）→ **芯片之芯**（达芬奇架构与 AI Core 深度解剖）→ **编程之道**（用 Ascend C 释放 NPU 极致算力）——从"为什么"到"是什么"再到"怎么用、怎么快"，形成负载驱动的完整闭环。
> **插入位置**：2024 版 = 模块 13 之后、实验一之前（理论收尾）；未来学院版 = **模块 8（并行架构）之后**——先讲传统并行（多线程/多核），再讲 AI 时代的并行（NPU 众核异构），专题即模块 8 的当代延伸与全课收束。
> **前置条件**：两版均要求五大部件、存储层次、指令系统、控制器、总线与 DMA 已讲完——专题可把全课知识在 NPU 上"重演"一遍。

### 3.1 三课时教学设计

| 课时 | 主题 | 内容要点 | 呼应传统模块（两版知识锚点） |
|------|------|---------|------------------------|
| 课时 1 | **算力之问：AI 负载有何不同，CPU 为何"算不动"** | ① 大模型负载画像：核心是大规模矩阵乘法（90%+ FLOPs）+ 海量权重访存 + 融合算子；② 性能指标新维度：TOPS、TOPS·W⁻¹、内存带宽（对 CPI/MIPS 的补充）；③ CPU 三面墙：晶体管分配（>50% 给 Cache/控制）、功耗墙、访存墙（DDR 带宽 vs 权重读取）；④ Flynn 分类落地：SISD → SIMD → GPU SIMT → NPU 达芬奇（阵列机思想复兴）；⑤ 异构计算：CPU 指挥、NPU 演奏（Host/Device 分工、SPMD 执行模型） | 2024 模块 1/9 · 未来模块 1（性能指标、冯·诺依曼） |
| 课时 2 | **芯片之芯：达芬奇架构与 AI Core 深度解剖** | ① AI Core 计算引擎：Cube 脉动阵列（矩阵乘，↔ 阵列乘法器的极致化）/ Vector（矢量）/ Scalar（标量控制）——运算器的专用化重组；② 多级存储层次：L0A/L0B/L0C ↔ L1 ↔ UB ↔ GM，对照寄存器/Cache/主存；**关键对照：Cache 硬件自动管理 vs UB 软件显式管理**；③ 数据搬运引擎：MTE（GM↔UB↔L0 多级搬运）、NDDMA、对齐/非对齐、ND/NZ 布局；④ 指令与执行：矩阵/矢量/标量/搬运四类指令的分类视角；⑤ 系统级：多 AI Core 协同、HCCS 互联与超节点；⑥ 昇腾 950 演进一瞥（SIMD/SIMT 双模、大容量 L2）；⑦ 收尾设问：层次这么多、搬运这么复杂，**谁来管？**——硬件把管理权交给软件 → 引出课时 3 | 2024 模块 3/5/6/8/10/11 · 未来模块 2/3/5/6/7（阵列乘法器 → Cube、存储层次/对齐、指令分类、总线 → HCCS、DMA → MTE） |
| 课时 3 | **编程之道：用 Ascend C 释放 NPU 极致算力** | ① 编程环境一分钟：CANN 分层鸟瞰（torch_npu 框架适配 → 图引擎 GE/算子库，用现成算子 → **自定义算子 = Ascend C**，本课主线）；② Ascend C 编程模型：SPMD 核函数（`__aicore__`）、Host 侧任务下发、GlobalTensor/LocalTensor、TPipe/TQue 队列化内存管理与同步——课时 2"UB 软件管理"的代码落地；③ 代码实操：Add 矢量算子全流程（初始化 → DataCopy 搬入 → 计算 → 搬出，TQue 双队列同步），Matmul 高阶 API 一瞥；④ **优化方法论**：Tiling 分块（UB 容量约束下切块 = 局部性原理软件化）、双缓冲流水（搬运与计算重叠 = 流水线思想的数据块级重现）、访存优化（对齐/ND 布局/搬运最小化）；⑤ 优化闭环：msprof 采集 → 单元利用率/流水图 → 瓶颈定位 → 优化验证（性能分析方法论回归）；⑥ 收束：负载 → 架构 → 编程 → 优化全链路图 + 学习路径 | 2024 模块 1/5/8/9/11 · 未来模块 1/3/5/7（软硬件逻辑等价、局部性 → Tiling、数据通路与流水 → 双缓冲、DMA → DataCopy/MTE） |

### 4.2 未来学院版模块 8"并行计算机体系结构"× NPU（实例级深化，2024 版无对应模块）

| 单/多处理器系统中的并行性；多处理器系统分类（Flynn） | 对照卡（○）：SIMD 阵列机思想在 NPU 的复兴；异构多处理器（CPU+NPU）作为"多处理器系统"的当代主流形态 |
| 多线程与超线程处理器 | 对照卡（○）：NPU 无超线程，用核间流水与同步原语（barrier/SetFlag/WaitFlag）编排并行——两种并行组织哲学对照 |
| **多核处理器实例** | **实例植入（◐→●，约 1 学时内嵌）：昇腾 AI Core 众核**——典型配置（24 AIC + 48 AIV）、SPMD 单程序多副本、多核数据分块与负载均衡、核间同步 |
| 模块 8 收尾 → 专题衔接 | 设问："通用多核已到功耗墙，AI 负载需要什么并行形态？"→ 紧排 2~3 学时专题 |

> **关联阅读锚点（未来学院版参考书）**：Hennessy《计算机组成与设计》"领域专用架构（DSA）"章节是 NPU 的学术谱系出处；CSAPP 第 6 章"存储器层次结构"与 UB/Cache 对照阅读。
