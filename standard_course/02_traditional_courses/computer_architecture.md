## 三幕剧设计总纲

**戏剧框架**：三节课 = 一场甲乙方项目的三个会议——学生全程扮演**评审团 → 架构师 → 性能医生**三种角色；三张产出物（甲方需求清单 → 乙方答辩表 → 终章设计清单）贴墙形成"合同对照墙"。

```
第一幕·需求评审会（课次9）   大模型这个甲方到底要什么？→ 产出《甲方需求清单》
第二幕·方案评审会（课次10）  达芬奇+CANN 怎么接单？  → 逐条验收 + 《乙方答辩表》
第三幕·验收调优会（课次11）  车开不到标谁的责任？     → 病历诊断 + 《终章设计清单》
```

## 通用工具箱（开课先立规矩）

**问题引导六法**：数量级竞猜 / 认知冲突 / 苏格拉底追问链（三问递进，末问悬置）/ 角色代入 / 反事实 / 甲方乙方。
**研讨五式**：结构化辩论（证据卡+时间盒+裁决给框架）/ 白板共创+画廊漫步 / 病历诊断 / Think-Pair-Share / 竞猜抢答。

## 课次 9｜第一幕·需求评审会（135'）

| 时段 | 环节 | 要点 |
|------|------|------|
| 0–45' | 三连数量级竞猜开场 → 甲方画像 5W1H → 白板共创算子 DAG → 存储特征"三种货物"（权重=常驻户/激活=快递/KV=长租客） | 计算/存储特征画像 |
| 50–95' | 访存"验伤"（三种局部性 vs Cache）→ Roofline 分组手算+投票 → **苏格拉底三连问**（摸鱼模块→能裁吗→**谁干活？悬置**）→ CPU→GPU SIMT 演进（容忍 vs 消除延迟） | 访存特征+CPU 困境 |
| 100–135' | 🗳️ **结构化辩论：「SIMT 是不是最终编程形态？」**（正反方证据卡）→ GPU 演进三部曲 → 行动出口（交《甲方需求清单》） | 辩论+伏笔② |

## 课次 10｜第二幕·方案评审会（135'，全章主体）

| 时段 | 环节 | 要点 |
|------|------|------|
| 0–45' | 回收辩论 + die photo 找茬 → **需求-方案对照总表**（逐格点亮）→ 维度一**三核异构=磨坊分工**（Cube=磨盘/Vector=排刀/Scalar=主厨）+ 面积经济学竞猜（16%/80%/90%+） | 计算单元 |
| 50–95' | 维度二**自动挡→手动挡**（CPU Cache vs 达芬奇 Tiling；三机制去向对照表）→ 维度三**数据搬运快递规则**（32B 对齐=标准托盘/ND-NZ=货架/NDDMA=认路老司机）+ Think-Pair-Share | 存储+搬运 |
| 100–135' | 维度四**编程模型变速箱系列**（C API=手动挡赛车/Tensor API=自动挡/PyPTO=智能驾驶）+ GELU 三写法投票 → 🗳️ **乙方答辩一分钟纸** | 编程模型+答辩 |

## 课次 11｜第三幕·验收调优会（135'）

| 时段 | 环节 | 要点 |
|------|------|------|
| 0–45' | 认知冲突开场（GELU 3ms vs 0.3ms）+ **双悬念回收** → 优化方法论总纲（医生三问：哪里慢→为什么→开什么药）→ 维度一**数据与任务规划**（Tiling 排班手算 + PD 分离呼应"KV 长租客"） | 方法论+维度一 |
| 50–95' | 维度二**流水并行**（三重流水）→ 维度三**访存优化**（处方清单回链第二幕快递规则）→ 维度四**计算优化**（标量/Reg 矢量/矩阵三层）+ 🗳️ **病历诊断**（三份病历：搬运墙/流水断裂/占用率低） | 维度二三四 |
| 100–135' | 搬运墙能耗阶梯 → **超节点**（HCCS/AMAT 尺度扩展/AllReduce 环形/HCCL）→ 🗳️ **终章设计清单一分钟纸** → 金句收束（预告 Interconnect 章） | 单芯片极限+收束 |

## CANN 内容融入清单（占比约 30%）

| 幕 | 体系结构概念 | CANN 对应物 | 深度 |
|----|------------|------------|------|
| 一 | 局部性/Roofline | msprof 剖析（算子分布/自动融合证据） | 演示 |
| 二 | 功能单元/面积 | 三核 + SIMD/SIMT 双模式 | 精讲 |
| 二 | 存储层次三机制 | Tiling/DataCopy/UB 复用/asc_lock·mem_bar；`__gm__/__ubuf__` | 对照表 |
| 二 | 流水线/DMA | TQue 双缓冲；NDDMA/ND-NZ/对齐 | 代码走读 |
| 二 | 抽象层次 | 多级 API（C API→Tensor API→PyPTO） | 三写法并排 |
| 三 | 剖析方法论 | msprof 四问 | 方法论 |
| 三 | 分块/局部性 | Tiling 排班+融合+对齐+KV 池化 | 处方清单 |
| 三 | AMAT 扩展 | 超节点 HCCS/HCCL/AllReduce | 精讲 |
