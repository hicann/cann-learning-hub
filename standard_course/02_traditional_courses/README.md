### 6.2 三幕剧核心内容概要

#### 第一幕·需求评审会（课次 9）

**核心内容：**
- 大模型负载画像：算子 DAG 四类（MatMul / Attention / Elementwise / Reduce）；存储特征（权重=常驻户 / 激活=快递 / KV Cache=长租客）；访存特征与 Roofline 现场手算
- CPU 的困境：苏格拉底三连问（哪些模块在摸鱼 → 摸鱼的能裁吗 → 裁掉后谁来干活）；功耗墙与 Amdahl
- CPU→GPU SIMT 演进：GPU 为图形而生的历史包袱变红利；SIMT 三件套（warp 锁步 / 海量线程容忍延迟 / 分支发散代价）；ILP 消除延迟 vs TLP 容忍延迟的哲学对照
- 结构化辩论：「SIMT 是不是 AI 计算的终点？」（正方：生态壁垒/灵活性；反方：能效差/负载静态/专用单元出现）；教师裁决框架 = 负载确定性

**体系结构回归：** 局部性 / Roofline / 延迟容忍 vs 消除

#### 第二幕·方案评审会（课次 10）

**核心内容：**
- 需求-方案对照总表（上节课甲方需求清单逐条应答）
- **维度一·计算单元**：三核异构 = 磨坊分工（Cube=磨盘 / Vector=排刀 / Scalar=主厨）；面积经济学竞猜（CPU/GPU/NPU 计算面积占比）；SIMD/SIMT 双模式 = "两个都要"的工程答案
- **维度二·存储层次**：CPU Cache=自动挡 vs 达芬奇 UB/L1/L0=手动挡赛车；三机制去向对照表（硬件预取→软件 Tiling / 硬件替换→UB 复用规划 / 硬件一致性→同步原语）；`__gm__/__ubuf__` 地址空间限定符；TQue 双缓冲
- **维度三·数据搬运**：对齐/非对齐（标准托盘 vs 零担）；ND/NZ Layout（分区编号货架）；NDDMA（会认路的老司机，多维搬运一次指令）
- **维度四·编程模型**：多级 API = 同一底盘配不同变速箱（C API=手动挡赛车 / Tensor API=自动挡 / PyPTO·框架层=智能驾驶）；同一段 GELU 三种写法并排展示
- 乙方答辩：一分钟纸验收（甲方需求→我的方案→最大疑问）

**体系结构回归：** 功能单元面积权衡 / 存储层次管理权转移 / DMA / 抽象层次与代价

#### 第三幕·验收调优会（课次 11）

**核心内容：**
- 悬念回收：GELU 3ms vs 0.3ms 认知冲突；揭晓前两幕悬念
- 优化方法论总纲：医生三问（哪里慢→为什么慢→开什么药）；msprof 剖析
- **维度一·数据与任务规划**：Tiling 排班（tile 大小与 UB 容量权衡）；多核分块与负载均衡；PD 分离（Prefill=批量入住 / Decode=逐间服务）
- **维度二·流水并行**：三重流水（MTE 搬运 / Cube·Vector 计算 / 输出回写）；通信计算重叠；流水线思想从指令级→数据块级→集群级的三次登场
- **维度三·访存优化**：处方清单（能融合就融合 / 能对齐必对齐 / ND-NZ 让 DMA 认路 / KV 池化复用）
- **维度四·计算优化**：标量优化 / Reg 矢量优化（VL=256B）/ 矩阵计算（Cube 分块）
- 病历诊断：3 份病历（搬运墙 / 流水断裂 / 占用率低）→ 小组开诊断+药方 → 当堂揭晓
- 单芯片极限与超节点：搬运墙能耗数据；175B 放不进单芯片 GM；超节点 HCCS 让"对端芯片 GM"成为存储层次第 N+1 层；模型切分（TP/PP/DP）= Tiling 思想的尺度重现；AllReduce 与 HCCL
- 终章设计清单一分钟纸；金句收束："体系结构的演进 = 存储层次的持续重构：AI 让管理权流向软件（CANN），让层次跨出芯片（超节点/互联）"

**体系结构回归：** 剖析方法论 / 分块与局部性 / 流水线 / AMAT 尺度扩展

### 6.4 考核融入

| 题型 | 考查概念 |
|------|---------|
| 概念辨析 | SIMT vs SIMD vs 达芬奇 Cube 阵列执行模型；"自动挡（CPU Cache）vs 手动挡（达芬奇 Tiling）"适用负载 |
