# 启航营课程总览（Bootcamp）

> 面向 CANN 算子开发入门者的集中式训练营，分为**两天营**与**两周营**两档，理论与实践 1:1 配对，以真实算子开发为主线，结业即可具备 NPU 算子开发与集成能力。

---

## 一、课程概览

| 维度 | 两天营 | 两周营 |
|------|--------|--------|
| **总学时** | 2 天 ≈ 14h | 10 个工作日 ≈ 60h |
| **学时分配** | 理论 7h + 实践 7h（每讲 1:1 配实践） | 理论 20h + 实践 40h（D3–D8 上午理论 2h + 下午 2~4h 实践） |
| **结业算子主线** | `add_rms_norm`（矢量单算子）→ 可选 PyTorch 接入 / 性能优化 | `add_rms_norm` + `quant_matmul`（双算子）+ 必选 PyTorch 集成 + 可选优化 |
| **目标学员** | 有 C/C++ 基础、希望快速了解 NPU 算子开发的工程师 | 有一定编程基础、希望系统掌握 NPU 算子开发与优化的工程师 |
| **前置要求** | C/C++ 基础；了解Makefile/GIT操作等 | C/C++ 基础；了解Makefile/GIT操作等 |
| **结业标准** | 独立完成矢量算子开发，理解 NPU 编程模型 | 独立完成矢量+矩阵双算子开发，并集成到 PyTorch 框架 |
| **课程大纲** | [两天营详细大纲](./syllabus_two_days_bootcamp.md) | [两周营详细大纲](./syllabus_two_weeks_bootcamp.md) |
| **讲义目录** | [two_days_course/](./two_days_course/)（7 讲） | [two_weeks_course/](./two_weeks_course/)（13 讲） |

## 二、排课节奏

### 2.1 通用原则

- **理论与实践配对**：每讲理论课后立即配套对应实践作业，实践内容与 PPT 实践环节对齐；
- **渐进式难度**：从跟练 → 变体改造 → 独立实现，逐步提升自主开发能力；
- **即时反馈**：每日实践作业通过 CANNJudge 自动判题，即时获得正确性与性能反馈。

### 2.2 两天营节奏（7 讲）

| 时间 | 内容 | 形式 |
|------|------|------|
| Day 1 上午 | 第 1–2 讲：异构计算导论 + Ascend C 编程模型 | 理论 + 跟练实践 |
| Day 1 下午 | 第 3–4 讲：矢量编程 + 数据搬运 | 理论 + 独立实践 |
| Day 2 上午 | 第 5–6 讲：融合算子 + 调试调优 | 理论 + 综合实践 |
| Day 2 下午 | 第 7 讲 + 结业答辩：算子集成 + 成果展示 | 实践 + 答辩 |

### 2.3 两周营节奏（13 讲）

| 日期 | 上午（理论） | 下午（实践） | 备注 |
|------|------------|------------|------|
| D1 | 第 1 讲：异构计算与 NPU 架构导论 | 环境搭建 + HelloWorld | 入门日 |
| D2 | 第 2 讲：Ascend C 编程模型 | 矢量加法算子跟练 | 基础日 |
| D3 | 第 3 讲：矢量编程（Reg/掩码/非对齐） | 矢量算子独立实现 | — |
| D4 | 第 4 讲：数据搬运与存储层次 | 4h 纯实践：跟练 → 独立实现 → 判题 | 纯实践日 |
| D5 | 第 5 讲：C API vs Tensor API（或基础API) 对比 | 4h 纯实践：**同题双实现对照** | 双 API 对照日 |
| D6 | 第 6 讲：矩阵算子编程（Cube/L0） | 4h 纯实践：GEMM 跟练 → 独立实现 | 纯实践日 |
| D7 | 第 7 讲：融合算子开发 | 4h 纯实践：融合算子 + 优化数据采集 | 纯实践日 |
| D8 | 第 8 讲：调试调优与性能分析 | 2~4h 实践：性能优化实战 | — |
| D9 | 第 9–11 讲：PyTorch 集成 + 量化算子 | 综合实践：双算子 + 框架集成 | 集成日 |
| D10 | 第 12–13 讲：高级优化 + 结业答辩 | 优化冲刺 + 成果展示 | 结业日 |

> **D4/D6/D7 下午为 4h 纯实践**（无新理论，按跟练→独立实现→判题推进）；**D5 为 C API vs Tensor API 同题双实现对照日**，需提交双实现对照报告。

## 三、结业体系

### 3.1 三档结业标准

两营采用同源递进的结业体系：

| 档位 | 两天营 | 两周营 | 说明 |
|------|--------|--------|------|
| **必选保底** | `add_rms_norm` 矢量算子正确性通过 | `add_rms_norm` + `quant_matmul` 双算子正确性通过 | 正确性门禁，必须通过 |
| **必选集成** | —（可选） | 算子集成到 PyTorch 框架，端到端跑通 | 两周营必选，两天营可选 |
| **可选优化** | 性能优化加分（可选） | 性能优化 + 高级特性加分（可选） | 超出基线性能可获加分 |

> **递进关系**：两天营 = 矢量单算子入门；两周营 = 双算子 + 框架集成 + 优化，是两天营的系统性延伸。


### 3.2 进一步学习

完成启航营后，可继续深入：

- **算子开发方向**：参考《AI 计算与神经网络计算架构实践》中第二部分进一步学习A2/A3、Ascend 950算子编程模型、调试调优与最佳实践；
- **框架集成方向**：进入原子课程 L2 层（TorchNPU、TorchAir、分布式训练框架；CANN 训练/推理技术 L2-20~25、图框架 L2-26~28、昇腾 AI 产业生态 L2-29）；
- **系统课程**：衔接《AI 计算与神经网络计算架构实践》课程。

## 六、常见问题

**Q：两天营和两周营有什么区别？应该选哪个？**
A：两天营适合快速入门（2 天掌握矢量单算子开发），两周营适合系统学习（10 天掌握双算子+框架集成+优化）。有时间建议直接参加两周营，内容更完整、实践更充分。

**Q：没有 NPU 硬件可以参加吗？**
A：可以。课程提供云端 NPU 环境，学员通过浏览器即可访问开发环境，无需本地硬件。
