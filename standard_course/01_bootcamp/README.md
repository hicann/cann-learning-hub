# 启航营课程总览（Bootcamp）

> 面向 CANN 算子开发者的集中式训练营，分为**一天营**、**两天营**、**两周营**与**四周营**四档，理论与实践 1:1 配对，以真实算子开发为主线，结业即可具备 NPU 算子开发与集成能力（四周营进一步覆盖大模型训推全链路、矢量 / 矩阵 / 融合全类型算子、图接入、极致性能与社区实践）。

## 二、排课节奏

### 2.1 通用原则

- **理论与实践配对**：每讲理论课后立即配套对应实践作业，实践内容与 PPT 实践环节对齐；
- **渐进式难度**：从跟练 → 变体改造 → 独立实现，逐步提升自主开发能力；
- **即时反馈**：每日实践作业通过 CANNJudge 自动判题，即时获得正确性与性能反馈。

### 2.2 一天营节奏（4 讲）

| 时间 | 内容 | 形式 |
|------|------|------|
| Day 1 上午 | 第 1 讲：昇腾 AI 产业生态与 CANN 架构基础（1h 理论）＋ 第 2 讲：如何开发 Ascend C 矢量算子（1h 理论） | 理论 |
| Day 1 下午 | 第 2 讲实践（1h 跟练）＋ 第 3 讲：CANNBot 算子开发介绍（0.5h）＋ 第 4 讲：结业作业冲刺（2~3h） | 实践 + 结业 |

### 2.3 两天营节奏（6 讲）

| 时间 | 内容 | 形式 |
|------|------|------|
| Day 1 上午 | 第 1–2 讲：昇腾 AI 生态架构 ＋ 基于 CANN 如何部署和推理大模型（各 1h 理论 + 1h 实践） | 理论 + 跟练实践 |
| Day 1 下午 | 第 3 讲：基于 CANN 的大模型推理优化与最佳实践（2h 理论 + 2h 实践） | 理论 + 实践 |
| Day 2 上午 | 第 4 讲：如何开发 Ascend C 矢量算子（支撑推理模型优化，2h 理论 + 2h 实践） | 理论 + 独立实践 |
| Day 2 下午 | 第 5 讲：算子接入 PyTorch ＋ CANNBot（1h 理论 + 1h 实践）＋ 第 6 讲：结业作业（2~3h） | 实践 + 结业 |

### 2.4 两周营节奏（18 讲次）

| 日期 | 上午 | 下午 | 备注 |
|------|------|------|------|
| D1 | 第 1 讲：昇腾 AI 产业生态与 CANN 架构基础（2h 理论 + 2h 实践） | 第 2 讲：基于 CANN 如何训练大模型（2h 理论 + 2h 实践） | 认知日 |
| D2 | 第 3 讲：基于 CANN 如何部署和推理大模型（2h 理论 + 2h 实践） | 第 4 讲：大模型推理优化与最佳实践（2h 理论 + 2h 实践） | 认知日 |
| D3 | 第 5 讲：异构计算与 Ascend C 算子编程导论（2h 理论 + 2h 实践） | 第 6 讲：Ascend C(A2/A3) SIMD 编程模型介绍（2h 理论 + 2h 实践） | 算子入门日 |
| D4 | 第 7 讲：Memory 矢量算子编程实践（基于 C API，2h 理论 + 2h 实践） | 第 8 讲：C API 矢量算子纯实践（4h） | 纯实践下午 |
| D5 | 第 9 讲：Memory 矢量算子编程实践（基于基础 API，2h 理论 + 2h 实践） | 第 10 讲：双 API 同题对照纯实践（4h） | 双 API 对照日 |

### 2.5 四周营节奏（28 讲次）

| 周次 | 主题 | 核心内容 | 关键节点 |
|------|------|---------|---------|
| **W1**（D1~D5） | 大模型训推全链路与 Ascend C 入门 | 生态架构；训练（SFT+RL 基础 / SFT 性能优化）；推理（部署 / 优化 / 高级实践）；异构计算导论 + SIMD 编程模型 | D2 / D4 训推纯实践判题 |
| **W2**（D6~D10） | 矢量 / 矩阵 / 融合算子与调试接入 | 矢量（Softmax）；矩阵（Matmul）；融合（Matmul+LeakyReLU）；调试调优与最佳实践；PyTorch 接入 | D6 / D7 / D8 / D10 下午纯实践 |
| **W3**（D11~D15） | 图接入、CANNBot 与极致性能案例 | AclGraph / GE 入图；CANNBot 全天专题（含更改 skill 优化算子）；矢量 / Matmul / 融合极致性能案例三部曲 | D12 CANNBot 全天专题 |
| **W4**（D16~D20） | 结业大作业与社区实践 | `add_rms_norm` 开发、整网集成、持续优化；社区任务（PR / issue / 算子竞赛） | **D16~D17 结业大作业；D18~D20 社区任务** |

> 四周营部分讲次复用两周营讲义（14 份 PPT）；W1~W2 以「上午理论 + 下午实践」推进（含 7 个纯实践半日），W3 为图接入、CANNBot 专题与极致性能案例三部曲，W4 为结业大作业与社区任务。

## 三、结业体系

### 3.1 四档结业标准

四营采用同源递进的结业体系：

| 档位 | 一天营 | 两天营 | 两周营 | 四周营 | 说明 |
|------|--------|--------|--------|--------|------|
| **必选保底** | `add_rms_norm` 矢量算子功能跑通 | `add_rms_norm` 矢量算子正确性通过（Qwen3-1.7B 场景） | `add_rms_norm` + `quant_matmul` 双算子（Qwen3-1.7B 匹配）正确性通过 | `add_rms_norm` 矢量算子判题通过（QWen3-1.7B 场景） | 正确性门禁，必须通过 |
| **必选集成** | —（可选） | —（可选） | 算子集成到 PyTorch 框架，端到端跑通 | 接入 PyTorch QWen3-1.7B 整网 + 持续性能优化 | 两周营起必选 |
| **必选社区** | — | — | — | 挑选任意社区任务，提交 PR / issue 或参加算子竞赛 | 四周营特有 |
| **可选优化** | 性能优化加分（可选） | 性能优化加分（可选） | 性能优化 + 高级特性加分（可选） | —（性能优化已并入必选作业 3） | 超出基线性能可获加分 |

> **递进关系**：一天营 = 矢量单算子功能跑通（最轻量体验）；两天营 = 矢量单算子入门 + 大模型训推认知；两周营 = 双算子 + 框架集成 + 优化；四周营 = 训推全链路 + 矢量 / 矩阵 / 融合全类型算子 + 图接入 + 极致性能 + 社区实践（20 天完整版），逐档系统性延伸。


### 3.2 进一步学习

完成启航营后，可继续深入：

- **算子开发方向**：参考《AI 计算与神经网络计算架构实践》中第二部分进一步学习A2/A3、Ascend 950算子编程模型、调试调优与最佳实践；
- **框架集成方向**：进入原子课程 L2 层（TorchNPU、TorchAir、分布式训练框架；CANN 训练/推理技术 L2-20~25、图框架 L2-26~28、昇腾 AI 产业生态 L2-29）；
- **系统课程**：衔接《AI 计算与神经网络计算架构实践》课程。

### 4.1 评分细则（仅供参考，具体由任课老师决定）

**一天营结业作业：**
- 必选保底：`add_rms_norm` 算子功能跑通、通过 CANNJudge 判题
- 可选加分：性能优化超出基线（+20%）

**两天营结业作业：**
- 必选保底：`add_rms_norm` 算子（Qwen3-1.7B 场景）正确性通过 CANNJudge 判题
- 可选加分：
  - PyTorch 集成（+10%）
  - 性能优化超出基线（+10%）

**两周营结业作业：**
- 必选保底：`add_rms_norm` + `quant_matmul` 双算子（与 Qwen3-1.7B 大模型匹配）正确性通过
- 必选集成：双算子集成到 PyTorch，端到端跑通
- 可选加分：性能优化、高级特性、代码质量等

**四周营结业作业（四档，全部必选）：**
- 必选开发（作业 1）：开发矢量算子 `add_rms_norm`（只需支持 QWen3-1.7B 模型），CANNJudge 判题通过
- 必选集成（作业 2）：将 `add_rms_norm` 算子接入 PyTorch QWen3-1.7B，整网端到端跑通
- 必选优化（作业 3）：持续优化 `add_rms_norm` 算子性能，提交性能提升数据与优化路径剖析
- 必选社区（作业 4）：挑选任意社区任务、或算子竞赛，提交 PR / issue 或参赛记录

## 六、常见问题

**Q：一天营、两天营、两周营和四周营有什么区别？应该选哪个？**
A：一天营适合快速体验（1 天完成矢量算子功能跑通），两天营适合快速入门（2 天掌握矢量单算子开发并建立大模型训推认知），两周营适合系统学习（10 天掌握双算子+框架集成+优化），四周营适合完整实战（20 天掌握大模型训推全链路与矢量 / 矩阵 / 融合算子开发、AclGraph/GE 图接入、极致性能优化，并以社区任务收尾）。时间越充裕，内容越完整、实践越充分，有时间建议直接参加两周营及以上。

**Q：四周营的社区任务（作业 4）可以选什么？**
A：可从 cann-learning-hub、cann-samples 等社区仓库的 issue / 任务列表中选题（文档改进、教程补充、算子样例、Bug 修复等），也可参加算子竞赛；以提交 PR / issue 或参赛记录作为完成凭证。

**Q：没有 NPU 硬件可以参加吗？**
A：可以。课程提供云端 NPU 环境，学员通过浏览器即可访问开发环境，无需本地硬件。
